# 分析师一致预期修正面·入场券探针预登记（2026-09-03，**用户已冻结，跑前未改**）

## 0. 立项

登记表中 consensus / 预期修正相关条目为零；文献里盈利预期修正是最经典的风格与市场择时变量之一。
库内 `stock_selector.stock_consensus_fy` 为**日频**一致预期（2019-10-08 起，FY1/FY2/FY3 三个滚动期，每日约 4,400～6,200 只票），
`stock_selector.index_constituent` 有 000300 / 000905 / 000852 自 2014 年起的月度成分快照。用户 09-03 裁「继续」（期权面收官后的第二块未测面）。

## 1. 命题（双侧，方向由数据裁决）

分析师对个股盈利的**修正方向与幅度**在 500∪1000 成分上的聚合，是否对现役 equal_weight 生产信号（long-flat，blend 标的）
提供显著、独立（控 equal_weight 偏 IC）、两半窗稳健、成本后存活、**且经选优校正仍显著**的择时信息。

## 2. 数据与构造（冻结）

- **个股序列**：`stock_consensus_fy` `forecast_horizon=1` 的 `net_profit`（FY1 一致预期净利润），按 `ts_code × report_date`。
- **滚动剔除**：Wind 的 FY1 在个股**年报发布日**从年 y 切到 y+1（实测 600519：2024-04-30 由 742 亿跳到 878 亿 = 前一日的 FY2）。
  定义滚动日：`|FY1_t − FY2_{t−1}| / |FY2_{t−1}| < 1%` 且 `FY1_t ≠ FY1_{t−1}`；滚动日的当日变化记 0。实测 2022～2024 滚动标记占票日 0.23%，集中在 2～4 月。
- **日变化**：`c_t = (FY1_t − FY1_{t−1}) / |FY1_{t−1}|`，裁剪到 [−0.5, +0.5]（防个别极端值），滚动日置 0，任一端缺失记 NaN。
- **20 日修正**：`rev20_t = Σ_{s=t−19..t} c_s`（窗内 NaN 视为 0，但窗内有效日 < 10 记 NaN）。
- **宇宙（PIT）**：t 日成员 = `index_constituent` 中 `effective_date ≤ t` 的最新快照；主宇宙 U = 000905 ∪ 000852；R4 另用 000300 与 000852。
  只统计当日 FY1 非空的成员（覆盖：300 约 97%、500 约 90%、1000 约 77%）。
- **四族日序列**：
  - **R1 修正广度** = (#{rev20 > +0.5%} − #{rev20 < −0.5%}) / #覆盖成员（死区 ±0.5% 过滤噪声）；
  - **R2 修正幅度** = 覆盖成员 rev20 的横截面 **10% 截尾均值**（草案原为中位数；序列构建实测 86% 的日子中位数恰为 0——20 日内多数票预期不变，中位数被钉死退化为常数，冻结前改为截尾均值，两侧各去 10%）；
  - **R3 广度变化** = R1.diff(20)；
  - **R4 规模差** = R1(000300) − R1(000852)。
- **PIT 说明**：`report_date` 为 Wind 一致预期的 as-of 日期，t 日值可能含当日发布的研报；本面按 t 日收盘可知、T+1 生效处理，
  与既有五轴同口径；这一假设写入 caveat（若 Wind 快照实际在次日才可得，最多相当于 1 日滞后，对 k≥5 的持有影响可忽略，结果文档须说明）。
- 缺日处理：某日覆盖成员 < 200 记 NaN，不插补。

## 3. 因子族与网格（冻结）

四族 R1～R4 × `GRID_LEVEL`（lb∈{5,20} × zw∈{60,250}）× 持有 k∈{5,10,20,40} = **64 个变体**。与杠杆/温度/长轴/期权面同构，不新增自由度。

## 4. 窗口、秤与闸门（冻结）

- 全窗 2019-10-08～数据尾；**两半窗 2020-2022 / 2023-2026**（本面专用 halves）。秤：blend 标的 + carry、3 bps、T+1；置换 n_perm = 1000。
- 关 1～3：`run_families_probe` 原样（置换 p < 0.05 且偏 IC 同号显著 p < 0.05；两半窗同号；sign-aligned 净 Sharpe > 0）。
- **关 0（候选 ⓪，本面直接写入）**：以全部 64 变体的全窗 |IC| 为统计量、argmax 选优，循环移位置换 1,000 次（移位 ∈ [80, n−80]）得到
  「网格最优 |IC|」空分布；**族代表的全窗 |IC| 须 ≥ 该空分布 95% 分位**（等价 p_vs_max_null < 0.05）。四关全过才 PASS。
  期权面的教训：三关的 p 是选优后 p，膨胀 8.8 倍；本面不再事后补。
- 多重比较披露：4 族 × 16 并测，关 0 已把整套选优吃进零分布；过闸后的装配测试才是终审。

## 5. 功效边界（事前）

可用约 1,650 个交易日（burn-in 后 zw=60 约 2020-01 起、zw=250 约 2020-10 起）；k=20 约 80 窗、k=40 约 40 窗。
只能检出 |IC| ≳ 0.2 的效应；关 0 的 95% 分位按期权面经验约在 0.45（k=40 主导）。未过闸记「低功效未检出」。

③ 2026-06 以后的三个孤立日不进入探针；④ 结果文档须报告两半窗各自的有效日数与非重叠窗数。
