# 关 0 门槛的在位者审计：现役信号过不了自己网格上的关 0

2026-09-03。缘起：资金流面 F1 三关全过、只败在关 0（|IC| 0.2599 vs 门槛 0.337），
用户质疑「毫无疑问的过度设计，现役信号也过不了你的这一系列要求」。本文是对该质疑的直接检验，结论是**质疑成立**。

机器 `backtest/gate0_incumbent_audit.py`，产物 `backtest/output/gate0_incumbent_audit.json`。

## 检验设计

把同一台关 0 机器（`selection_permutation_test`，max-T 口径，1000 次循环移位置换）
套到**现役 equal_weight 信号自己的参数网格**上：

- 网格：lookback ∈ {5,10,20,40}，z_window = 2×lookback（`generate_signal` 内置规则），smoothing = 5（现役值），
  × k ∈ {5,10,20,40} = **16 变体**，含现役点 lb20zw40 / k=20。
- 16 变体的门槛比资金流面的 32 变体**更宽松**——设计上偏向在位者。
- 重建校验：lb20zw40 重建序列 vs 部署的 `equal_weight_signal_20d40z.csv`：
  **corr = 1.000000，max|diff| = 5.0e-05**。审计对象确认是现役信号本身。
- 评窗 3,003 日（2014-05-05..2026-09-03），标的 blend，与资金流面同一 IC 口径（非重叠 k 日窗）。

## 结果：不过，而且不是擦边

| | \|IC\| | 关 0 门槛 q95 | 结果 |
|---|---|---|---|
| **现役点 lb20zw40 k=20** | **0.1948** | **0.2823** | **不过**（差 0.088） |
| 网格最优 lb20zw40 k=10 | 0.2034 | 0.2823 | 不过，`p_selected` = **0.2927** |
| （对照）资金流 F1 代表 | 0.2599 | 0.3370 | 不过，p = 0.2208 |

按「离门槛多远」算，**F1 反而比现役信号更接近**：0.2599/0.337 = 0.77 vs 0.1948/0.2823 = 0.69。

分层 q95：k=5 → 0.106、k=10 → 0.160、k=20 → 0.209、k=40 → 0.279（与资金流面同一形态：门槛随 k 涨）。

## 决定性的一个数：同一条现役信号，换口径就翻

现役网格上：

- `p_selected`（max-T，我在资金流面冻结的口径）= **0.2927**，不显著
- `p_min_p`（Westfall–Young min-P，同一台机器同时算出）= **0.0130**，显著

**同一条已实盘部署多年的信号，在同一份数据、同一个网格上，两个口径给出相反结论。**
这与资金流面 F1 身上观察到的是同一个现象，说明 max-T 对这类跨 k 方差异质的网格不是中性选择。

## 结论与边界

**成立**：我给新候选立的关 0 门槛，现役信号自己过不了。这是一条真实的不对称，而且我在冻结预登记前没有查。

**连带认一处**：资金流面预登记 §4 写的功效边界是「可检出 |IC| ≳ 0.16」，但真正卡住的是关 0 的 0.337，
**差两倍多**。这不是事后才知道的——关 0 门槛在跑之前就能估，我没算。

**不成立的推论 ①：这不说明现役信号是假的。** 关 0 是**发现阶段**的多重检验校正；
现役信号的证据基础是另一类——实盘部署、跨多个确认窗、活的跟踪记录。
拿发现阶段的尺子量一个已服役多年的对象，本来就不该期待它过。

**不成立的推论 ②：这不说明关 0 该取消。** `selection_permutation.py` 记着没有它时的实测假阳率：
16 点网格 **20%**、40 点网格 **35~44%**（名义 5%）。不做多重检验校正，三个探针里就有一个是假的。
问题不在「要不要校正」，在「选了哪种校正」。

**不成立的推论 ③：这不构成对 F1 或期权面 O2 的翻案。** 看过读数再换口径，就是用同一份数据既选规则又下结论。

## 波及面

近期这一串轴里，大多数是**实质上**没东西（创新高 IC 近零、反转 27 点全负、分析师预期关 1 全不过、基差三族 STOP），
这些不受本审计影响。

但有**两条**是三关过了、只败在关 0：

这两条的 STOP 结论现在都要带上限定：**它们是被一条现役信号也过不了的线挡掉的**。
处置不是翻案，是：**下一条新面的预登记把口径选择论证清楚**（见 `2026-09-03-gate0-criterion-argument.md`），
再拿论证后的口径去跑这两条的样本外确认。

## 审计本身的边界

- 现役信号的**真实历史搜索空间未知**，本文的 4×4 网格是按 `generate_signal` 的内置参数规则重建的近似。
  真实空间若更大，门槛只会更高（对结论无害）；若当年是按别的准则选点，则「现役点」的含义会变。
- 评窗（3,003 日）与资金流面（2,715 日）不同，两个 q95 不可直接互比；文中只在各自网格内比较。
- 本审计不改变任何已登记裁决。
