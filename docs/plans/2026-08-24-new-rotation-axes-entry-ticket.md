## 1. 构建规格（冻结）

- **带**：四个总市值排名带（`sample_space` 现状机器，含既有过滤：沪深后缀、
  剔新股 1 年、剔流动性尾部 20%）：300带=1–300 / 500带=301–800 /
  1000带=801–1800 / 2000带=1801–3800。
- **调样**：`rebalance_dates("2015-06-01", <数据末>)`（半年，中证口径），
  首个 eff = 2015-06-15（与 geo5 同窗）。考察截止 = `review_cutoff(eff)`。
  期间收益覆盖 `(eff_i, eff_{i+1}]`，末期到数据末。
- **因子窗**：cutoff 前 420 自然日的日收益（`close/pre_close−1`，行级有效性
  沿用 `_daily_returns`）。
  - 低波：窗内**最后 244 个交易日**收益标准差；非缺失 ≥120 日，否则该票剔除。
  - 动量：**12-1 动量** = 跳过最后 21 个交易日、再往前至多 252 个交易日的累计
    收益；非缺失 ≥120 日。
  - 流动性：`adv_1y / avg_mv_1y`（成交额换手率；两列取自 `sample_space` 帧，
    任一缺失剔除）。**注**：非官方自由流通换手，库内无日频流通股本历史的
    低成本替代；进截面排名，方向性不受影响。
  - 股息：D/P，**逐字复用腿工厂已冻结机器**——`dp_source_for(cutoff)` 切换：
    2026-01-01 前 = `dividend_ttm_events(修正可知日事件行)/avg_close_1y`，
    之后 = `stock_indicator.dividend_yield`；未分红 fillna(0)（真实 0，
    非缺失伪装——DP 死因子教训在案）。
- **腿**：带内按因子升序排名，`n//3` 只入腿（低/高三分位两端）；任一腿 <10 只
  → 该带该期跳过并记录（无静默截断）。**腿内等权**，期间买入持有漂移
  （`_leg_returns` 同款语义，停牌日 0 收益）。
- **canonical 方向**（spread = 多腿 − 空腿）：低波轴 = 低波腿 − 高波腿；
  动量轴 = 高动量 − 低动量；流动性轴 = 高换手 − 低换手；股息轴 = 高股息 − 低股息。
- **信号**：每带 `_signal(多腿净值, 空腿净值)`（decompose 生产口径：
  lookback20/z40 tanh + rolling5，**无参数网格**——避免选优置换问题）；
  轴信号 = 当日可用带**等权平均**（带数序列入档）。

## 2. 入场券判定（冻结措辞）

- **主判读**（每轴一条）：轴信号对宽基 **blend**（`load_underlying_returns`，
  与 baseline 同标的层），**k=20 非重叠**，`partial_ic_with_pvalue` 控
  **现役 ew 生产信号**（`output/equal_weight/equal_weight_signal_20d40z.csv`
  `factor_value` 列），n_perm=2000，seed=0，评窗 **2015-08-15 → 数据末**
  （跳过信号 warmup）。
- **过闸 = partial IC 有限且双侧置换 p < 0.05**；IC 符号入档，作为后续正式
  立项的冻结方向假设。
  - 登记语实例化注记：用户登记语「显著为正」按上述 canonical 方向的**双侧**
    检验实例化。理由：新轴 spread 的预测方向无先验，单侧「为正」会把信息判定
    绑死在任意方向约定上；双侧偏严不偏宽。机器（`partial_ic_with_pvalue`）
    原生双侧。
- **多轴**：四轴各自判读；另报 Bonferroni×4 参考列（p<0.0125，不改判）。
- **参考行（不判定）**：k∈{5,10}；目标 500/1000；两半窗
  （评窗起→2020-12-31 / 2021-01-01→末）偏 IC 点估计；无控 IC + 双侧置换 p；
  ew 对 blend 的 k=20 IC（量级锚）。
- **两个锚（先于判读检查）**：
  1. 接线锚：`partial_ic(ew, blend, control=ew) = 0`（残差退化路径，机器应
     精确回 0）；
  2. 负控锚：rotation 信号（`rotation_target_probe.build_signals("U2")`
     同款构造）走同一判定，**预期不过闸**。任一锚破 → 先查管线，不读轴行。
- **功效预检（事先接受措辞）**：评窗 ~2,650 交易日 → n≈132 个非重叠窗，
  se≈0.087，双侧 5% 可辨 |pIC| ≳ 0.17。未过闸只得写
  **「当前功效下不可辨认」**，不得写「无增量信息」。
- **后果**：过闸 = 进入正式预登记队列（配对检验主体、答钝化问；入场券
  **不是采用批准**）。未过闸 = 归档，重开须新证据或更长评窗。
