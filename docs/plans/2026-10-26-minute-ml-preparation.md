## 研究问题及固定比较

研究个股日内路径和横截面参与度，能否为equal_weight期货池提供日频特征之外的增量。
首轮保持每日决策，以5分钟尺度提炼结构，不新增日内交易或自建成长/价值分类器。

- A组：沿用上一轮14列日频价格/风格特征；不加入已测的两列OI。
- B组：相同14列＋以下16列分钟结构特征；相同可用训练日期、相同测试日历。
- 模型：各组Ridge和浅层HistGradientBoosting，共4条；模型及有限参数列表、年度扩展训练、
  内层245条成熟标签验证、至少500条内层训练、MSE选参均复用`backtest.ew_ml`。
- 主标签：沿用T+1收盘成交，T+2..T+6五日实际合约池收益的风险标准化代理。
  不因为分钟信息可能短效而事后改成最有利的持有期。首轮不新增次日/开盘目标搜索。
- 执行：原EW、固定75%、固定半空、波动控制和同方向过去仓位均值参照；IC/IM实际合约，
  3bp、10bp、额外延迟一天。同窗比较B相对A以及相对简单策略，不能只比较新旧run全窗数字。
- 2019起逐年外层预测为预定框架。具体起止须等交付覆盖验收后、任何收益计算前锁定。
  若不足500＋245条成熟训练记录，报告不能按该框架运行，不缩短预热来凑结果。

14列日频特征应按新的统一输入版本生成，沿用公式；旧run只作为已知历史证据，不修改。
标签始终先在完整交易日历生成，再筛训练行，禁止压缩缺日后再shift。

## 交付契约：不猜供应商时间含义

契约版本`stock-minute-ml-input-v1`，输入为每个交易日的小批规范化数据。
源码不包含数据库配置、真实数据读取器或正式训练CLI；清洗后再对接真实导出接口。

1. `bars`：symbol、bar_end、open/high/low/close、volume、amount、quality_ok、available_at。
   价格为未复权元，量为股，额为元；本轮只用单日相对价格，无隔夜收益或跨日复权拼接。
2. 固定48格：Asia/Shanghai，9:35..11:30、13:05..15:00，每格5分钟结束标签。
   开盘集合竞价不并入首格，收盘集合竞价归最后一格；这是一份**待数据方确认的消费契约**，
   不声称当前源标签已经符合。源区间、午休和竞价映射必须有明确交付依据；不能简单平移标签。
3. `memberships`：session_date、pool（500/1000）、symbol、effective_date、known_at、
   eligible、exclusion_reason。逐日完整历史名单，并提供独立的各池应有成员数。
   不以当前成分股回填历史、不从当天有行情的股票反推名单。生效日和已知时间不得晚于决策时点。
4. eligible=false仅允许显式`suspended`或`not_yet_listed`；名单仍保留在质量审计里。
   其余缺数据、异常、迟到、一日零量、首格无成交的股票日计入覆盖损失，不能事后改成“不适用”。
5. 全部时间列须显式带时区。决策截止采用T日20:30。available_at为可用时刻，不能用
   本次历史回填时间假装历史发布时刻；仅有合理滞后假设时，manifest声明documented_assumption，
   结果不得声称历史实时可得性已证实。时间契约确认不了时，不启用依赖它的特征。
6. 质量屏蔽精确到股票、日期、周期；绑定清洗版本与未解决问题清单，不按后续收益决定剔除。
   48格缺任何一格、重复、跨日或午休标签、非有限值、负量额、不可能OHLC、已标异常、
   晚于截止发布等，均有可审计拒绝或股票日无效原因；不前填缺格、不自行修库。
7. 零成交格保留：量额均零，OHLC必须为相同价格且与前格收盘相等。首格必须有真实成交，
   否则缺少本日路径起点，该股票日不可评分。正量与正额必须同时成立。
   全日零量不会被当作“低波动优质样本”。成交均价超OHLC范围1分钱以上时标为无效代理输入，
   不宣称因此确定源字段错误；按原值保留审计。

`examples/minute_ml/delivery.template.json`是未就绪模板；必需文件角色为bars、memberships、
calendar、quality_exclusions，包含相对路径、SHA256、字节数和行数。清洗回执、规范化依据、
成员来源、质量版本和覆盖起止均需填实。状态为ready也不自动发起读取或研究。

## 每个股票日的路径与每池8个特征

用48格首格open为起点，后续格用前格close，形成48个log收益r。
early为首6格累计（前30分钟），late为末6格累计（最后30分钟），day为48格总和。
实现用等价的区间端点价格比计算early/late/day，避免log逐项相加的浮点残差把平盘误判上涨。
每池对有效且eligible的股票等权聚合，不用当日成交额或当日市值作动态权重。

| 每池特征 | 精确定义 |
|---|---|
| up_breadth | day>0的股票比例，零收益不计上涨 |
| late_up_breadth | late>0的股票比例 |
| early_up_late_down | early>0且late<0的股票比例，分母为全部有效股票 |
| return_dispersion | day的横截面标准差，ddof=0 |
| path_efficiency | 平均sum(r)/sum(abs(r))；全平路径取0 |
| downside_variance_share | 各股票sum(min(r,0)^2)之和 / 各股票sum(r^2)之和；分母0取0 |
| late_volume_share | 平均(最后6格成交量/全日成交量) |
| close_location | 平均((最后close−全天low最小值)/(全天high最大值−全天low最小值))；全平取0.5 |

500和1000各8列，共16列。不命名为主力净流入、主动买卖、真实价格冲击或投资者身份。

每池覆盖率=有效eligible股票数/完整名单中的eligible股票数，必须≥95%，且分母>0。
两池任一不通过，则当日16列全部置为缺失，保留交易日及分池覆盖、逐股票日原因。
95%是事前质量容忍，不是对缺失无偏的保证；必须报告被屏蔽范围和覆盖分布，不能见收益再调。

## 接入模型时的缺失及公平对照

合成验证提供`align_feature_groups`：要求日频、分钟表和有效标记拥有完全相同的完整、
唯一、升序日历；已标有效但出现非有限值须失败。训练行取两组共同有效日期。
不把覆盖率、清洗状态或缺失标记作为预测特征。

当日分钟无效时，A/B四条模型均回退原EW，保持同样的可用性。
有效日q=.75+.25*tanh(p)，先在完整交易日历做5日均值；无效日用p=0作为中性平滑占位，
但实际q强制为1。后续有效日的5日窗口仍按真实交易日计算，不跳过缺日。
同方向过去仓位参照也保留相同回退日；匹配有效/无效状态分别报告，不冒称精确同风险。
`past_control_with_fallback`只用此前有效且同方向日的仓位估计均值；无效日不参与估计。

最终报告除原经济门槛外必须列出B−A的预测误差、净收益、Sharpe差、分年/分段稳定性及
成本/延迟/最好5日敏感性。历史复用，不授予统计GO，不按外层结果拼接赢家。
