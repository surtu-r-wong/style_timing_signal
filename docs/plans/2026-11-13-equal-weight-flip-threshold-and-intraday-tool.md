# equal_weight 线穿零后的翻负阈值与日内情景测算（2026-11-13）

**背景**：期货池现役 equal_weight 对称线的平滑值 2026-11-11 收 −0.0341，11-12 收 **+0.0543**
刚穿零，对称仓 −1 → +1。用户要求测算：今天的 raw 当天值多低会把平滑值再次拉回负数，
并按「成长 −6.5% / 价值 +1%」情景估算。当日完成，全部数字以 2026-11-13 盘中为有效期。

## 结论（TL;DR）

1. **翻负阈值：raw_today < −0.5163**（= −窗口内前四天 raw 合计，11-09~11-12 为 −0.0810/+
   0.0026/+0.3003/+0.2944）。低于它则平滑值转负、对称仓翻回 −1。
2. **成长 −6.5% / 价值 +1%（四对统一）翻不了负**：raw 只到 **−0.2435**，平滑值 **+0.0546**
   （与昨天 +0.0543 几乎持平——滚出的 11-06 raw −0.2446 与新进的 −0.2435 近似等量替换），持仓维持 +1。
3. **翻负需要单日相对冲击 ≈ −11.7%**：价值 +1% 固定时成长要单日跌 ≈ **−10.7%**；
   成长 −6.5% 固定时价值要单日涨 ≈ **+5.2%**。属极端行情量级。
4. 若今天四对平走（0/0），raw ≈ +0.3444、平滑值 ≈ +0.1721（−0.2446 滚出反而抬升）。
5. 已沉淀为可复用工具 `tools/intraday_scenario.py`（见文末），此后日内估算不必手工推导。

## 口径与验证

- 生产口径：`factor_value` = `factor_value_raw` 的 **5 日简单移动平均**；每对
  相对收益 = 成长简单收益 − 价值简单收益 → 20 日滚动复合 −1 → z=(cum−mean40)/std40 →
  **tanh(z/2)** → 四对（300/500/1000/2000 成长 vs 价值）等权平均。
  来源 `signals/equal_weight/generate_signal.py`；部署口径见 `backtest/production.py`
  （POOLS：期货池 = equal_weight 对称）。
- 验证：从 PG `stock_selector.index_daily` 拉 8 指数复算，11-12 与 committed
  `equal_weight_signal_20d40z.csv` 最大偏差 5e-5（4 位小数舍入级），口径对齐。
- 平滑值一过零对称仓即翻转（`symmetric_position` 阈值 0，无死区）。

## 情景测算明细（2026-11-13 模拟日）

统一冲击「成长 −6.5% / 价值 +1%」即每对当日相对收益 −7.5%：

| 对 | factor (tanh(z/2)) | 隐含 z |
|---|---|---|
| 沪深300 | −0.269 | −0.55 |
| 中证500 | −0.207 | −0.42 |
| 中证1000 | −0.087 | −0.18 |
| 中证2000 | −0.410 | −0.88 |
| **四对等权 raw** | **−0.2435** | — |
| **平滑值 SMA5** | **+0.0546 → 持仓 +1** | — |

单日 −7.5% 相对冲击只打出 raw −0.24 的原因：**z 分母大**——20 日风格价差的 40 日标准差
被近两周剧震撑大（raw 从 11-03 的 −0.745 冲到 11-11 的 +0.30），单日 −7.5% 不足 1σ；
tanh(z/2) 压缩 + 四对平均进一步稀释（中证 1000 只到 −0.087）。

成长跌幅 → raw 扫描（价值 +1% 固定，单调）：

| 成长单日 | −2% | −6.5% | −10% | **≈−10.7%** | −15% | −20% |
|---|---|---|---|---|---|---|
| raw | +0.116 | −0.2435 | −0.477 | **−0.5163（翻负）** | −0.703 | −0.829 |

分对示例：仅 300/500 挨打（−6.5%/+1%）、1000/2000 平走时 raw 仅 **+0.0911**、平滑 +0.1215
——未挨打两对仍在 +0.47/+0.37，分化稀释显著。

## 工具：`tools/intraday_scenario.py`

```bash
# 统一冲击（百分数）；无参 = 四对平走基准
/home/elfbob/claude-code/stock_selector/.venv/bin/python style_timing_signal/tools/intraday_scenario.py -g -6.5 -v 1.0
# 分对覆盖：-g/-v 为缺省，段 ∈ 300/500/1000/2000
... tools/intraday_scenario.py -g -6.5 -v 0 --pair 300:-6.5:1.0 --pair 1000:0:0
```

- 数据基期自动取 PG 最后已收盘交易日，追加模拟日重跑生产管线原函数（非复制品）；
- 每次先与 committed CSV 对账，偏差 > 5e-4 报错退出；翻负阈值随窗口自动滚动；
- 统一模式附带成长/价值两个反解（粗扫 + 二分，防非单调）；只读 PG，不写任何文件；
- 注意：20:30 日更后再跑，基期变为当天、模拟的是下一交易日（输出有「数据基期/模拟日期」两行）。

## 边界与过程备注

- **阈值逐日滚动**：窗口前四天 raw 变了阈值就变；本文 −0.5163 仅对 2026-11-13 有效。
- **反解对分母敏感**：z 的 40 日 std 缩小后（风格波动回落），同样幅度的单日冲击
  折算的 z 会更大，本文「−11.7% 才翻负」不可外推到平静期。
- 过程记录：反解初版二分方向写反，曾给出「跌 0.1% 即触阈」的荒谬值，自查后改粗扫+
  正确二分并网格核对；工具的三种模式均已实跑验证、数值与本文一致。
