| `p_min_p`（备用口径·不入闸） | 0.330669 | — |
| `selection_inflation = p_selected / p_naive` | **4.63×** | — |

**观测赢家 0.2315 连零分布的 p95（0.3487）都够不到**——不是擦边，是明显落在零分布主体内。

### 闸③ 早/晚期一致性（stability 硬闸） —— **PASS**

选择窗按中位交易日对切：**切点 2018-12-26**，early 1217 天 / late 1217 天。

| 半窗 | 桶 IC（下 / 上） | 桶天数 | 有符号统计量 |
|---|---|---|---|
| early 2014-01-02 ~ 2018-12-25 | 0.281611 / 0.003004 | 579 / 569 | −0.278608 |
| late 2018-12-26 ~ 2023-12-29 | 0.361999 / 0.238989 | 720 / 497 | −0.123011 |

**去均值余弦 = +1.0 > 0 → PASS**。二分（2 维）按预登记明文接受"退化为排序一致"，
本例即"两半窗都是 下桶 IC > 上桶 IC"。
诊断（不进闸）：同一状态变量的**三分**版余弦 = **+0.9289**
（early [0.1785, 0.2952, −0.0352] vs late [0.2742, 0.4358, 0.2002]），
说明形状一致不是二分退化带来的假象。

→ 闸③ **过了**，因此按预登记 §11 的预算纪律，**闸④ 照跑**（未触发中止分支）。

### 闸④ 收益层 —— **FAIL**

调节器（单点、无自由参数）：赢家选择窗有符号统计量 = −0.2315 < 0
→ **低效力桶 = 上桶（高波动半区）**，`w(上)=0.5`、其余（含 69 个状态 NaN 日）`w=1.0`。
先 `production_position`（long-flat θ=0）再乘 `w` → 仓位取值 ⊂ {0, 0.5, 1}。

| 窗 | 调节版净 Sharpe | 现役净 Sharpe | 差 | 调节版 ann / maxdd / 换手 | 现役 ann / maxdd / 换手 |
|---|---|---|---|---|---|
| train_2014_2020 | 1.730849 | 1.705347 | **+0.0255** | 21.18% / −8.68% / 11.052 | 29.11% / −13.48% / 11.339 |
| **val_2021_2023** | **0.988328** | **1.000931** | **−0.0126** | 8.86% / −11.11% / 9.099 | 11.72% / −13.12% / 8.425 |
| selection_2014_2023 | 1.556563 | 1.538854 | +0.0177 | 17.72% / −11.11% / 10.468 | 24.13% / −13.48% / 10.468 |
| holdout_2024_2026（只报告；**carry 止于 2026-04-29 → 本窗最后一年无 carry 输入，对多头略偏悲观**） | 2.093387 | 1.858890 | +0.2345 | 25.34% / −11.67% / 10.095 | 34.06% / −16.67% / 10.872 |
| full_2014_2026（只报告） | 1.672081 | 1.609892 | +0.0622 | 19.29% / −15.45% / 10.392 | 26.17% / −16.67% / 10.551 |

**`worst(train,val)` 调节版 = 0.988328 < 门槛 1.100931 → FAIL**，
缺口 **0.1126**；而且它比现役的 1.000931 **还低**。

经济读法（供关帐引用）：调节器在 **4 / 5 个窗上都提升 Sharpe**，
却恰恰在**唯一起约束作用的那个窗（val）上把它压低**。原因是
**IC 高 ≠ 赚钱多**：把高波动半区仓位砍半，年化收益从 11.72% 掉到 8.86%（−24%），
回撤只从 −13.12% 收到 −11.11%（−15%），收益下降快过风险下降 → Sharpe 反降。
换手方向也不统一（train ↓、val ↑、holdout ↓；选择窗两者恰好都是 10.468，是巧合）
——预登记本就规定换手只报告不设闸，不作判据。

**结论：即便闸② 侥幸过了，闸④ 也在同一批数上独立地否掉了这条路。**

## 4. 诊断列（预登记明示不进闸门）

- **`paired_ic_bootstrap`（i.i.d. 抽样，与 20-offset 平均口径不匹配 → 只作诊断）**：
  在 offset=0 的单条非重叠网格（选择窗 122 点）上，比较 `x_a = signal × w(s)` 与
  `x_b = signal` 对同一批前瞻收益的 rank IC，同一组抽样行同时作用两侧：
  `diff_ic = +0.020977`，95% CI **[−0.0288, +0.0733]**，`p = 0.4049` → **CI 含 0**。

  > **该诊断的适用边界（QA Minor-3，必须连读）**：`x_a = signal × w` **不是 `x_b` 的单调
  > 变换** —— offset=0 网格上 **48.4%（59/122）的因子值为负**，乘 0.5 会把这些点的秩
  > **往上抬**，`diff_ic` 因此混入了纯粹的秩畸变，不是干净的"调节是否提升预测力"。
  > 而且它检验的是**因子级**乘法，**不对应闸④ 实测的调节器**（后者乘的是 long-flat
  > **仓位** ∈ {0,1}，对 `signal ≤ 0` 的日子根本不生效）。
  > → **本行只可作"方向粗看"：CI 含 0、p≈0.40，未见任何与闸②/④ 相反的信号。**
  > 不得据此对闸④ 的调节器、或"按状态调节因子"这一类命题下任何结论。
- **单 offset 的稀薄证据**（面板列 `rank_ic_offset0` / `rank_ic_offset0_n`）：
  赢家变体在 offset=0 网格上每桶只有几十个点，正是预登记 §5 换掉单 offset 口径的理由。
- 零分布诊断：当选统计量 p95 = 0.3487、8/8 变体在零分布下都当选过。
