## 1. 命题（双侧，方向由数据裁决）

股指期权的前瞻性风险定价（隐波水平/变化、期限结构、偏度、看跌看涨持仓比）是否对现役 equal_weight 生产信号
（long-flat，blend 标的）提供**显著、独立（控 equal_weight 偏 IC）、两半窗稳健、成本后存活**的择时信息。
任一族过闸 → 另开多头装配设计；全不过 → 期权面归档，"生产信号对公开信息面的覆盖度"第八次确认。

## 2. 数据与构造（冻结）

**源**：`public.option_daily`（symbol / trade_date / settle / volume / oi），底层指数收盘 `stock_selector.index_daily`
（IO→000300.SH，MO→000852.SH）。**不用厂商 implied_vol / greeks**：它们 2025 年仅约 75% 覆盖、2026-02-25 起全空，
且 strike 列空；全历史一律自算，保证口径一致。厂商值只作 2020～2024 的量级对照（自算 ATM 隐波与其同量级、相差 1～2 个波动点，
差异来自时间口径，见 §6）。

**自算规则**：
- 合约解析：`IO2609-C-4700.CFE` → 月份 2609、C/P、行权价 4700。到期日 = 合约月第三个周五，非交易日顺延到下一交易日（数据核实：2602→02-24、2606→06-22）。
- 每日近月 = 距到期 ≥ 7 个自然日的最近合约月，次月 = 其后一个合约月；T 按自然日 / 365。
- 隐含远期 F：取距指数收盘最近的 3 个行权价，`median(K + C − P)`（结算价）。
- ATM 隐波：K 取距 F 最近的行权价，用 Black-76 分别反推 call 与 put 隐波，取均值。
- **IV30**：近月与次月 ATM 方差按自然日线性插值到 30 天，开方。
- **期限斜率**：次月 ATM 隐波 − 近月 ATM 隐波。
- **偏度**：近月内按行权价线性插值，`IV_put(0.95F) − IV_call(1.05F)`（插值点越界则取端点，并计入质量报告）。
- **PCR**：当日全部挂牌 put 持仓量之和 / call 持仓量之和。
- 缺日处理：某日不能构造（合约不足 / 反推失败）记 NaN，不插补；质量报告披露 NaN 天数。

**PIT**：全部用当日结算价与收盘价，收盘即知；信号 T 日生成、T+1 生效（`engine.run_strategy` 同秤），无额外滞后。

## 3. 因子族（冻结：五族主测 + 一族描述）

| 族 | 定义 | 语义（先验，双侧） |
|---|---|---|
| O1 隐波水平 | `level_signal(IV30_IO, lb, zw)` | 高隐波=恐慌定价高涨 |
| O2 隐波 20d 变化 | `level_signal(IV30_IO.diff(20), lb, zw)` | 隐波急升=避险爆发；回落=修复 |
| O3 期限斜率 | `level_signal(term_IO, lb, zw)` | 倒挂（近月>次月）=即期压力 |
| O4 偏度 | `level_signal(skew_IO, lb, zw)` | 看跌相对贵=尾部对冲需求 |
| O5 持仓 PCR | `level_signal(PCR_IO, lb, zw)` | 看跌持仓占比高=对冲拥挤 |
| O6（描述） | `level_signal(IV30_MO − IV30_IO, lb, zw)` | 小盘相对恐慌溢价；2022-08 起，**只报数不裁决** |

网格：全族 `GRID_LEVEL` = lb∈{5,20} × zw∈{60,250}（4 形态）；持有 k∈{5,10,20,40}。与杠杆/温度/长轴三批完全同构，不新增自由度。

## 4. 窗口、秤与三关（冻结）

- 全窗：IO 2019-12-23（含 burn-in 后实际约 2020-12 起可用，zw=250 时更晚）～ 2026-09-02。
- **两半窗（本面专用，替代默认 2014-2019 / 2020-2026）**：`2020-01-01～2022-12-31` / `2023-01-01～2026-12-31`。
  实现上给 `run_families_probe` 增加 `halves` 参数，默认值不变。
- 秤：`load_underlying_returns` 500 / 1000 / blend，blend 裁决；成本 3 bps/边；carry 计入；置换 n_perm = 1000。
- 三关（`run_families_probe` 原样）：关 1 置换 p < 0.05 且偏 IC（控 equal_weight 生产信号）同号显著 p < 0.05；
  关 2 全窗与两半窗同号（`pick_representative` 强制）；关 3 sign-aligned 持有净 Sharpe > 0。任一不过 → 该族 STOP。
- 多重比较披露：5 族 × 4 形态 × 4 k 并测、族内选代表；探针是廉价第一滤网，过闸后的装配测试才是终审。

## 5. 功效边界（事前写明）

IO 可用样本约 1,400 个交易日（扣 burn-in）：k=20 非重叠约 70 窗，两半窗各约 35；k=40 约 35 窗。与 07-09 C1 的 79 窗同级，
**只能检出 |IC| ≳ 0.2 级别的效应**；未过闸的族记「低功效未检出」而非「无信息」。O6 样本约 900 日，不裁决。
