## 3. 解读与边界

- **两个板块的残差流对同一目标符号相反**，且两者信号层相关只有 0.29。这说明「市场级主力残差净流入」不是一个跨板块一致的量：
  哪个板块的流入算"主力在买"，答案随板块而变。原线 F1 的 +0.26 更像 300+创业板这对组合在 2015-2026 上的特定读数
  （32 变体 + 代表选择 + 三关同尺），不是可迁移的机制。
- 原线本身只败在关 0（max-T 门槛），本结果**不构成翻案也不需要翻案**：关 0 当时拦下的正是这种"三关过但机制不稳"的候选。
  以在位者审计的话说，关 0 门槛对 F1 太高是真的，但 F1 也没有它看起来那么真。
- **不得引作**：「科创板资金流无信息」（只测一个冻结规格，且它在原方向反向是描述不是裁决）；「资金流面已穷尽」（F2 型科创−300、同表四档字段未登记）。
- **方法记录（两条复制线合看）**：基差线输入侧相关 0.61 → 复制 −0.03；资金流线相关 0.29 → 复制 −0.16。
  两条"三关过/全格同号、只败关 0"的贴线候选，横截面上一个归零一个反向。**关 0 在这两例上的判断都是对的**；
  今天的 min-P 论证只说明 max-T 功效低，不说明被它拦下的东西是真的。
- 三条盘点里剩下的隐波 HO（22 窗、与 IO 同读数概率高）与股息（18 窗）功效更低，按本日两例的结果，**不建议再开**；
  建议把它们的重开条件改写成「无横截面出路，关帐」而非留等时间的措辞。
