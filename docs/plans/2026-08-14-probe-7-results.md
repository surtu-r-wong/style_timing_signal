### 1.1 实现偏离登记（照 probe4 偏离 A~G 体例；实现期发生，控制器事后裁）

- **偏离 A（分位 → 仓位映射）**：预登记只钉了"信号 = rolling/expanding percentile"，
  未指明关3 净值层的仓位映射；房规 `hold_position` 按 **sign** 换仓，而分位 ∈ (0,1] 恒正
  → 直接喂会退化成"恒满仓 buy&hold"。实现取 **`pct − 0.5` 居中**（高于/低于中位 =
  与既有 tanh 信号同款的居中语义）再交 `hold_position(sig×direction, k)`。
  **IC/置换/关1/关1b/关2 完全不受影响**（Spearman 对单调平移不变），只作用于关3 与
  净值报告列。判例 `test_centered_shifts_by_half_only`。
- **偏离 B（P95 的取法）**：预登记写"当期样本 `ann_date` 的 P95 日生效"，未指明插值口径。
  实现取 **`percentile_disc(0.95)` 语义**（排序后 0-based 下标 `ceil(0.95·n)−1` 的
  **实际观测日**，不插值）→ 保证 ≥95% 样本已披露（PIT 保守方向）。SQL（A2）与 pandas（A1）
  同一语义，判例 `test_p95_eff_date_percentile_disc_semantics` + 锚点期交叉验证。
- **偏离 C（生效日乱序的 PIT 语义，库内实测恰一例）**：**2019Q4 年报 P95 = 2020-04-30
  （疫情延迟）晚于 2020Q1 季报 P95 = 2020-04-22**，预登记"生效日起 ffill 成日频阶梯"
  未预见两期生效日倒挂。实现取 **as-of by report_date**：任一日显示"生效日 ≤ t 的期中
  report_date 最大者"——新期一经生效即取代旧期，**2019Q4 的台阶从不出现在日频序列里**
  （反向规则 = 旧数据在 4/30 盖掉新数据，经济上不可辩护，不采）。残留 look-through 如实登记：
  2020Q1 生效日（04-22）时其 expanding 窗内的 2019Q4 **最终值**实际只有 **70.7%** 样本已披露
  （8 天后达 P95）——单期、单值、8 个自然日的口径残差，方向与幅度都不足以改变任何判读。
  判例 `test_step_to_daily_newer_report_supersedes_on_eff_collision` 等两条。
- **偏离 D（复用面的边界）**：预登记要求"与 ②/面2 同一目标序列与机器"。实现**原样复用**
  `selection_permutation_test` 与 `divergence_probe` 的统计量机件（`ScoreFrame` /
  `build_score_frames(grid_k=…)` / `abs_spearman_batch` / `abs_partial_batch` /
  `make_batch_scorer` / `net_sharpe_by_window` / `p_at_threshold`）及房规
  `nonoverlap_ic` / `hold_position`；但 ② 的两台**编排器** `build_ic_panel` / `run_machines`
  未复用——其内部 `variant_grid()`/`GRID_LB`/`GRID_ZW`/`min_shift=80` 在 `def`/模块层绑死
  ② 的 (fam,lb,zw,k) 网格，⑦ 的网格没有 lb 维、zw∈{250,500}、⑦A 需 `min_shift=120`，
  面2 式"运行期换绑"救不动三处常量 → 探针本地写了**等价编排薄层**（逐点循环 + 单次调用），
  并保留面2 同款"向量化 vs 房规 ≤1e-9"运行期断言（实测 2.78e-17）兜逐位一致。
  **不改 ② 任何代码，机器与统计量零口径漂移。**
- **偏离 E（关2 半窗切分细则）**：预登记"按各族自身样本切半"未指明切点。实现取
  **选择样本前 n//2 天 / 其余**（⑦B：2018-01-11~2021-01-05 / 2021-01-06~2023-12-29；
  ⑦A：2018-04-23~2021-02-25 / 2021-02-26~2023-12-29），切分日已入 summary sidecar。
- **偏离 F（报告列范围一度收窄，QA F1 返修已补齐）**：预登记 §B.15 写的是
  `corr(⑦B, ⑦A)`（全 ⑦B 两维），首版 diagnostics 只交付了 size 维 vs ⑦A 的 4 行
  （沿用了立项导航的措辞"corr(⑦B size 维, ⑦A 两序列)"）。返修用**完全相同**的对齐方法
  （同 `_pair`、同 ⑦A 选择样本 n=1,385）补齐 gv 维 4 行（§3.2）；重跑逐字节确认
  panel/permutation/verdict/sensitivity/summary 五件产物与首版**完全相同**，
  仅 diagnostics 增 4 行——不触任何闸门数字。

## 4. 限制段

1. **长 k 档抬高零分布水位（②/面2 限制的第三次复现，更极端）**：⑦B 零分布赢家
   k=40 当选 **864/1000** 次（k5 仅 2 次）；⑦A k=60 当选 **664/1000** 次。观测赢家
   恰好也是长 k 档（B k40 / A k40，A 的关1b 机器自选 k60），`p_selected` 高有结构性成分。
   **明确不做**：砍长 k 重判（二次选优，预登记禁令）。
2. **⑦A 低功效是硬约束**：33/22 个独立观测 + 6 点选优 → 过闸线 |IC| ≈ 0.5 量级；
   本探针对"中等强度的拥挤反向效应"**没有检出能力**。结论只能写"低功效未检出"（§B.12）。
3. **⑦A2 语义不纯已由用户接受**（预登记 §B.8）：创业板+科创板占比是"小盘成长"混合代理，
   与 size/growth 单维都不对齐；A2 与 ⑦B size 维 corr 0.53 也部分来自共同的市场状态而非
   同一风格轴。
4. **方向先验的射程**：§B.5 的先验写在"风格价差反向"上，而三关目标序列 = blend 绝对收益
   （闸门框架沿用 ②/面2，预登记 §B.14 自洽钉死）。size 维负 IC 与先验**语义上同向**
   （高小盘拥挤 → 后市走弱），但严格说先验与检验统计量不在同一目标上——只入档，双侧检验未受影响。
5. **⑦A 阶梯信号的秩结构**：季度台阶 + 非重叠采样 → 同一台阶内多个块共享同值（大量并列秩），
   Spearman 用平均秩处理；k=60 档一个台阶只覆盖 ~1 个块，独立信息量再打折。
6. **⑦A val/holdout 仓位恒 −1**（§2 已述）：expanding 分位对"屡创新高"序列天然饱和
   （2020 后 A2 分位长期 >0.9），单边语义的字面代价在 holdout 段净 Sharpe −0.97 里全额显形。
   这是预登记口径的如实执行，不是实现错误。
7. **偏离 C 的残留 look-through**：2020Q1 生效日时窗内 2019Q4 终值实际披露 70.7%
   （8 天后达 95%），单期单值；且 2019Q4 台阶从不显示。幅度不足以影响任何判读。
8. **`885000.WI` 是 Wind 基金指数**：净值口径含费后收益、成分随发行季变动——β 的"整体
   小盘暴露"读数继承该指数的构造口径，未做（也无法做）基金层加总的独立复核。
9. **`max_abs_diff_rebuilt_ew_vs_production_csv = 5.0e-05`**：diagnostics 用的四对信号
   由冻结根重建，与 committed 生产 CSV 的逐日最大差 5e-5（CSV 落盘精度位），与 ② 正式跑
   同量级，非本探针新增噪声。
10. **既有怪癖原样保留**：`engine.py` `shift(1)`（T 收盘成交文档债）、首日成本落第二天、
    blend carry 缺腿按 0 且止于 2026-04-29（只影响 holdout 报告段）——与历次探针同款，闸门不受染。
