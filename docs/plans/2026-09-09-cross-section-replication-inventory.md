## 0. 四条线的共同事实（读盘点前必知）

- **目标都是 blend**（000905.SH + 000852.SH 现货日收益等权，long-flat），**没有一条是风格价差择时**。
  风格四对（000918/919、H30351/352、932406/407、932408/409）只以「现役 equal_weight 控制变量」身份出现。
  → 把构造套到风格价差上是**新命题**，不是复制。目标侧的复制对象只能是同类宽基（000300 / 932000 / 000985）。
- 目标侧宽基彼此高度相关（同一市场 beta），复制到 300/2000 上对「选优膨胀」有效、对「regime 运气」无效。
  **输入侧换品种**（IH/IF、HO、科创腿）才是更独立的证据，但要先量输入序列与原序列的相关（隐波实测 IO/MO 0.837，等于同一读数）。
- 关 0 口径按 `2026-09-03-gate0-criterion-argument.md` 默认 min-P；复制对象无选优史时 min-P 直接是正式口径。

## 2. 复制设计的硬规则（进预登记）

1. 复制对象、构造、代表参数、方向、k 档全部冻结自原线，**不重新选优**；关 0 退化为该对象上的单检验（min-P 口径记录但无网格时等于普通 p）。
2. **先做独立性预检**（不看目标）：复制输入序列与原输入序列的相关 > 0.8 → 不算独立证据，只能记「同读数」。
3. 过线规则：**复制对象过半同向且 p 过线**才算过；一个对象过不算。
4. 目标侧复制（300/2000/全指）只能作辅助，主证据必须来自输入侧换品种或未触碰历史段。

## 3. 建议顺序

① 基差 T1/T2 → IH 复制 + IF 2014-01..2015-04 段（需用户先改 C1/基差登记表的 reopen_condition）
② F1 → 科创腿输入 + 300/2000 目标（辅助）
③ 隐波 → 先算 HO 与 IO 的相关，>0.8 直接关
④ 股息 → 不建议动；历史段 18 窗无功效
