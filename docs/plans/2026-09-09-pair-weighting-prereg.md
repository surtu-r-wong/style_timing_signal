# 四对合成层权重网格·预登记（2026-09-09，**用户裁「测一下」即冻结；跑前未改**）

## 0. 立项与披露
用户提议合成层有空间。摸底 `2026-09-09-pair-weighting-scoping.md` 已看过 14 种结构替代（等权第一）；本预登记在其后冻结，读数已披露。
先验：四对相关 0.6~0.8、单腿质量相近 → 等权≈最小方差解，**事前预期不过**；价值在关帐。

## 1. 命题
四对 tanh 信号的**静态权重**中，是否存在一组在选优校正后仍显著优于等权、且收益层达到替换门槛的配置。

## 2. 构造（冻结）
- 输入：生产文件 `equal_weight_signal_20d40z.csv` 的 `pair_01..04_factor_20`（四对各自 z→tanh 后信号，与现役同源）。
- 网格：每对权重 ∈ {0, 1, 2}，去全零，按比例去重（(1,1,1,1)≡(2,2,2,2)）→ 约 65 个变体，含现役 (1,1,1,1) 与去一对、固定倾斜等。
- 合成：加权平均 → 5 日均值平滑（同现役）→ 对称符号映射。
- 秤：blend 现货，k=20 非重叠 Spearman IC（与全部族探针同口径）；收益层用同秤日频对称引擎（T+1、3 bps、含贴水）。

## 3. 统计量、零分布与判据（冻结）
- **统计量** = Δ|IC| = |IC(变体)| − |IC(等权)|，全窗；选优 = argmax（**真实规则即 argmax，无错配**）。
- 零分布：循环移位（[2k, n−2k]，B=1000，seed 0），四对信号**同一移位**后重新合成——保留四对间相依结构，只打断与收益的配对。
- **关 0 口径：min-P（默认）**，同时报 max-T。变体间有效样本量同质（同 k），两口径预期接近。
- **PASS** = 赢家 min-P 校正 p < 0.05 **且** 赢家同秤对称 worst(train 2015-20, val 2021-23) Sharpe ≥ 等权 + 0.10（③(f) 替换门槛）。否则 STOP，等权维持。
- 只报不闸：全部变体的对称 Sharpe/回撤/换手；赢家在 holdout 2024-26 的读数。

## 4. 功效边界
Δ|IC| 的零分布由 65 变体最大值标定；n≈150 窗。等权 |IC| 约 0.19；能检出的 Δ 约 ≥ 0.08。
