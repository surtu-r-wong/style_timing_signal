## 1. 机器做什么、不做什么

### 做

给定（**变体网格**、**每变体的评价函数**、**选优规则**、**观测统计量**），
对每个置换样本**重跑整套选优**，取"当选统计量"的空分布，对观测赢家给出**选择校正后的 p**。
argmax 选优时这就是标准的 **max-statistic**（White's Reality Check / Westfall–Young 家族）。

同一次运行还免费给出：
- `p_min_p`：Westfall–Young **min-P** 备用口径（各变体零分布尺度不齐时比 max 更有功效）；
- `p_naive`：**旧做法的现场对照**（只对赢家算 p）+ `selection_inflation` = 两者之比；
- `null_winner_counts`：每个变体在空分布下当选的次数（网格"有效宽度"的诊断）。

### 不做（写死，防止越界引用）

- **不做多重比较之外的任何校正**。窗口消耗（C2）、PIT（勘误 §1）、
  "替换命题要过同秤头对头"（C5）都不在它管辖内——过了这台机器不等于过了那些闸门。
- **不替代"独立确认窗"分支**。勘误 §4 原文是"改造置换过程**或**用独立确认窗"，
  二选一；本机器只把第一支付清（见 §5）。
- **不出裁决**。`backtest/output/selection_permutation_demo.csv` 是机器演示产物，
  **不构成任何轴的 PASS/STOP，不进任何裁决表**；CLI 前后各打一条横幅提醒。
- **不改任何既有模块**：`significance.py` / `scan.py` / `momentum_scan.py` /
  五探针 / 冻结根（`signals/ selection/ research/ factors/ stock_selector/data/`）**零改动**。

## 2. 修的是哪个缺陷

**旧做法**（rotation / leverage / thermo / long_axes / erp 五探针，勘误 §4 已核实）：

```
① 在 J 点网格上算统计量 → ② 选出赢家 ĵ → ③ 只对 ĵ 跑置换，得 p
```

③ 的零分布是"**单个固定变体**的统计量分布"，而观测值是"**J 个变体里最极端的那个**"。
两者不同分布 → p 系统性偏小。偏多少取决于网格的有效宽度：本文档 §4 实测
**假阳率 ÷ 名义 5%** = 4 点 1.3×、16 点 4.1×、40 点 **8.7×**。
（§4 表里的"膨胀"列用的是**另一个分母**——naive ÷ 同行的校正实测值；
两种折算并存是有意的：本节要的是"比名义水平糟多少"，§4 表要的是"同一次实验里两条路差多少"。
每处都已标注分母，引用时请连分母一起引。）

**新做法**：

```
对 b = 1..B：  用第 b 个置换样本 → 重算全网格 J 个统计量 → 套用同一条选优规则 → 记下当选统计量
p = #{当选统计量(含观测行) ≥ 观测当选值} / (B+1)
```

选择效应被吃进零分布里：零分布本身就是"从 J 个里挑最好的"，与观测同秤。

### 关键实现口径：置换只重排配对，不重算因子

"重跑整套选优" = 每个置换样本下**重算全网格统计量并重新选优**；
但**变体构造本身不依赖置换**——所有变体都是同一段价格历史的确定性函数，
置换只打断"信号 ↔ 收益"的时间配对。所以：

- 因子只算一次（40 点网格实测 73 s），置换只重排已算好的信号数组；
- 运行成本 = 原来的 × 网格点数（这正是各候选"**预登记不扩网格**"的第二个理由）。

**前提与例外**：循环移位与因果滚动变换只在**环形平稳**近似下精确可交换
（移位后的绕接点处，滚动窗口跨越了序列首尾）。本仓 n≈3,065 交易日、lookback≤60，
边缘污染 ≤2%；§4 的"因果滚动变体"判例把这一近似的代价量化了（校正 p 仍守在 4.0%）。
若某探针的**变体构造本身依赖收益**（例如按收益分箱建的状态变量，候选 ④ 要小心），
必须走更贵的分支：把 `stat_fn` 写成"用重排后的输入**重建变体**再评分"——
API 原生支持，代价是因子重算 × n_perm。

## 3. API 用法

### 契约

| 回调 | 签名 | 约定 |
|---|---|---|
| `stat_fn` | `(variant, idx) -> float` | `idx` = 长度 n_obs 的重抽样索引；观测样本的 idx = `arange(n_obs)`。统计量**越大越好**（双侧口径自行返回 `|IC|`）；**该行无法评分**（样本不足/NaN）返回 `-inf`，⚠️ 但独立闸门不得塞进 `-inf`，见 §9 第 11 条边界 |
| `batch_stat_fn` | `(variant, idx_matrix) -> ndarray(m,)` | 可选，纯提速：一次算完某变体在全部重抽样下的统计量 |
| `select_fn` | `(stats) -> int` | 选优规则，默认 `argmax`；返回 −1 = 本行无可行变体。**观测行与每个置换行走同一条规则** |

置换方案：`scheme="rotation"`（默认，循环移位，与 `rotation_probe` 同口径；
IC 类统计量建议 `min_shift=2*max(k)`）/ `scheme="block"`（重叠块重抽样，
观测行与置换行**不精确可交换**，**仅作敏感性对照**）。

### 最小例子

```python
from backtest.selection_permutation import selection_permutation_test, make_stat_fn

signals = {v: build_signal(v) for v in grid}      # 因子只算一次
def score(vals, variant):                          # vals = 重排后的信号数组
    return abs(nonoverlap_ic(pd.Series(vals, index=dates), ret, k=variant["k"]))

res = selection_permutation_test(
    list(signals), n_obs=len(dates),
    stat_fn=make_stat_fn(signals, score),
    n_perm=1000, seed=0, scheme="rotation", min_shift=2 * max_k,
    statistic_name="abs_nonoverlap_ic",
)
res.p_selected   # ← 裁决用这个
res.p_naive      # ← 旧做法，只作对照，不得进闸门
```

### 三个 p 的取用纪律

- **`p_selected` = 主口径**，闸门只读它；
- **`p_min_p` = 备用口径**，当各变体零分布**尺度不齐**（例如统计量不是尺度不变量，
  或各变体有效样本量差很多）时改用它，**并在探针文档里写明为什么换**；
  ⚠️ min-P 的分辨率受 B 限制，**J 大时须 B ≫ J**（实测 J=40：B=199 过保守到 0.3~2.5%，
  B=999 回到名义 5.8%）；
- **`p_naive` = 对照量**，只准出现在"机器修好了"的证据段，**任何闸门都不得读它**。

## 4. 校准证据

合成设定：n=512；源序列 = 白噪声经**环形**移动平均（保证循环移位下精确可交换）；
网格 = 近似真实 lb×zw 的带通变换族（同尺度高相关、跨尺度低相关）；
统计量 = Pearson 相关（单侧，越大越好）；B=199；全部固定 seed（判例确定性）。

### (a) 合成 null：校正 p 近均匀，旧做法系统性偏小

| 网格点数 J | 重复 R | **校正 p ≤.05** | min-P ≤.05 | **naive p ≤.05** | 膨胀（naive÷校正） | KS(校正) | KS(naive) |
|---|---|---|---|---|---|---|---|
| 4 | 200 | 2.5% | 3.0% | 6.5% | 2.6× | 0.050 | 0.210 |
| 8 | 300 | 3.7% | 3.3% | 11.3% | 3.1× | 0.048 | 0.305 |
| **16** | 300 | **4.7%** | 3.3% | **20.3%** | **4.3×** | **0.052** | 0.485 |
| 40 | 300 | 3.7% | 0.3%※ | **35.0%** | **9.5×** | 0.047 | 0.638 |
| 40 | 200 | 3.0% | 2.5%※ | 43.5% | 14.5× | 0.085 | — |
| **40（B=999, 加跑复核）** | **400** | **5.0%** | **5.8%** | **39.3%** | **7.9×** | **0.038** | — |

- 名义水平 5%。KS 的 α=0.01 临界 = 1.63/√R（R=300 → 0.094；R=200 → 0.115；R=400 → 0.082）——
  **校正 p 全部远过关，naive p 全部远不过关**。
- ※ min-P 在 **B=199、J=40** 时因 p 值离散化而过保守（0.3~2.5%）；末行把 B 提到 999 后
  回到名义水平（5.8%），证明这是**分辨率**问题而非偏倚。见 §3 的取用纪律。
- 末行（J=40、B=999、R=400、独立 seed）是**主口径最强的一条证据**：
  校正 p 在名义 5% 处实测 **5.0%**，KS 0.038 < 临界 0.082。
- 判例：`test_null_max_statistic_is_uniform_and_naive_p_is_inflated`、
  `test_naive_inflation_grows_with_grid_size`。

### (b) 因果滚动变体（真实探针的形态，非环形）

| 设定 | 校正 p ≤.05 | KS(校正) | naive p ≤.05 |
|---|---|---|---|
| J=16, R=200, 因果 rolling | **4.0%** | 0.060 | 15.0% |

环形近似的代价可忽略。判例：`test_null_calibration_survives_causal_rolling_variants`。

### (c) 合成强/弱效应：功效未被摧毁

| 效应强度 | R | **校正 p ≤.05** | 校正 p 中位数 | min-P ≤.05 | naive ≤.05 |
|---|---|---|---|---|---|
| 0.30（强） | 60 | **100%** | 0.0050 | 100% | 100% |
| 0.12（弱） | 60 | **81.7%** | 0.0150 | 85.0% | 95.0% |

判例：`test_power_survives_correction`、`test_weak_effect_correction_costs_power_but_stays_directional`。

### (d) 退化与口径一致性

| 判例 | 断言 |
|---|---|
| `test_single_variant_grid_collapses_to_plain_permutation` | J=1 时 `p_selected == p_naive == p_min_p`，`selection_inflation == 1.0` |
| `test_matches_rotation_probe_shift_permutation_pvalue_exactly` | 单变体 + `min_shift=2k` → 与 `rotation_probe.shift_permutation_pvalue` **`==`**（不是近似） |
| `test_matches_significance_bootstrap_pvalue_exactly` | 单变体 + 默认移位区间 → 与 `significance.bootstrap_pvalue` **`==`** |
| `test_moving_block_index_matrix_matches_paired_bootstrap` | 块采样器与 `paired_bootstrap.moving_block_indices` 逐元素相同。⚠️ **此条只保证"副本保真"**（本模块的块采样器是那个函数的独立副本），**不构成对块重抽样口径本身的校准证据**；若 `paired_bootstrap` 那侧改了语义，两边会静默漂移，这条判例是唯一守卫 |
| `test_batch_and_scalar_paths_agree` | 提速路径与朴素路径 `allclose(atol=1e-12)` |
| `test_observed_row_goes_through_identity_index` | 观测行确实走 `arange(n)` 这条同款代码路径 |

精确一致的机制：numpy `Generator` 的批量 `integers(lo, hi, size=B)` 与逐次调用是**同一条流**
（`test_rotation_shift_stream_matches_sequential_house_convention` 钉死），
且 `x[idx[b]] == np.roll(x, shift_b)` 按构造成立。

## 6. ②/①b/④/⑤ 接入清单

通用三步：① 一次性算出全网格变体信号（`dict[variant] -> np.ndarray`，同一条时间索引）；
② 写 `score(重排后的信号, variant) -> float`（越大越好，不可行返回 `-inf`）；
③ 调 `selection_permutation_test`，闸门读 `p_selected`。

| 候选 | 网格 | variant 定义 | 统计量（`score`） | 移位区间 | 预计 wall（n_perm=1000） |
|---|---|---|---|---|---|
| **②** 四对分歧度/离散度 | **48 点合成一次调用**：3 族 D1/D2/D3 × lb∈{5,20} × zw∈{60,250} × k∈{5,10,20,40} | `(family, lb, zw, k)` | `abs(nonoverlap_ic)`；关1b 的偏 IC（控 ew）另跑一次同款机器 | `min_shift = 2·max(k) = 80`，`max_shift = n_obs − 2·max(k)` | **≈231 s**（仅 IC，48×1001×4.8 ms）；IC+偏 IC ≈ **690 s** |
| **①b** 32 点映射网格 | 32 点：θ_L 4 × h 2 × w_S 4 | `(theta_L, h, w_S)` | 同秤净 Sharpe 或 worst(train,val)（映射改的是仓位，不是因子） | `min_shift=1`（无前瞻窗），`max_shift` 用默认 n_obs | ≈ **300 s**（按 demo 的 10.1 ms/评价折算） |
| **④** 条件化有效性 | 状态变量 × 分箱 | `(state_var, bin_rule)` | 交互项统计量 | 同 ②（按最大前瞻窗定 `2k`） | ⚠️ **若状态变量的构造依赖收益，必须走"重建变体"贵分支**（§2 末段） |
| **⑤** 配对集合 + 红利腿 | 4 个集合（若逐窗判 GO 则窗也进网格） | `(pair_set,)` 或 `(pair_set, window)` | 集合层 IC / Sharpe | `min_shift = 2k` | 秒级（J=4） |

### ⚠️ 族级多重比较：机器只校正**单次调用内**的选择

**这是 ② 最容易漏的地方，也正是 ⓪ 要堵的模式本身。** ② 是 **16 点 × 3 族且逐族判 GO**——
若按族分 3 次调用，每次内部校正得再干净，**3 次独立的 PASS 机会仍未被校正**，
等于把"先选优再算 p"从变体层搬到了族层。必须二选一，且**必居其一**：

| 方案 | 做法 | 代价 | 评价 |
|---|---|---|---|
| **A（推荐）48 点合成一次调用** | 三族的 48 个变体装进**同一个** `variants` 列表（`variant` 是不透明元组，`(family, lb, zw, k)` 直接用，**零新代码**），机器一次给出跨族的当选统计量空分布 | ≈3×72 s ≈ 231 s | 功效更高（自动吸收族间相关），且"哪一族赢"由数据说了算 |
| **B（备选）族级 Bonferroni** | 仍分 3 次调用，但**预登记**族级阈值 α = 0.05/3 = **0.0167** | 同样 3×72 s | 保守（忽略族间相关），但保留"逐族独立立账"的表述习惯 |

**不需要校正的地方**：② 的关1（IC 显著）∧ 关1b（偏 IC 同号显著）是 **AND 合取**——
要求两个条件同时成立，只会让整体假阳率**更低**，**天然保守，不需要再为这两关做多重比较校正**。
同理关2/关3 是附加约束，方向也是收紧。

**共同纪律**：
- 网格点数**按预登记来**，不得因为"机器能算"就扩（成本 × J，且 J 越大功效越低）；
- 一次探针里**所有变体必须共用同一条时间索引**（机器要求 idx 跨变体共享）——
  演示里的做法是取全网格非 NaN 日期的交集（40 点网格因 zw=250 的暖机而损失约 1 年样本，
  这与 `scan.py`"每变体各用各的可用日期"有口径差，见 §7 的对表结果）；
- 探针文档里必须同时报 `p_selected` 与 `p_naive`，让读者看见选择效应有多大。

## 8. 性能实测与预算

单机（本开发机，非 WSL2）：

| 项目 | 实测 |
|---|---|
| 一次全网格选优（40 点，两窗 Sharpe） | **0.40 s**（单点评价 **10.1 ms**） |
| 40 点因子一次性构建（含取数） | 73 s（**只做一次**，与 n_perm 无关） |
| **40 点 × n_perm=1000 端到端** | **370 s（6.2 min）** |
| 峰值内存（机器本体，J=40 / n_perm=1000 / n=3065） | **119 MiB** |
| 单点 `nonoverlap_ic`（n=3065） | 4.3~5.3 ms |
| 单点 `partial_rank_ic`（同上） | 9.1~11.2 ms |
| **② 预计（48 点合成一次调用 × n_perm=1000）** | **≈231 s**（仅 IC）／ **≈690 s**（IC + 偏 IC 各跑一次） |

内存构成：索引矩阵 2 份 × (1001 × 3065) int32 ≈ 25 MiB，其余是 numpy/pandas 基线。
**结论：任务书设的"预计 >1 小时或 >2 GiB 就停下汇报"的门槛没有触及**，
本机直接跑即可，无需投 WSL2。

## 9. 实现自由度（一次选定，逐条列清）

| # | 自由度 | 选定 | 理由 |
|---|---|---|---|
| 1 | 新模块 vs 就地改 | **新模块** `backtest/selection_permutation.py` | 任务书硬约束；既有探针零改动 |
| 2 | 置换作用对象 | **重排"已算好的变体信号"**，不重算因子 | 数学等价（变体不依赖置换）。**真正省下的是"因子构造"这一项：J·B 次 → J 次**——40 点网格实测构建一次 73 s，若每个置换都重建则 40×1001 次构建，折算 **≈20 小时**；评分那一项（J·B 次）省不掉，也不该省。贵分支仍由 API 支持 |
| 3 | 默认置换方案 | **循环移位**（`rotation`） | 与 `rotation_probe` 先例对齐、比 iid 保守、环形平稳下精确可交换 |
| 4 | 块重抽样地位 | **仅敏感性对照** | 有放回抽样使观测行与置换行不精确可交换 → 只近似校准 |
| 5 | 观测行怎么算 | **并入池首、走 identity idx** 同一条代码路径 | 可交换性的前提；顺带杜绝观测/置换两条路径的口径漂移 |
| 6 | p 的分母 | `count/(B+1)`，观测行计入 | 与 `rotation_probe` / `significance` 房规逐字一致 → 能做 `==` 判例 |
| 7 | 主口径 | **`p_selected`（当选统计量）** | argmax 时即 max-statistic，功效优于 Bonferroni，且天然吸收变体间相关 |
| 8 | 是否同时给 min-P | **给，标为备用** | 尺度不齐时 max 会被高方差变体霸占；但离散度受 B 限制，需 B ≫ J |
| 9 | 是否同时给 naive p | **给，且显式命名 `p_naive_UNCORRECTED`** | 每次运行自带"机器修好了"的现场对照；命名本身阻止误用 |
| 10 | 统计量方向约定 | **越大越好**（双侧自行取 `abs`） | 让 `argmax` 成为默认选优规则，API 面最小 |
| 11 | 可行性约束怎么表达 | **不可行 → `-inf`**（而非另开 mask 参数），但**有使用边界，见下** | 直接覆盖 `leverage_probe.pick_representative` 的"同号"规则形态，无需第二个回调 |
| 12 | 选优规则可插拔 | **`select_fn` 可换**（默认 argmax） | ②④⑤ 的规则不一定是 argmax；观测行与置换行强制走同一条 |
| 13 | 提速路径 | **可选 `batch_stat_fn`**，与朴素路径有一致性判例 | 校准测试需要 R×B×J 量级的评价，纯标量路径太慢 |
| 14 | 索引矩阵可注入 | **是**（`index_matrix=`） | 精确一致性判例与复现需要 |
| 15 | 索引 dtype | **int32** | (1001×3065) 从 24 MiB 降到 12 MiB |
| 16 | NaN 统计量 | **转 `-inf`** | 与 `rotation_probe` 的"非有限 ic 不计数"行为一致 |
| 17 | 演示取数路径 | **`_demo_factor_fn`**（`scan.equal_weight_factor_fn` 的同构副本 + `db` 透传） | `scan.py` 的工厂不收 `db`，而演示要走只读备端；因子计算仍走冻结根，零口径漂移 |
| 18 | 演示定位 | **CLI 前后各打横幅 + 列名带 `_UNCORRECTED` + summary sidecar 内嵌横幅** | 防止产物被后人误读成裁决 |

### 第 11 条的使用边界（**别把闸门塞进统计量**）

`-inf` 只保留给一种情形：**该变体在该行根本无法评分**（样本不足、窗口不够、统计量为 NaN）。

**反例（禁止）**：② 的关2 是"两半窗同号"，它**同时是一道独立闸门**。
若把它写进关1 的统计量（不同号 → `-inf`），会同时踩两个坑：

1. **双记**：同一条件既进了关1 的零分布、又作为关2 再判一次，整体假阳率被压得比预登记更紧，
   探针实际执行的已不是预登记的闸门；
2. **p 的含义偏移**：`p_selected` 不再是"最优 IC 有多难靠错配得到"，
   而变成"最优的**同号**IC 有多难得到"——这个量没法跟历史探针的 p 对表，
   也没法跟 §4 的校准证据对表（校准是在无约束 argmax 上做的）。

**正解**：关1 用**无约束**的统计量跑机器拿 `p_selected`，关2 作为**独立的后置判据**照常判。
`leverage_probe.pick_representative` 那种"同号"写法之所以能用 `-inf`，
是因为在那里同号是**选择规则的一部分**（gate2 直接复用选择结果 `sign_ok`），
不是一道额外的独立闸门——形似而实质不同，接入时必须先分清自己属于哪一种。

## 10. 已知限制

1. **环形绕接近似**：循环移位对因果滚动变换只是近似可交换——每个置换样本在绕接点附近，
   滚动窗口会跨越序列首尾。**污染长度 = 变体的记忆长度**，本演示最深的变体是
   `zw250 + lb60 + sm5 = 315 日 = n(3065) 的 10.3%`。
   实测代价：§4(b) 的因果 rolling 判例在同等比例下校正 p 仍是 **4.0%**、KS 0.060。
   ⚠️ **判据不是"记忆长度 / n < 1/10"**（本演示自己就是 10.3%，那样写会把自己标红）；
   判据是：**(a) 记忆长度 ≪ 样本长度**（经验上 ≲1/3）**且 (b) 用 §4(b) 那类因果判例实测校准**。
   记忆长度逼近样本的 1/3、或序列有强趋势/水平漂移使首尾拼接产生突变时，
   改用块重抽样并声明其近似性。
2. **校准证据的数据源都是平稳序列**（与第 1 条并列，是另一个前提）：§4 的合成 null
   一律是白噪声经环形/因果平滑，**平稳性由构造保证**。真实的风格价差、宏观状态变量
   可能有水平漂移或结构断点，循环移位在那些序列上的可交换性只是近似——
   本模块**没有**在非平稳真实序列上做过校准实测。接入时若序列明显非平稳，
   须补一条敏感性对照（block 支路）并在探针文档里报告两者差异。
3. **min-P 的分辨率**：J 大而 B 小时过保守（J=40/B=199 实测 0.3~2.5%；B=999 回到 5.8%）。
   用 min-P 请 B ≥ ~20×J。主口径 `p_selected` 无此问题。
4. **块重抽样支路：未做校准实测**。目前只有机制判例与确定性判例
   （`test_block_scheme_runs_and_is_deterministic`）+ 与 `paired_bootstrap` 的副本保真判例，
   **没有跑过 §4 那样的 null 均匀性实验**。理论上它也不精确可交换（有放回抽样改变信号成分）。
   → **不得当主口径**；要当主口径必须先补校准实验。
5. **`argmax` 并列取首下标**：`null_winner_counts` 这个**诊断**列在统计量大量并列时会略偏网格前部。
   **不影响任何 p**（p 只看当选统计量的值，与并列时挑了谁无关）。
6. **共用时间索引的代价**：全网格取交集会按最长暖机窗截头（40 点网格损失约 1 年）。
   这是"跨变体共享同一置换"的必要代价，探针文档须写明样本区间。
   ⚠️ 反过来，**跨变体共享同一次移位是不可退让的**：若逐变体独立抽移位，
   变体间相关结构被打散、空分布被人为撑宽，校准立刻崩（QA 反事实实测：KS 0.49、空分布宽 38%）。
7. **机器只管多重比较**：不解决 PIT、窗口消耗、头对头同秤等任何其他闸门。
8. **演示依赖库连通**：主库 Debian `100.65.111.79:5432` 本次 **Connection refused**，
   演示改走只读备端 Pi5 `100.75.102.44`（`index_daily` max = 2026-08-11，只读单查询、带超时）。
   这是**环境事实的留痕**，不是本候选的开放项。
