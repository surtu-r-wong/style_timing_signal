## 2. 机器复现校验

V0 max-T 与登记 p **逐位相同**：基差三族、分析师四族、资金流两族。创新高 N1（0.847 vs 0.842）与隐波 O2（0.273 vs 0.255）
差在评窗多了一天（blend 收益 09-03 补跑后延到 2026-09-01，原跑到 08-31；n_obs 2879 vs 2878、1603 vs 1602），
移位流随 n 变，属预期内的重抽样差异，不是机器差异。资金流 V1 的网格赢家恰是登记的代表 `F1_lb5zw250 k=20`（obs 0.263 = 两半窗 0.344/0.263 的较小者），
证明 V1 的统计量确实复现了 `pick_representative`。

## 3. 三条结论

1. **零分布选优规则错配是真的，但修正后没有改变任何裁决。** F1 从 0.221 降到 0.059/0.071，是错配影响最大的一例，仍差一步；
   其余族代表要么本来就远、要么在真实规则下反而更差（T2 0.162→0.431：它的最差半窗 0.140 很小）。
2. **min-P 对族代表本身普遍不比 max-T 松。** 09-03 论证的功效优势是对"落在低噪声档的真效应"而言；这些代表大多在 k=40（最吵档），
   min-P 在那里本就弱于 max-T（0.374 vs 0.103、0.755 vs 0.273）。口径论证仍成立，但它救不了这批候选。
3. **在位者审计更正**：09-03 写"同一条现役信号 min-P 0.013 显著"，那是网格赢家 lb20zw40 **k=10** 的数。
   部署点 k=20 自己的单步 min-P 校正 p 是 **0.155**，真实规则下 0.131，都不显著。"关 0 拦在位者"仍成立，"换口径就翻"说重了。
