### 8.0 结论先行

1. **STOP 于闸门 ⓪，而不是被前置闸挡下。** E 在 **train 与 val 双窗 rank IC 均高于 A**
   （train **0.2071 vs 0.2007**、val **0.3862 vs 0.3575**）——双窗条件**通过**；
   但配对 IC 差在**五个窗全部不排除 0**（train +0.0064 p=0.831 / val +0.0287 p=0.389 /
   选择窗 +0.0035 p=0.881 / holdout +0.0121 p=0.704 / full +0.0124 p=0.522）→
   按预登记读法"明确优于而非平手"不成立，⓪ 不过。

   > **⚠️ 引用纪律（防误引用，逐条钉死）**：
   > - 本次证明的是 **E 在预登记那杆秤上没有可判定的增量**，**不是**"红利腿被证明无价值"。
   >   增量的**点估计五窗全为正**，只是全部落在噪声带内。
   > - 也**不是**"红利腿有价值只是样本不够"。功效不足与效应为零在本数据上**不可分**
   >   （val 窗只有 37 个非重叠样本点，见 §8.7 边缘读法 2）。正确写法是
   >   **「在预登记秤上无可判定增量」**，句号。
   > - 模式与 Batch 11 的 B（500+1000+2000）**同款**：弱高、五窗同向、CI 全不排除 0。
   >   E 是 ⑤ 家族**第二个**通过"双窗 IC 均高于现役"这一条的挑战者（B 已通过过，
   >   Batch 11 §3.3），**不是第一个**——任何"首次"的措辞都是误记。

2. **前置诊断闸这次量对了东西**（这是本批次相对 Batch 11 的核心增量）。
   max\|corr\| = **0.5575**（阈值 0.9）→ 同源判定 False，闸放行。

   相对收益 = 分红计提，corr 天然近 0（"闸没坏、入参不对"）；本次两腿是**两条不同指数**
   （日收益 corr **0.8484**、净值比年化漂移 **+1.54%**、相对收益 \|·\|>50bp 的天数占比

→ **这是"稀释"不是"符号反了"**：红利腿没有给出错误方向的看多信号，它只是在那段时间
**不表态**，而等权平均对"不表态的腿"的惩罚就是把有表态的四腿摊薄。经济上完全合理，
也正是"加腿"这个动作的固有代价（同样的稀释在 Batch 11 的 D 上以更极端的形式出现过）。
**实现无异常。**

2. **E 的选择窗换手 10.267050 与 Batch 11 的 D / D_rev 跨批次完全相同**（三者都是
   10.267050）。核实：三个构造在选择窗都恰好翻仓 **102 次**，而
   `metrics.turnover = Σ|Δpos| / n × 245` 在 long-flat {0,1} 下**就是翻仓次数的线性函数**
   （102 × 245 / 2434 = 10.267050），所以次数撞车 ⇒ 换手逐位相同。三者的 `worst_tv`
   **各不相同**（D 0.7463 / D_rev 0.9513 / **E 1.1032**），确认是**指标退化**而非同一构造。

> **由此还得到一条对判据②的诚实限定**：判据②"换手不增"在本口径下等价于**翻仓次数**比较，
> E 过关的实质是 **102 次 vs A 的 104 次 —— 少翻了 2 次**。这是本次唯一过关的判据，
> 但它的**分辨力就是这么粗**，不宜被当成"E 在交易成本上明显更优"的证据。

### 8.7 边缘读法（诚实列出，供 QA 攻击）

> **本节含一次性诊断读数**（分段 corr / 红利腿单腿指标 / 符号检验 / 门槛敏感性算术），
> **不入产物、重跑模块不产生**。QA 已逐条独立复算对上。

1. **val 窗 diff +0.0287 在更宽的 α 下会不会显著？不会。** p = **0.389** → 需要
   α ≈ 0.39 才能排除 0；90% 区间约为 d̂ ± 1.645·boot_sd = +0.0287 ± 0.0574 =
   **[−0.029, +0.086]**，仍含 0。**任何常规显著性尺度下都不显著。**
   （单候选已经用了最宽松的 α=0.05、无 Bonferroni——这条路已经走到头了。）
2. **"五窗 diff 全为正"看起来像弱证据，但不是五份独立证据。** 五个窗**互相嵌套**：
   选择窗 = train + val，full = 选择窗 + holdout。真正互不重叠的只有 **train / val /
   holdout 三段**，符号一致性在嵌套窗上是**几乎自动**的。
   把证据量算清楚：三个互不重叠段**同号**，符号检验的**单侧 p = 1/2³ = 0.125**——
   **是弱证据，不是"零证据"**，但**远不到常规显著**（且这三段各自的配对差 CI 全部含 0，
   p = 0.831 / 0.389 / 0.704）。诚实的写法是"方向一致但量级不可判定"，
   既不能说成"没有任何迹象"，也不能说成"多窗一致所以可信"。
3. **holdout 的方向与"秩序轴弱优势"相反。** E 的 holdout 净 Sharpe **1.6258 vs A 1.8589**
   （低 0.233），MaxDD −17.1% vs −16.7%，剔最强年 0.813 vs 1.138 —— 三项都更差，
   尽管 E 在 holdout 的 rank IC 更高（0.2306 vs 0.2185）。
   → **秩序上的弱优势没有兑现成收益**；holdout 不进闸门，此处列出只为不藏数据。
4. **MaxDD 恶化与"红利腿是 2021-2024 最大风格分散来源"这条先验直接冲突**
   **（MaxDD 是非预登记闸门的事后诊断量；方向相反时不得反向引用）**。两条实测：
   (i) 红利腿**单腿** long-flat 在选择窗的净 Sharpe 只有 **0.6538**、MaxDD **−30.8%**
   ——它自己就是一条又弱又深回撤的择时腿；
   (ii) 它与现役族的相关性**在 val 段（2021-2023）升到 max\|corr\| = 0.8178**、
   2021-2024 段 0.7807（全样本 0.5575，见 §8.3 分段表）——
   **在最被期待提供分散的那几年，它反而与现役最同向。**
   → 先验在数据上不成立；"加红利腿 = 加分散"这个直觉本批次未获支持。
5. **三个挑战者 margin 扎堆（+0.0975 / +0.0902 / +0.1022）不是"都差一点"**，
   见 §8.0 结论 3：`worst` 只看短板，而 A 的短板（val 1.0009）远低于自身 train（1.7053），
   三个候选的 val 值又本就扎堆 → 同一个分母效应的三次显影。
   **门槛敏感性（须精确陈述）**：E 的 margin = **+0.10224582**，
   所以把 +0.15 换成 **+0.10 时判据①恰好过关**（**这一点与 Batch 11 的 B +0.0975 /
   C +0.0902 不同**——那两个在 +0.10 下仍不过）。但**裁决依然不变**：
   **闸门 ⓪ 在任何读法下都不过**（判据顺序上它就在收益层之前），
   **判据③（剔最强年 1.0273 vs 1.2365）独立杀死它**。
   → **裁决对门槛不敏感，但理由是 ⓪ 与 ③，不是判据①**。
   任何"降门槛就能过"的说法必须同时说明它只影响①这一条。
6. **闸门 ⓪ 读法敏感性**：若把 ⓪ 弱化成"只要双窗 IC 都高于现役"（去掉 CI 条款），
   **E 会过 ⓪**——但随后被收益层判据①③**全部**挡下，**最终裁决不变**。
   这与 Batch 11 对 B 的结论结构完全一致。
7. **前瞻收益的窗口边界**（沿用 `fusion_probe` 口径）：val 窗最后 1 个非重叠样本点的
   前瞻收益落在 2024 年初。影响面 = 每窗至多 1 个观测，且**两个集合共用同一张网格**
   → 头对头比较不受影响。
8. **carry 样本边界**：blend carry 止于 2026-04-29，其后评估段无 carry 输入（对多头略偏悲观）。
   四条判据**全部落在 2014-2023 选择窗**，不受影响；受影响的只有 holdout / full 两个**仅报告**窗。
