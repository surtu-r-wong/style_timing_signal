# 关 0 口径论证：默认改用 min-P，max-T 退为例外

2026-09-03。机器 `backtest/gate0_criterion_study.py`，产物 `backtest/output/gate0_criterion_study.json`。

**结论（供后续预登记引用）**：

> 关 0 的默认口径为 **Westfall–Young min-P（`p_min_p`）**。依据：两个独立真实网格上，
> min-P 的检验水平准确（α=0.05 实测 0.050 / 0.040），而 max-T 对落在低噪声档的真效应
> **功效等于零假设本底**（k=5 档 δ≤0.15 时检出率恒为 0.050）。
> 只有当网格内各变体的**有效样本量相当**（同质），或有先验认为真效应就落在方差最大的那一类变体上时，
> 才用 max-T（`p_selected`）。**预登记 §3 必须写明选了哪个口径、依据是什么**，不得沿用默认而不论证。

## 0. 为什么要论证这件事

资金流面 F1 三关全过、只败在关 0（|IC| 0.2599 vs 门槛 0.337）。
在位者审计（`2026-09-03-gate0-incumbent-audit.md`）发现**现役 equal_weight 信号在自己网格上也过不了**
（|IC| 0.1948 vs 门槛 0.2823），且同一条现役信号 `p_selected` = 0.293 不显著、`p_min_p` = 0.013 显著。

**但"在位者也过不了"不能直接推出"该换口径"**——那只说明门槛高，不说明高得没道理。
换口径必须先证明新口径的**检验水平是对的**，否则只是把门槛调松、把假阳率放回去。本文补的就是这一步。

## 1. 方法：用真实联合零分布做水平与功效研究

`selection_permutation_test` 的 `null_stats` 是 (B, J) 的置换统计量矩阵——**B 次对真实联合零分布的抽样**，
保留了变体间真实的相依结构（4 个形态高度相关；4 个 k 的非重叠窗口数 542/270/134/66，噪声水平差 3 倍）。

- **水平**：置换行在零假设下可交换 → 任取一行当「观测」、其余当参照算 p，该 p 在零假设下应服从均匀分布。
  测 P(p ≤ α) 是否等于 α。**直接测假阳率，不依赖任何合成数据的分布假设。**
- **功效**：把某一档 k 的各列整体抬高 δ（位置移动型备择：真效应叠加在同一份噪声上），
  对未改动的参照算 p，测检出率。分别把效应放在四个 k 上。

两个 p 的公式逐字复用 `selection_permutation.column_pvalues` 的房规，与生产口径同源。

## 2. 水平：两个口径都是有效检验（换口径的前提成立）

两个独立网格，B=1000：

| 网格 | α=0.05 max-T | α=0.05 min-P | α=0.10 max-T | α=0.10 min-P |
|---|---|---|---|---|
| 资金流面（32 变体，2,715 日） | **0.050** | **0.050** | 0.100 | 0.089 |
| 现役 equal_weight（16 变体，3,003 日） | **0.050** | **0.040** | 0.100 | 0.100 |

**min-P 的假阳率是对的（准确或略保守），不是把门槛调松。** 前提成立，可以比功效。

## 3. 功效：max-T 对最吵那一档以外的效应几乎是瞎的

### 3.1 资金流面网格（32 变体，2,715 日）

检出率（α=0.05，B=1000；每格 max-T / min-P）：

| δ | 效应在 k=5 | 效应在 k=10 | 效应在 k=20 | 效应在 k=40 |
|---|---|---|---|---|
| 0.02 | 0.050 / 0.116 | 0.050 / 0.087 | 0.050 / 0.069 | 0.073 / 0.055 |
| 0.04 | 0.050 / 0.252 | 0.050 / 0.154 | 0.053 / 0.089 | 0.102 / 0.071 |
| 0.06 | 0.050 / 0.530 | 0.050 / 0.270 | 0.054 / 0.141 | 0.155 / 0.102 |
| 0.08 | 0.050 / 0.833 | 0.050 / 0.466 | 0.061 / 0.230 | 0.219 / 0.138 |
| **0.10** | **0.050 / 0.994** | **0.050 / 0.700** | **0.078 / 0.344** | **0.301 / 0.193** |
| 0.15 | 0.050 / 1.000 | 0.059 / 0.998 | 0.190 / 0.722 | 0.559 / 0.382 |
| 0.20 | 0.056 / 1.000 | 0.182 / 1.000 | 0.503 / 0.980 | 0.811 / 0.653 |

**读法**：0.050 就是零假设本底——等于完全看不见。

- 效应在 **k=5**：max-T 一路到 δ=0.15 都是 0.050，δ=0.20 才动到 0.056。**十个真效应一个都找不出来。**
- 效应在 **k=10**：同样到 δ=0.10 仍是 0.050。
- 效应在 **k=20**（F1 代表与现役信号部署点都在这一档）：δ=0.10 时 0.078 vs 0.344，**差 4.4 倍**。
- 效应在 **k=40**（最吵的一档）：max-T 反超，0.301 vs 0.193。

**max-T 只在效应恰好落在方差最大的那一类变体上时占优，其余全线碾压性落后。**

### 3.2 现役 equal_weight 网格（16 变体，3,003 日）——独立复现

不同信号族、不同变体数、不同评窗，同一形态：

| δ | 效应在 k=5 | 效应在 k=10 | 效应在 k=20 | 效应在 k=40 |
|---|---|---|---|---|
| 0.04 | 0.050 / 0.251 | 0.050 / 0.085 | 0.059 / 0.105 | 0.116 / 0.075 |
| 0.06 | 0.050 / 0.548 | 0.050 / 0.148 | 0.070 / 0.175 | 0.192 / 0.100 |
| 0.08 | 0.050 / 0.842 | 0.059 / 0.300 | 0.092 / 0.269 | 0.261 / 0.137 |
| **0.10** | **0.050 / 0.997** | **0.068 / 0.460** | **0.130 / 0.418** | **0.367 / 0.175** |
| 0.15 | 0.061 / 1.000 | 0.136 / 0.962 | 0.391 / 0.796 | 0.681 / 0.417 |
| 0.20 | 0.208 / 1.000 | 0.495 / 1.000 | 0.751 / 1.000 | 0.921 / 0.726 |

δ=0.10 时的倍数：k=5 **20×**、k=10 **6.8×**、k=20 **3.2×**、k=40 **0.48×**。
变体少（16 vs 32）使门槛降低，故 max-T 在 k=20 上比资金流网格好一些（0.130 vs 0.078），
但方向与量级完全一致：**k=5 仍是完全瞎的，只有 k=40 反超。**

### 3.3 机制

### 3.4 代价不是零

min-P 在 k=40 上损失 36% 相对功效（0.193 vs 0.301 @ δ=0.10）。
它做的是**把检验功效从"方差最大的变体"重新分配给"有效观测数更多的变体"**——
在**不知道真效应落在哪一档**时，这个方向是对的；若确知效应就在最慢/最吵那一档，max-T 才更合适。
这正是「默认 min-P、max-T 退为需论证的例外」这条规则的由来。

## 4. 对已有裁决的影响（不翻案）

**不构成对任何已登记裁决的翻案。** 看过读数再换口径 = 用同一份数据既选规则又下结论。
本文只改变**今后**的预登记默认值。

近期「三关过、只败关 0」的轴有两条，但**只有一条真受影响**：

| 轴 | 日期 | 代表所在档 | 该档 max-T 功效 @δ=0.10 | `p_min_p` | 受影响? |
|---|---|---|---|---|---|
| 股指期权 IV 面 O2 | 2026-08-27 | **k=40**（最吵的一档） | **0.301**（max-T 的最优区） | **0.234 不显著** | **否** |
| 资金流向面 F1 | 2026-09-03 | **k=20** | **0.078** | — | **是** |

**期权面 O2 的 STOP 对口径选择是稳健的**：它的代表恰好落在 k=40，正是 max-T 功效最好的那一档，
且该轴的 `p_min_p` = 0.234 同样不显著——换成 min-P 结论不变。此前把它一并列为"要重看"是我的错，已更正。

**只有资金流面 F1 受影响**：代表在 k=20，max-T 在该档的功效只有 0.078。

处置：按本文口径重做**样本外单点确认**（新数据、同构造、同代表、不重新选优），而不是在旧数据上换口径重算。

## 5. 落到预登记模板的三条

1. **§3 必须写明关 0 口径与依据**。默认 min-P；用 max-T 需给出「网格同质」或「先验效应在最吵类」的论证。
2. **§4 的功效边界必须按实际生效的那道闸算**。资金流面预登记写「可检出 |IC| ≳ 0.16」，
   而真正卡住的是关 0 的 0.337，差两倍多——功效边界写的是单检验的数，闸门用的是另一个。
   今后功效边界须写「在选定口径下、代表所在档位的可检出效应量」。
3. **网格设计阶段就看有效样本量的离散度**。本面跨 k 的非重叠窗口数差 8 倍（542 vs 66）。
   若离散度大，要么改用 min-P，要么把 k 收窄到同质区间，二选一并写进预登记。

## 6. 本论证的边界

- 备择假设建模为「某一档 k 的 |IC| 整体位移 δ」。真实效应还会按各形态的敏感度不同地传导，
  本文不建模这一层；但位移型备择是标准做法，且四个 k 的对比是在同一建模下做的，结论的方向不受影响。
- 证据来自**两个独立真实网格**的联合零分布（资金流 32 变体 2,715 日 / 现役 equal_weight 16 变体 3,003 日），
  不同信号族、不同变体数、不同评窗，结论一致；但仍只是这两个网格——
  推广到形态数或 k 集合差异很大的网格前应重跑本模块（`--grid` 可加新网格）。
- 本文不评价关 0 该不该存在。`selection_permutation.py` 记着没有它时的实测假阳率：
  16 点网格 20%、40 点网格 35~44%（名义 5%）。**校正必须做，本文只解决选哪种校正。**
