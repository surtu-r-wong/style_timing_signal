## 1. 两个命题（各自独立裁决）

**A. 价差反转快腿资格**：风格价差的 5～10 日反转信号（现役同一四对、同一 z→tanh 管线、符号取反）是否（i）自身三窗为正且 worst(train,val) 不低于现役同窗，
（ii）与现役有时滞（相关 < 0.5），（iii）经选优校正仍显著。过闸 = 取得 08-17 分批建仓线的重开钥匙（那条线登记的唯一重开条件即"自身足够好且有时滞的快腿"），
不等于生产切换；装配另开预登记。

**B. 指数反转/趋势的空头触发**：500/1000 blend 自身的短期反转（大涨后回落）与长期趋势（跌破长均线）作为**只做空**的触发，
其空头段净收益（含贴水成本）是否显著为正且两半窗同号。这是对「空头无价值」结论的最后一次直接检验，门槛就是贴水墙。

## 2. 构造（冻结）

**A 族**（复用 `backtest.momentum_scan.momentum_factor_fn`，四对与 `config_4pairs.csv` 同、blend 标的、carry 计入、3 bps、T+1）：
- 变体 = **07-10 短 z 窗原网格**：measure ∈ {classic, slope, voladj} × L ∈ {5, 10} × skip=0 × zw ∈ {10, 15, 20, 25, 30} × sm ∈ {0, 5} = **60 点**，
  因子 = **−1 × 原动量因子**（反转）。网格不扩、不缩：⓪ 的零分布必须覆盖当初被看过的整张网格。
- 仓位：对称 `to_position(mode="discrete")`；三窗 train 2014-2020 / val 2021-2023 / holdout 2024-2026（与 07-10 同）。
- 统计量（⓪）：worst(train, val) Sharpe（`pick_plateau_representatives` 同一选优规则 = argmax）。

**B 族**（标的 = blend 收益本身；只做空仓位 `short_only = −1 当信号为"空"，否则 0`）：
- B1 短期反转：blend 累计收益 `ret_L`（L ∈ {5, 10, 20}）的滚动 z（zw ∈ {20, 60}），z > +1 → 空（大涨后做空），持有 k ∈ {5, 10, 20}；18 点。
- B2 趋势：blend 价格指数（由收益累积）低于 MA（M ∈ {60, 120, 250}）→ 空，持有 k ∈ {5, 10, 20}；9 点。
- 合计 27 点；秤：blend 标的 + carry（空头付贴水）、3 bps、T+1；两半窗 2014-2019 / 2020-2026。
- 统计量（⓪）：空头段全窗净 Sharpe，argmax。

## 3. 闸门（冻结）

**A**：① 三窗 Sharpe 全正；② worst(train,val) ≥ 现役（equal_weight 20d40z sm5，同秤重算）同窗 worst；③ 与现役因子相关 < 0.5（时滞/独立性）；
④ **⓪**：60 点 worst(train,val) 的 argmax 空分布（循环移位 1,000 次，移位 ∈ [2·20, n−2·20]，重排信号侧），代表统计量 p_selected < 0.05。
四条全过 → A PASS（快腿资格）；否则 STOP。

**B**：① 代表的空头段全窗净 Sharpe > 0 且两半窗均 > 0；② 空头段净年化 > 0（已含贴水与成本，即跑赢贴水墙）；
③ **⓪**：27 点空头段净 Sharpe 的 argmax 空分布，p_selected < 0.05。三条全过 → B PASS；否则 STOP，并记录代表的空头段净年化与同期贴水率作为"贴水墙有多高"的量化。

## 4. 功效边界与披露

A：约 3,000 日、对称口径，与 07-10 同功效；B：空头段样本 = 触发日数（预计 15～35% 的交易日），k=20 时非重叠窗约 30～60，功效低，事前承认。
多重比较：A 60 点、B 27 点均由 ⓪ 吃进零分布。A 的线索来自已看过的网格 → ⓪ 是硬门槛不是诊断列。
