# 目标市值坐标改为直接测量（替代排名带代理）

2026-08-06

## 背景

B3 首次跑到 spec §5.5 的市值坐标校准闸门，失败：

```
q500_mean_abs_error  = 0.25195   （阈值 ≤ 0.25）
q1000_mean_abs_error = 0.16321
q_order_share        = 1.0
```

这道闸此前从未执行过——`calibrate_target_coordinates` 位于 `if not blockers:` 之后，
一直被更早的数据闸挡着。0.252 是首次真实测量值，没有历史基线。

## q500 是什么，为什么必须准

spec §6.3 定义：

```
x_i(q) = s_perp_i + q * h_perp_i
```

`q` 是**标量市值坐标**，不是股票池——spec 明写「排名带只用于定位 q……禁止把
301—800 或 801—1800 偷换成选股 universe」。

为什么必须是中证500 的位置：§9.1 的拟合目标是中证500 现金指数收益；§10.1 的
`B3_dual_target` 用 q500 的信号控 **IC（中证500 股指期货）**、q1000 控 IM。
**执行工具是 IC，风格信号就必须在 IC 所跟踪指数的市值水平上评估。**

因此「正确的 q500」有唯一定义：**中证500 实际所在的市值坐标**。不是口味问题。

## 诊断结论

用 B3 自己的变换重建 `m_perp`，复现出 `mean_abs=0.2512`（B3 实测 0.25195），
口径可信。据此：

- **系统性偏置**：36 个月 100% 同号，signed mean = −0.2512，sd 仅 0.056；
- **排名带与真实成份只重合 56.8%**；真实成份在总市值排名中的中位是 **688**，
  而非 301–800 的中点 550；
- **误差本身在漂移**（2021-01 的 −0.228 → 2023-07 的 −0.169）。

### 已否决的两条路

**平移排名带**（如统一 +150）：**没有机制**。误差随时间漂移这一事实本身就证伪了
「常数偏移」模型；而且把带边界拿去最小化闸门自己的指标是循环论证。更关键的是：
流通市值带的重合度**更低**（50.9%）中位数却**更准**（0.090）——说明「中位数对上」
≠「代表了该指数」，平移优化的只是前者。

**改用流通市值排名**：`stock_indicator.circ_mv` 在 2015-01-30 之前无数据，
坐标会在边界跳变。且中证500 的选样本就是按**日均总市值**排序，自由流通市值只用于
**加权**——「按自由流通选样」是错误认知，不能作为依据。

**偏差的机制目前没有经过验证的解释。** 可能与半年度调样加缓冲区（成份是滞后快照）、
流动性筛选、上市年限要求、ST 剔除、以及 B3 universe 含 CSI 样本空间排除的大市值票
有关，均未验证。**这不影响决定**——直接测量之所以正确，是因为目的如此，而非因为
任何机制故事。

## 决定：不要代理，直接测量

代理存在的唯一理由是「成份数据只有 2021 年起有」。实测 Wind `indexconstituent`
推翻了这个前提：

- `000905.SH` @ 2014-01-30 → **500 行，有数据**；
- `000852.SH`：2014-06-30 无数据，**2014-10-31 起有**（中证1000 于 2014-10-17 发布）。

因此：

```
q500  = median(m_perp | 当期真实中证500 成份)
q1000 = median(m_perp | 当期真实中证1000 成份)
qblend = (q500 + q1000) / 2      # 不变
```

`m_perp` 仍在 B3 的 size universe 上计算，所以坐标含义是「真实成份在 B3 截面中
所处的位置」——正是所需。

### 窗口起点 2014-01 → 2014-10

中证1000 在 2014-10-17 之前**不存在**，B3 必需窗口前 9 个月的 q1000 不可能代表它。
这是本体缺口而非数据缺口。用户 2026-08-06 拍板把 `windows.discovery` 起点挪到
`2014-10-01`。

**代价已明示并接受**：discovery 从 84 个月缩到 **75 个月（−11%）**，M0/M1 的估计
系数会变，此前基于 84 个月的结论需重跑。required formation 从 120 变为 **111**。

### as_of 必须取 formation 日本身

111 个 formation 日中多数早于自然月末（春节等月份差好几天，如 `2015-02-27`、
`2020-01-23`）。按自然月末回填会让 as-of **系统性取到上一个月**的成份——做校验时
尚可凑合，直接测量时是实打实的错误。故成份按 formation 日逐日回填，222 次 wset。

## §5.5 的替代闸门

代理没了，风险从「代理准不准」变成「测量牢不牢」。四条，任一不过判 `DATA_BLOCKED`：

1. **精确快照存在**：每个 required formation 日，两个指数都必须有 `effective_date`
   恰好等于该日的快照。**这取消了 as-of 的静默降级**——缺快照即阻断，而不是悄悄
   用上个月的成份冒充本月。
2. **成员数在预期范围**：中证500 = 500、中证1000 = 1000（容差 ±2，应对调样临界）。
   防止半截回填被当作正常数据。
3. **成员落入 size universe 的比例 ≥ 95%**。阈值取自**稳健性**而非拟合：中位数对
   少量缺失不敏感，95% 覆盖下偏移有界。（2021–2023 实测中位 487/500 = 97.4%，
   仅作合理性旁证。）
4. **序**：`q1000 > q500` **月月成立**。原 §5.5 允许 90%，直接测量后没有理由留例外
   ——出现例外即数据有误。

原三个误差诊断量作废；manifest 改记覆盖统计（成员数、落入 universe 比例）。

- 不动 `confirmation` 与 `report_only` 窗口。
