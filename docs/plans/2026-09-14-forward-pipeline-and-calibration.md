## 1. 现在可以实际运行什么

新增`backtest.forward_market`，绑定原信号campaign及新增采集/评分依赖代码指纹。每个交易日晚间从只读、可重复读的数据库事务取得两指数、IC/IM全部日行情和OI及项目交易日历；保留快照、来源时间和哈希链。按当日OI与到期排除规则记录下一交易日目标合约。

- CLI使用真实时钟，没有历史日期覆盖参数；拒绝盘中、陈旧、重复、跨午夜、代码漂移、日历冲突和不完整写入。
- 市场日历缺口不会被当成休市日吞掉；行情记录缺日会列明并阻止涉及该日的评分。
- 原信号记录器独立保留；信号缺日沿用最后记录的方向、初始空仓，收益日不删除，覆盖率和最长中断另报。
- 这是**报价观察及模型成交**，没有券商/期货公司的真实成交回执，不代表账户收益、成交可行性或供应商PIT保证。
- 日历来源为现有数据库`public.trading_calendar.sfe`，每个收录日必须同时有两指数和IC/IM报价；不将数据库未来日历描述为交易所的外部公证。日历修订会停止接收，需明确审查。

## 2. 独立统计补验发现了什么

固定504个交易日、20/60日移动块bootstrap各499次。两个比较逐项先取两块长p的较大值，再做Holm校正，以双侧5%裁决；每个模拟场景400份独立数据。五种联合零假设、六种备择，共4400份独立数据；单块结果也完整保存，没有看结果改主规则。

四条模拟净收益具有相同边际分布和总体Sharpe，组成两个相关比较。全局共享方差0.6、每对额外共享0.2、个体0.2。基准总体Sharpe0.3、日波动1%；备择只给第一个比较的第一条收益增加确定性均值，形成指定年化Sharpe增量。没有把每份样本人为去均值或强制样本Sharpe相等。

| 联合零假设场景 | 至少误判一个比较的比例 | 单侧95%二项上界 |
|---|---:|---:|
| iid正态 | 4.75% | 6.89% |
| 共享波动聚集＋t5厚尾 | 3.25% | 5.12% |
| AR(0.3) | 7.00% | 9.47% |
| 慢状态均值变化 | 23.50% | 27.25% |
| 确定性波动断点 | 3.50% | 5.42% |

事前验收要求是**每种场景的单侧95%上界≤7.5%**，属于模拟容差，正式显著性仍为5%。AR场景与慢状态场景不满足；不能笼统说“加了块bootstrap和多重比较校正就可靠”。AR场景的双侧95%区间仍含5%，故本轮只说未通过预设验收，不能断言其真实错误率已被精确证明高于5%。慢状态场景的双侧95%区间为19.43%–27.97%，失准明显。

这里23.5%是特定合成慢状态场景的**家族误报率**，不是现役策略在真实市场中有23.5%的错误概率。该场景以对称Markov状态驱动均值，每日翻转概率0.02；所有策略总体仍等Sharpe。它说明持续状态下、有限504日样本和固定短块可能严重低估不确定性，不是对全部bootstrap方法的否定。

功效是第一个比较被正确判为正增量的比例；第二个比较仍保持零效应：

| 真实年化Sharpe增量 | iid正态检出率 | 波动聚集＋厚尾检出率 |
|---|---:|---:|
| +0.2 | 3.25% | 2.50% |
| +0.4 | 8.25% | 9.75% |
| +0.6 | 17.25% | 17.00% |

+0.4的检出率95%区间分别约5.75%–11.39%、7.03%–13.09%，明显达不到预设80%实用目标。**即便真实存在中等优势，在这些假设下，两年左右观察也很可能只能得到“不确定”。** 这不是确定需要多少年的样本量估算，不能把504日按功效倒数机械放大。

## 3. 实质影响与后续顺序

1. 可开始积累可信的本地信号和市场证据，避免将来只有回填曲线可供解释。记录不会因统计方法暂未验收而失去描述价值。
2. 维持原504日观察约定和期中只查质量的纪律；不根据这次功效结果事后更改原协议，也不声称观察结束就一定能确认优势。
3. 下一统计优先项应是与慢状态依赖相匹配的推断方案、样本长度和最小可检出增量的联合设计。需要另立预登记和独立模拟验证，不能在本轮失败数据上反复挑规则再称校准通过。
4. 正式确认规则若在看过某段前瞻收益后才确定，确认窗必须从其后新的未使用样本开始。当前代码不输出正式p或GO，已有模拟不会自动启用确认。
5. 实际账户层仍需要现货标的、实际两池权重和券商成交记录；当前指数代理及小数合约模型不能补出这些事实。

## 4. 手动运行

信号日最早2026-09-15，在当日晚间更新数据后分别运行。两条记录独立：某天信号缺失不应阻止保存当天完整市场行情。

```bash
bash -c 'ulimit -v 2000000; python -m backtest.forward_observation record --campaign backtest/output/forward/20260914-incumbents-v1'
bash -c 'ulimit -v 2000000; OPENBLAS_NUM_THREADS=1 python -m backtest.forward_market record --market backtest/output/forward/20260914-incumbents-market-v1'
```

平时仅检查质量：

```bash
bash -c 'ulimit -v 2000000; OPENBLAS_NUM_THREADS=1 python -m backtest.forward_scoring quality --market backtest/output/forward/20260914-incumbents-market-v1'
```

满足完整观察门槛后，显式指定一个全新输出目录运行`forward_scoring score --market ... --output ...`，仍只得到描述性模型评分。不得修改时钟、补签旧日期或改元数据绕过限制。
