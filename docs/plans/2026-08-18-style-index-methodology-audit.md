# 风格指数编制方案审计：现役四对横跨**两个不同的指数族**

**日期**：2026-08-18　**性质**：事实审计（读权威原文，非回测）
**⚠️ 2026-08-18 二读更正**：用户补齐缺件后全部读完，**§2 的"经典 vs 纯风格"二分法不准确**，真正的分界是**老版 vs 新版**。以 §7 为准。
**原文来源**：`/home/elfbob/exchange/20260702/指数编制方案/`（用户本地权威件，中证指数有限公司发布）
**起因**：用户质疑"四组等权存疑，同一桶的成长和价值选出的数量都不一样"。穿透后发现
成分只数不对称（1:1 / 1:1.5 / 1:1.87 / 1:1.48），追查规则后确认**根因是方法论不同族**。

## 0. 结论先行

现役 `config_4pairs.csv` 的四对里，**前两对与后两对属于两个不同的中证指数族**，
在**价值因子公式、选样规则、加权方式、缓冲区**四个维度上均不同。
最本质的差别是：

> **经典族的成长与价值是两个独立排序；纯风格族是单一相对风格轴的两端。**

因此"300成长 − 300价值"与"1000P成长 − 1000P价值"**测的不是同一种价差**，
把四对等权平均，量纲上并不齐。

|---|---|---|---|---|

## 2. 逐条规则对比（均引自本地权威原文）

| 维度 | **经典规模风格** | **纯风格（Pure）** |
|---|---|---|
| 样本空间 | 母指数样本（沪深300 / 中证500 / 中证800） | 母指数样本（中证1000 / 中证2000） |
| 价值因子指标 | D/P、B/P、CF/P、E/P | 同上 4 个 |
| **价值得分公式** | `(Z(D/P)+Z(B/P)+Z(CF/P)+Z(E/P))/4` | **金融**：`(Z(D/P)+Z(B/P)+Z(E/P))/√3`（**剔 CF/P**）<br>**非金融**：`(Z(D/P)+Z(B/P)+Z(CF/P)+Z(E/P))/2` |
| 区分金融/非金融 | **否** | **是** |
| 成长因子指标 | SalG、ProG、ΔROE | 同上 3 个 |
| **成长得分公式** | `(Z(SalG)+Z(ProG)+Z(ΔROE))/√3` | **完全相同** |
| **成长与价值的关系** | **两个独立排序**（互不约束） | **单一轴两端**：`综合价值得分 =(价值概率+(1−成长概率))/2`，`综合成长得分 = 1 − 综合价值得分` |
| **选样规则** | **固定名次**：300价值取 100、500价值取 150、800成长取 150 | **取综合概率 = 1 的全部**（经 logistic 平滑，Y≤0.1→0、Y≥0.9→1；分位点 X_L/X_M/X_U 取自由流通市值累计 25%/50%/75%）→ **数量不固定** |
| **加权方式** | 价值指数：**调整市值加权**（300价值 ≤10%）<br>成长指数：**成长得分调整后的自由流通市值加权**（800成长 ≤10%、单一级行业 ≤30%） | **按综合风格得分加权**（非市值），单样本 ≤**15%**、**前五合计 ≤60%** |
| **缓冲区** | **有**（300价值 80/120；500价值 105/195；800成长 90/210） | **无** |
| 调样 | 半年（6/12 月第二个周五的下一交易日） | 同 |
| 基日 | 2004-12-31 | 2012-12-31 / 2013-12-31 |

**这解释了实测的成分只数**：300价值=100（规则写死 100）、500价值=150（规则写死 150）、
1000P/2000P 数量不定（概率=1 的全部，故 213/399、207/307 不对称）。

## 3. 第三个族（供统一方案参考）：上证全指相对风格

《上证全指风格指数系列编制方案》（2020-12 V1.1），000057/000058/000059/000060：

- 成长因子第三项是**内部增长率 G = ROE×(1−红利支付率)**，**不是 ΔROE** —— 与前两族不同。
- 全指成长/价值 = 成长/价值评分最高的**各 150 只**，**调整市值加权**。
- **全R成长** = 成长评分前 150 **以及**价值评分在前 150 之外的证券（数量不定）；
  加权 = 调整市值 × **风格权重因子**，因子按"成长评分排名/价值评分排名"分四档
  **1 / 0.75 / 0.5 / 0.25**。
- 缺失值用同行业均值代替；极值按 5%/95% 分位缩尾。

即中证至少有**三种**把股票切成成长/价值的做法：**固定名次**（经典）、**概率阈值**（纯风格）、
**双排序 + 权重分档**（相对风格）。

## 4. 对现役信号的直接含义

1. **四对不同族 → 价差不同质。** 对 1/2 是"两个独立因子排序、市值加权组合"之差；
   对 3/4 是"单一相对风格轴两端、按风格得分加权"之差。等权平均它们，
   混合的是两种不同定义的"风格价差"。
2. **加权口径不同 → 经济含义不同。** 经典腿（至少价值侧）是市值加权，其收益对应一个
   可自然持有的组合；纯风格腿按风格得分加权，得分越极端权重越大，**不对应任何
   自然持仓**。
3. **纯风格族是 2025-01 的首版（V1.0），基日 2012/2013** → 2013-2024 的历史为回填。
   ⚠️ 但同日的对照检验**未发现回填污染指纹**（以经典两对为对照组，切点 2025-01-22
   前后四对同步变化，1000P 完全落在经典两对的区间内），故此条**登记但不据以否定读数**。

### 7.2 ⭐ 更正：真正的分界是**老版 vs 新版**，不是"经典 vs 纯风格"

| | **老版规模风格**（2004 基日，V1.2） | **新版规模风格**（2024-12，V1.0） | **纯风格 P**（2025-01，V1.0） |
|---|---|---|---|
| 代表 | 000918/000919、H30351/H30352 | 932392-932395 | 932400-932409 |
| **价值得分** | `(Z(D/P)+Z(B/P)+Z(CF/P)+Z(E/P))/4` | 金融 `(Z(D/P)+Z(B/P)+Z(E/P))/√3`<br>非金融 `(...)/2` | **与新版逐字相同** |
| **区分金融/非金融** | **否** | **是** | **是** |
| 成长得分 | `(Z(SalG)+Z(ProG)+Z(ΔROE))/√3` | 相同 | 相同 |
| 选样 | 固定名次（300 取 100/100；500 取 100成长/150价值） | **固定 200 只**（1000、2000 均是） | 概率=1 的全部；**2000 带额外取得分前 50%** |
| 加权 | 价值=调整市值加权(≤10%)<br>成长=得分调整后自由流通市值加权 | 得分调整后自由流通市值加权(≤10%，一级行业≤30%) | **综合风格得分加权**(≤15%，前五≤60%) |
| 缓冲区 | 有（80/120、105/195） | 有（100/300） | **无** |

**关键**：**新版规模风格族也单独处理金融股**（价值分剔 CF/P）。所以"分金融"**不是 P 族独有**，
而是**新版方法论**的共同特征。老版（300/500）至今仍用不分行业的 `/4` 公式。

### 7.3 由此得出的路线可行性（与 §6 的初判不同）

- **路线 A（全走规模风格族）无法达成同质**：300/500 只有**老版**（不分金融、除以 4），
  1000/2000 只有**新版**（分金融）。换过去以后，混的仍然是**两套价值公式**，
  只是把"经典 vs 纯风格"的不同质换成了"老版 vs 新版"的不同质。**A route 不成立。**
- **路线 B（全走纯风格 P 族）最接近同质**：四带的价值公式、成长公式、概率化、加权方式
  **全部一致**，唯一差异是 **2000 带多一道"取得分前 50%"的截断**（其余三带取概率=1 的全部）。
  这是选样口径的一个附加条款，不改变公式与加权。
- → **只有 B 能让四带全程使用同一套价值公式（且全程分金融）。**

**用户倾向 P 的判断成立，但理由需改写**：不是"P 族分金融、经典不分"（新版经典也分），
而是"**只有全 P 路线能做到四带全部分金融，因为规模风格族的 300/500 至今仍是老版公式**"。

### 7.4 其余两族（登记备查，不进本轮候选）
