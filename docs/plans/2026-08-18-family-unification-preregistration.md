## 0. 命题与它的真正目的

现役 `config_4pairs.csv` 的四对**横跨两套不兼容的编制方法**：

- 300、500 用**老版规模风格**：价值分 `(4项Z)/4`、**不区分金融**、固定名次、市值加权；
- 1000、2000 用**纯风格 P 族**：价值分**区分金融**（金融剔 CF/P）、取综合概率=1、
  **按风格得分加权**。

把这四个价差等权平均，混合的是**两种不同定义的"风格价差"**。

**本轮不是"找一个更好的信号"，是"检验现役的结构是否站得住"。** 这一点决定了读法（§5）。

## 2. 口径冻结

- **信号构造完全不动**：四对 tanh(z) 等权平均 → `rolling(5).mean()` → `production_position(θ=0)`
  long-flat；`lookback=20`、`z_window=40`。**只换四对的输入价格序列。**
- **执行标的固定** = 现役部署口径 `blend(500+1000)`，`cost_bps=3.0`。
  主判据**含 carry**（与部署一致）；零 carry 版本作对照列一并报告。
- **窗口**：`full` / `train 2014-2020` / `val 2021-2023` / `2024-2026`。
  **2024-2026 仅报告**，不进任何选择或排序（已被历次决策消耗，见
  `2026-07-11-external-review-fixes.md` §3）。
- **⓪ 机器参数**：`scheme="rotation"`、`min_shift=60`、`max_shift=n−60`、
  `n_perm=1000`、`seed=0`（与 ⑧ 正式跑同口径）。
- **统计量** = 配对 Sharpe 差（候选 − 现役），full 窗，同一置换下配对。

## 3. 三关闸门（预先声明）

- **关1（统计）**：full Sharpe 差 > 0 **且** `p_selected < 0.05`。
  `p_naive` 与 `p_selected` 在单点下相等，仍两个都报。
- **关2（护栏）**：`worst(train, val)` ≥ 现役同窗值 − 0.02（沿用 ⑧ 关2 形式）。
- **关3（成本与风险）**：MaxDD 不恶化、换手不恶化。
- **OVERALL = GO** 当且仅当三关全过。

## 5. ⭐ 结果解读规则（**跑前写死，事后不得更改**）

这是本预登记最重要的一节。三种情形，各自的**唯一**允许表述：

**情形 ① 候选 B 过闸**（Sharpe 差 > 0 且 p < 0.05，关2/关3 同过）
→ 表述："**方法论同质化改善了信号**"。可进入部署变更讨论（仍需另做换月/成本复核）。

**情形 ② 差异不显著**（p ≥ 0.05，无论差值正负）
→ 表述："**在本样本上，四对是否同质对信号无可辨认的影响**"。现役维持不变。
**不得**表述为"现役更优"或"同质化无用"——不显著只说明分不出来。

**情形 ③ 现役显著胜出**（候选 Sharpe 显著更低，p < 0.05 且差值为负）
→ **必须**记为："**混族的优势没有理论支撑**"。并同时执行以下三条，不得省略：

1. **不得据此加强对现役的信心。** 没有任何理论说"混两套不兼容的定义"应当优于
   "用一套一致的定义"。在找到机制解释之前，该优势**按运气处理**。
2. **必须触发一个新问题**："为什么不一致的混合会更好？"——并按 §1b 跑候选 A，
   检查是否由老版 300/500 的某个具体特性（不分金融 / 固定名次 / 市值加权）驱动。
   该特性若被定位，属**独立的机制命题**，需另行预登记，**不得就地采信**。
3. **该情形削弱而非加强现役的立足点**，须在收官文档与记忆里如实记为"现役结构存疑"。

> 写下这一节的原因：情形 ③ 在事后极易被读成"现役经受住了挑战"。它不是。
> 它是"我们无法解释现役为什么好"，这是**更弱**而不是更强的位置。

## 8. 为什么必须是单点而不是网格（依据）

同日实测：1160 点联合网格的过闸门槛（零分布 95% 分位）为 **+1.27 / +1.53 / +1.55**，
而整张网格**能给出的最大增益**只有 **+0.60 / +0.39 / +0.61** —— **结构上产不出 GO**
（`2026-08-18-microcap-joint-grid.md` §7）。搜索空间越大门槛越高。
本轮以**单点候选**换取最大功效，这是当前唯一能真正做出裁决的形态。
