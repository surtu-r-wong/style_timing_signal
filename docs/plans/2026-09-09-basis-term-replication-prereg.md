## 1. 命题（双侧写法，方向已冻结）

「期指基差期限斜率 T1（远月相对更深贴水 → 曲线更陡）对**该期货自身标的**未来 40 日收益有正向预测力」

## 2. 构造（冻结，逐字继承原线）

- 数据：`public.futures_daily` 取 `symbol LIKE 'IF%'/'IH%'` 的 close；现货 `stock_selector.index_daily` 000300.SH / 000016.SH 收盘。
- 每日每合约年化基差率 `b=(S−F)/S×365/days`，到期第三个周五，剔除距到期 <7 自然日合约，剩余 <3 记 NaN。
- T1 = b 对到期年数的 OLS 斜率；T2 = 最远 − 最近（只作描述）。**单品种不合并腿**（原线的 500/1000 均值在这里没有对应物）。
- 信号化：`level_signal(T1, lb=5, zw=60)`（rolling mean → z → tanh，原线代表形态），k=40 非重叠窗，**方向 +1**。
- 机器：`backtest/basis_term.py::build_replication_series`（复用 `day_term_metrics` / `build_index_series`，单测 `tests/test_basis_term.py` 2 passed）；
  探针待冻结后写 `backtest/basis_term_replication.py`，须带手算字面量单测 + 变异验证。
- PIT：合约 close 与指数收盘同日可知，T+1 生效。
- 2015 股灾极值（IF 2015-07-07/08、09-01/02 |T1| 3.4~4.0）按原线冻结规则**不裁剪、不剔除**。

## 3. 检验、窗口与判定（冻结）

### 3.1 两个检验

| # | 输入 | 目标 | 窗口 | k=40 窗数 | 检验 |
|---|---|---|---|---|---|
| P1 | T1_IF lb5zw60 | 000300.SH 日收益 | 2014-01-02..跑当日 | 77 | 非重叠 Spearman IC；循环移位置换 1,000 次，**单侧**（方向 +1 已冻结）p |
| P2 | T1_IH lb5zw60 | 000016.SH 日收益 | 2021-01-04..跑当日（若 000016 现货回填到 2015-04-16 则从该日起，≈69 窗） | 34（回填后 ≈69） | 同上 |

无网格、无选优 → **关 0 不适用**（`adjusted_pvalue` 的 criterion 无对象），单侧置换 p 就是正式口径。
两半窗（2014-2019 / 2020-2026）IC 只报不闸（IF 首半窗 ≈37 窗、IH 无首半窗）。

### 3.2 判定规则

- **PASS**：P1 单侧 p < 0.05 **且** P2 的 IC 与 +1 同号（000016 回填后 P2 亦须 p < 0.05）。
- **STOP**：其余一切情形。**本 STOP 是终局**，不再写任何「等样本」类重开条件；
  唯一例外是 000016 回填后 P2 从「同号」升格为「显著性检验」时，若 P1 已过而 P2 在回填前只是同号，可补跑 P2 一次。
- PASS 后不进生产：下一步是「与原线同秤合并的装配设计」（原线登记表已写），届时 IF/IH 信息与 IC/IM 信息是否重复计数须另论证。

### 3.3 描述性副产物（只报不闸）

- T2_IF / T2_IH 同一检验（与 T1 同源，不计数）。
- T1_IF、T1_IH → blend（500/1000 现货等权）的 IC 与**控现役 equal_weight 的偏 IC**（生产相关性）。
- IF 2014-01-02..2015-04-15 段（原线评窗前，7 窗）IC 符号。
- 逐年 IC 符号表。

## 4. 功效边界与在位者

- P1：n=77，若真 ρ=0.20（原线代表量级），单侧 α=0.05 功效约 0.55；ρ=0.29（原线网格最优）约 0.8。
