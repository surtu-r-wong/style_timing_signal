## 1. 命题（双侧）

剔除同日涨跌后的主力残差净流入（市场级；小盘减大盘）经滚动均值慢腿化后，是否对 equal_weight 生产信号
（long-flat，blend 标的）提供显著、独立、两半窗稳健、成本后存活、且经选优校正仍显著的择时信息。

## 2. 构造（冻结）

- 数据：`index_money_flow`（000300.SH / 000905.SH / 000852.SH / 932000.CSI；Wind 板块代码 csi_300 由用户给定，
  其余三个由取数探针按「只数和 = 成分数」定案后写入 README）；收益用 `index_daily` 收盘价。
- `f_it = main_inflow_money / (main_in_money + main_out_money)`：净流入占主力成交比，量纲无关（单位倍率不影响）。
- `e_it = f_it − a − b·r_it`，(a, b) 只用 **t−1 及以前 250 日** OLS（min 120 日）；t 日收盘即可算、不随未来改写。
- **F1 市场残差流** = 四指数 e_it 均值（可用指数 ≥ 3 才记，否则 NaN；中证2000 若 2023 前无板块历史不影响 F1 的 2014 起点）。
- **F2 规模残差流差** = mean(e_500, e_1000) − e_300（与创新高面 N2 同构；不用中证2000）。
- 当日收盘即知，T+1 生效。序列缓存 `backtest/output/money_flow_series.csv`。
- 机器：`backtest/money_flow_series.py`（含 5 个手算字面量单测 `tests/test_money_flow_series.py`：量纲无关、过去 OLS 精确复原、
  PIT 不改写、t 日不入系数、族公式与 ≥3 规则）、`backtest/money_flow_axis_probe.py`（创新高探针逐字克隆，只换族名与输入）。

## 3. 网格、窗口、秤与闸门（冻结）

- 两族 × `GRID_LEVEL`（lb∈{5,20} × zw∈{60,250}）× k∈{5,10,20,40} = **32 变体**。
- 两半窗默认 2014-2019 / 2020-2026；秤 blend 标的 + carry、3 bps、T+1；置换 1,000。

## 4. 功效边界与引用纪律

约 3,000 日（板块资金流若从 2014 起）、k=20 约 150 窗、k=40 约 75 窗，可检出 |IC| ≳ 0.15。
关的是「主力残差净流入（市场级 / 小盘减大盘）× 水平型网格对 equal_weight 的入场券」；**不得引作**「资金流对个股或行业无价值」
（个股层面的大单/尾盘因子未测），也不得引作「未残差化的原始流无价值」（原始流 81% 是价格，那是价格类面的既有结论）。
不登记的形态：开盘/尾盘拆分、超大/大单拆分、只数口径、原始净流入——以后要测须另立预登记。

## 5. 数据前置（跑前必过，不过则 data_blocked）

1. 恒等式：main = in − out、main = extra + large、四档之和 = 0（容差 0.01）；

4. 各指数起点：沪深300/500/1000 须覆盖 2014-01 起（否则半窗一改为 data_blocked 而非缩窗跑）。
