## 2. 尾部桶的定义（逐条冻结）

| 项 | 冻结值 | 理由 |
|---|---|---|
| 交易所 | `.SH` / `.SZ`（不含 `.BJ`） | 与 `UNIVERSE_SQL` 既有口径一致 |
| **规模带** | 每个调样日按 `stock_indicator.total_mv` 降序排名，取 **3801 名及以后** | 用排名而非"不在母指数内"：库内无四母指数的历史成分（只有 2026 年 7~8 期），且排名口径可复现。**副作用是好的**：次新股巨头（如 `688825.SH C长鑫`，总市值全市场第一、2026-07-27 上市）按排名属大盘，**自动不进尾部桶** |
| **上市时间** | 剔除**上市不足 1 年**者 | 中证样本空间惯例；且 SalG/ProG 需三年季度数据，新股因子不可靠 |
| **流动性** | 剔除**过去一年日均成交额排名后 20%** | 中证式规则。实测剔后 20% 保留约 1,122 只、最低日均成交 830 万 |
| 行级有效性 | `close IS NOT NULL AND pre_close > 0 AND volume > 0` | 沿用 `UNIVERSE_SQL` |
| **调样** | 每年 6 月、12 月第二个星期五的下一交易日 | 与中证四对同步，避免调样时点错配 |

## 3. 成长/价值分类（按**纯风格 P 族**方法论，逐条照抄原文）

原文 = `/home/elfbob/exchange/20260702/指数编制方案/中证2000纯成长（纯价值）指数编制方案.pdf`
（2025-01 V1.0），规则表见 `2026-08-18-style-index-methodology-audit.md` §7.2。

1. **价值因子 4 项**：D/P、B/P、CF/P、E/P；**成长因子 3 项**：SalG、ProG、ΔROE。
2. 各指标取**极值调整后**的标准化 Z 值；**按中证行业分类区分金融 / 非金融**：
   - 价值得分（金融）= `(Z(D/P)+Z(B/P)+Z(E/P))/√3`（**剔 CF/P**）
   - 价值得分（非金融）= `(Z(D/P)+Z(B/P)+Z(CF/P)+Z(E/P))/2`
   - 成长得分 = `(Z(SalG)+Z(ProG)+Z(ΔROE))/√3`
3. 平滑成 0~1 概率 → `综合价值得分 = (价值概率 + (1−成长概率))/2`；`综合成长得分 = 1 − 综合价值得分`。
4. logistic 平滑（原文公式），`X_L/X_M/X_U` = 样本空间内按综合价值得分升序、
   累计自由流通市值达 **25% / 50% / 75%** 时对应的得分；`Y ≤ 0.1 → 0`、`Y ≥ 0.9 → 1`。
5. **样本 = 综合成长（价值）概率为 1 的证券**；
   ⚠️ **尾部桶沿用 2000 带的附加条款**：从中**再取综合得分最高的 50%**
   （2000P 有此条款而 300P/500P/1000P 无；尾部与 2000 带同属"样本量大"的情形，故照 2000 带办）。
6. **加权 = 综合风格得分加权**，单样本 ≤ **15%**、前五合计 ≤ **60%**。

**缺失值处理**：某因子缺失 → 用**同中证一级行业均值**代替（上证全指方案的明文做法；
纯风格方案未写，此处照该先例，**属自由裁量，登记在案**）。

## 5. 三关闸门

- **关1**：full Sharpe 差 > 0 **且** `p_selected < 0.05`（单点 → `p_selected` = `p_naive`，两个都报）。
- **关2**：`worst(train, val)` ≥ 现役同窗值 − 0.02。
- **关3**：MaxDD 不恶化、换手不恶化（≤ 现役 × 1.05）。
- **OVERALL = GO** 当且仅当 Gate 0 过 **且** 三关全过。

⓪ 机器：`rotation`、`min_shift=60`、`max_shift=n−60`、`n_perm=1000`、`seed=0`；
统计量 = 配对 Sharpe 差（候选 − 现役），同一置换同时作用于两条仓位序列。

## 6. ⭐ 解读规则（跑前写死，事后不得更改）

**情形 ① 过闸** → "**尾部规模带携带现有四对没有的信息**"。可进部署变更讨论。
但结论必须带 **provisional** 限定（§7 第 1 条）。

**情形 ② 不显著** → "**在本样本与本实现下，尾部对无可辨认增量**"。
**不得**表述为"尾部没有信息"—— 因为至少三个因素会稀释真实效应：
approximate-PIT、自建分类器与官方实现的差异、以及 1/5 权重的稀释。
正确表述是"**这个实现下测不出来**"。

**情形 ③ 显著为负** → 必须给出机制解释再下结论；在找到机制之前记为"异常，待解释"，
**不得**据此宣称"尾部有害"。
