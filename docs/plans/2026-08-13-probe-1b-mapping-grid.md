## 2. 预登记网格（32 点，**未扩**）

议程只钉死了**点数结构**「θ_L 4 × h 2 × w_S 4 = 32」与 `w_S` 的三个负值原文；
**θ_L 与 h 的具体取值属实现自由度**，本次一次选定如下（理由见 §11）：

| 轴 | 取值 | 说明 |
|---|---|---|
| **θ_L** | **{0.0, 0.1, 0.2, 0.3}** | 0 = 现役；其余为仓内既有 0.1 步长阈值梯（`scan_thresholds.threshold_grid` 的 `open_longs`） |
| **h** | **{0.0, 0.1}** | 0 = 无滞回（退化为无记忆映射，**对照**）；0.1 = 仓内既有带宽（同上文件 `hysteresis` 默认） |
| **w_S** | **{0.0, −0.25, −0.5, −1.0}** | 0 = 现役 long-flat（**对照**）；三个负值为议程 ①(b) **原文** |

**映射定义**（新代码 `backtest/mapping_probe.hysteresis_position`）：
进场 `|s| > θ_L + h`、出场 `|s| ≤ θ_L`；多头权重 +1、空头权重 `w_S`。
选这一参数化（而非"进场 ±θ_L、出场 ±(θ_L−h)"）的两个理由：

1. **h=0 时精确退化**为既有无记忆映射 `positions.to_position_asym(s, θ_L, θ_L)`
   —— 于是 **(0, 0, 0) 就是现役 `production_position(θ=0)`**、**(0, 0, −1) 就是 ①a 的对称口径**，
   两个历史已知点都落在网格里，可作同秤锚点（§10 取证）；
2. **无歧义**：四条水位天然有序 `−(θ_L+h) ≤ −θ_L ≤ θ_L ≤ θ_L+h`，多空保持区互斥，
   不存在"多头未出场而空头已进场"的冲突分支（另一种写法在 `|s| ∈ (θ_L−h, θ_L)` 时正是这种冲突）。

**网格内的重合点如实标注**：(0, 0, 0) = **现役**，是**对照点不是候选**（产物 CSV 的 `is_incumbent` 列）；
(0, 0, −1) = ①a 的对称口径（`is_symmetric_1a` 列）。二者均照常参与 argmax 选优
（它们本就是 θ_L 与 w_S 各含 0 这一选择的自然产物），但结论表述中不当作"新发现的候选"。

## 6. 机器接入与 `p` 的含义边界

### 6.1 接入方式（机器文档 §6 + 上两批 QA 钉死的四条规矩，逐条对表）

| 规矩 | 本次执行 |
|---|---|
| **32 点合成同一次调用** | ✅ 一次 `selection_permutation_test`，`variants` = 32 元组；无分族/分轴多次调用 |
| **主口径 `p_selected`，`p_naive` 只作对照** | ✅ 判据表里 `p_naive` 明标 `UNCORRECTED(对照·不得入闸)`，且两者**都不是判据** |
| **变体 = 已算好的仓位序列**，移位作用在"仓位 × 收益"错配上 | ✅ 32 条仓位序列由现役因子一次算出；置换只重排仓位数组。**未**"移因子再重跑滞回映射" |
| **`-inf` 只给无法评分行；独立闸门不得编进统计量** | ✅ 统计量是**无约束** worst_tv 净 Sharpe；换手与 MaxDD 两条判据**后置独立判**。本次无 `-inf` 行（std=0 按房规 `metrics.sharpe` 返回 0.0，不是 `-inf`） |

**"移位精确保持换手"是这条写法成立的前提，已被判例钉死到逐日粒度**
（`test_rotation_rolls_the_daily_turnover_sequence`：移位后的**逐日 |Δpos| 序列** ==
原逐日序列的同幅循环移位，3 个变体 × shift ∈ {1, 37, 250} 全部 `array_equal`；
**环形总换手**随之逐位不变）。即成本结构不被移位改造，只是整体搬家。
若改成"移因子再重跑映射"，每个置换样本的换手与成本结构都会变，成本后净 Sharpe 的零分布随之失真。

### 6.3 三条必须写明的边界（**否则这些 p 会被误读**）

1. **`selection_inflation = 1.0` 不代表"这次没有选择效应"**：`p_selected` 与 `p_naive`
   **双双触底 1/1001**，比值因此被截断成 1。真实证据在别处：**32 个变体在空分布下全部当过赢家**
   （网格有效宽度是满的），且 **32 点里有 20 点的 `p_naive` 同样触底**——
   naive 口径在这张网格上根本不具区分度。要把 `p_selected` 与 `p_naive` 分开，需要 B ≫ 1000；
   本次未加大 B，因为 **p 不是本探针的判据**（①(f) 的三条判据里没有任何一条读 p）；
2. **`p_selected` 回答的问题不是判据①的问题。** 它问的是
   *"当选映射的 worst_tv 有多难靠**信号与收益随机错配**得到"*——
   而**现役自己的 `p_naive` 也触底 0.000999**。即：这条 p 检验的是"这一族映射作用在一条
   **本就有效的因子**上是否强于随机错配"，**不是**"赢家是否强于现役"。
   判据①问的才是后者，而它是**同秤差值**的问题，**不是**本次机器回答的问题；
3. **空分布下的当选者集中在 `w_S = 0` 子族**（1,000 次置换里 **724 次**由 `w_S=0` 的 8 个点夺魁，
   −0.25/−0.5/−1 三族合计仅 276 次）。机制清楚：随机错配下毛收益期望为 0，
   于是**换手最低者（成本最小）胜出**——这条诊断反过来印证了判据②所盯的成本差异是真实且巨大的。

## 7. 移位区间的选取依据（**不照抄 [2k, n−2k]**）

**为什么不照抄**：房规 `[2k, n−2k]`（`rotation_probe` / 探针 ②）防的是"移位后**前瞻窗**与原窗仍重叠"
的机械残留配对。本探针的统计量把 `pos_eff[t]` 与 `und[t]` **同日**相乘，**没有前瞻窗，k 概念不存在**
（机器文档 §6 的 ①b 行也写明 `min_shift=1`）。任务书要求"取充分去相关长度并写明依据"，故改用下述规则。

**规则（一次选定，先于任何统计量结果；实现见 `mapping_probe.choose_min_shift`）**：
> 移位下界 = **结构性候选梯 {20, 40, 60, 120, 250}**（现役因子 lookback=20 / z_window=40 的倍数）
> 上**第一个**使**全部 32 条仓位序列**的 |ACF| 都落进白噪声带 `2/√n` 的滞后。

**实测结果**：n = 2,434 → 带宽 `2/√n = 0.04054`。
32 变体的 |ACF| 上包络：lag20 **0.2202**、lag40 **0.2721**、**lag60 0.0328 < 0.04054 ✅** →
**`min_shift = 60`**，`max_shift = n − 60 = 2374`（对称截断：移位接近 n 等价于小幅**反向**移位）。

**一条不能瞒的事实 + 它的方向**：仓位序列的 ACF **不是单调衰减**的，在
**lag ≈ 194~198、226~232（峰值 0.2009 @ lag 228）与 335 附近**有**周期性回潮**
（32 变体 |ACF| 上包络的最大值即 0.2009；32 变体 × lag ≥ 60 全体的均值 0.0617）。
这是风格轮动本身的周期结构，**任何移位下界都消不掉**，硬要避开就得排除大部分移位区间（且是循环论证）。
**但它的方向是保守的**：H0 下循环移位与观测行**精确可交换**，p 的校准与残留自相关无关；
H1 下残留只会让置换行**保留一部分真效应** → 零分布上移 → `p_selected` **偏大**。
即本探针的 p **只可能低估显著性，不可能造假阳**。（本次 p 已触底，该保守性未咬到任何结论。）
