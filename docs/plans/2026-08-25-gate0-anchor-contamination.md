## 3. 归因做实：双向 A/B（含阳性对照）

只证「我的改动没影响」是不够的——零结果可能只是实验失灵。故做**两个方向**：
同一份数据、只切换 `_knowability` 新旧两版，各建一次等比五桶腿。

| 调样日（数据界） | 桶 | 新规则 | 旧规则 | 判定 |
|---|---|---|---|---|
| **2025-12-15**（2025-10-31） | g1 | [42, 64] | [42, 64] | 同 |
| | g2 | [97, 117] | [97, 117] | 同 |
| | g3 | [188, 235] | [188, 235] | 同 |
| | g4 | [396, 444] | [396, 444] | 同 |
| | g5 | [778, 911] | [778, 911] | 同 |
| **2020-06-15**（2020-04-30） | g1~g4 | — | — | 同 |
| | **g5** | **[578, 562]** | **[578, 561]** | **不同** |

**读法**：

- 2025-12-15 那期，两版规则都复现出 **08-25 run 的数字**，而 08-24 run 记的是
  g1[45,62]/g2[95,115]/g3[191,233]/g4[396,445]/g5[769,922] ⇒
  **该期的 run 间差异 100% 来自数据，与口径改动无关。**
- 2020-06-15 的 g5，两版**分别精确等于** 08-25 与 08-24 的记录 ⇒
  **那一处确属本日改动**（`300178.SZ` 的伪行前视后门被关，见首披日计划 §4.1）。
  这同时是**阳性对照**：证明该实验有能力检出本日改动，故上一行的零结果是真零。

另有两条独立佐证：2000 带 wind 段四个调样日**七因子逐票完全相同**；
cutoff 2025-10-31 变为不可见的 25,802 行 income 里**季末行为 0**
（`pit_ttm_with_known` 本就按 `is_quarter_end` 滤掉它们）。

**结论：本日 PIT 口径统一对 ρ 的贡献 ≈ 0；三闸的 +0.012 全部是数据修复。**

### 5.2 纪律取档 B（记录 + 静默检查，不做前置闸）—— 已实现

`run_manifest.input_drift_report` + 四个 runner（0r/0a/0b/0r'）起跑拍照收尾比对。
