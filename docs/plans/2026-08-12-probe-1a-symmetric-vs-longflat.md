## 0. 结论先行

**闸门判定：不显著。** 部署口径 long-flat 与对称口径的 Sharpe 差（勘误后 1.62 vs 1.41）
在同秤配对 block bootstrap 下**无法与 0 区分**——主判据格 `equal_weight × blend × full`
差值 **+0.198**，95% CI **[−0.251, +0.609]**，**p = 0.373**，CI 跨 0。
三个分段窗口**全部不显著**，且**符号不一致**（2014-2020 +0.300、2021-2023 **−0.255**、
2024-2026 +0.269）。

按 ①(f) 预登记，**结果不触发任何部署动作，本文仅入档**。

**随之确立的事实（决策级信息，勘误 §2 已预告的"负"分支）**：
现役 long-flat 的依据**不是被统计证据支持的收益优势**，而是**风险特征**——
同秤下 MaxDD **−16.7% vs −29.3%**（约减半）、年化换手 **10.55 vs 21.18**（约减半）、
Calmar **1.570 vs 1.222**。而**年化收益在全部 12 个格子里对称口径都更高**
（blend/full **35.8% vs 26.2%**）。即：long-flat 用**更低的收益**换**更低的回撤与换手**，
Sharpe 上的领先量级存在但**不具统计显著性**。

**读法警告（必须连着看，不许摘取）**：
- 12 格里只有 **500 口径的 full 与 2014-2020** 名义显著（p=0.033 / 0.022），
  而这两格**互相嵌套**（full 的样本包含 2014-2020，且该段占 full 的 56%），
  实质是**同一段证据被数了两次**，不是两个独立发现；
- 12 次名义检验在 α=0.05 下期望约 0.6 次假阳性，且各格样本高度重叠 → **未做多重比较校正**
  （预登记未要求，本文亦不据此下任何结论）；
- **1000 口径四格全部符号为负或近零**——与 500 口径方向相反。
  blend（部署口径的实际标的）介于两者之间，正是"不显著"的直接来源；
- **12 格共用 seed=0，且同一窗口下三口径的 n_obs 相同** → 三口径的块索引矩阵**逐位相同**。
  因此"500 为正、1000 为负"的跨口径符号分歧**不是独立的蒙特卡洛噪声**，
  而是同一组重抽样块作用在不同标的上的真实差异——这一点使分歧的读数更干净，
  但也意味着三口径的 p 值**高度相依**，不可当作三次独立确认；
- **percentile CI 未做偏差校正**。判据格 blend/full 的 `boot_mean − d̂ = −0.019`（约 d̂ 的 9%）。
  实测 500/full 格的偏差校正因子 `z0 = +0.069`，作偏差校正（BC，令加速项 a=0）后
  `ci_lo` 由 **+0.030 移到 +0.060**——是**远离** 0 而非跨回 0。
  即：**500 那两格的名义显著性不因 CI 构造而脆弱**，
  不许摘取的理由只是上面的**嵌套 + 多重比较 + 1000 口径反向证据**，不是 CI 的构造问题。
  （加速项 a 未计算，故此为 BC 而非完整 BCa；预登记未要求任何校正。）
- 预登记指定的判据格是 **blend × full**，它**不显著**。

## 4. 方法

**同秤纪律（§4 C4）**：两口径共用 `backtest/baseline.py` / `backtest/engine.py` 的同一 harness，
唯一差异是映射函数：

| 口径 | 映射 | 代码 |
|---|---|---|
| long-flat（部署） | `signal > 0 → +1`，否则 0 | `positions.production_position(θ=0)` |
| 对称多空 | `sign(signal)` ∈ {−1, 0, +1} | `positions.to_position(mode="discrete", θ=0)` |

因子、成本（3bps/边）、T+1 生效、全日历口径、carry、样本区间**逐项相同**。
两口径在 **49.7% 的交易日**上不同（对称持空、long-flat 空仓）；持多 48.97%、双方同为 0 仅 1.31%。

**配对**：两条**净日收益序列**按日期对齐后，同一组日期块索引**同时**作用于两序列
→ 保留同日相关性，检验对象是**差**而非各自水平。重抽样对象是引擎产出的净日收益
（换手成本与 carry 已内嵌逐日），故块内成本结构原样保留。

**检验构造**：H0 = 两口径总体 Sharpe 差 = 0。
CI = bootstrap 分布的 2.5/97.5 分位；p = 把 bootstrap 分布平移到 0 近似零分布后的双侧值，
`p = (#{|d* − d̂| ≥ |d̂|} + 1) / (n + 1)`。

**不走 IC 秤**（§4 C5）：本探针不改因子，只比同一因子在不同映射下的策略收益序列，
判据在 Sharpe / MaxDD / 换手层，与偏 IC 无关。

**新代码位置**：`backtest/paired_bootstrap.py`（新建）。
`significance.py`（单策略循环移位置换）与 `baseline.py` **未作任何改动**；
冻结根 `signals/ selection/ research/ factors/ stock_selector/data/` 未触碰。
单元测试 `tests/test_bt_paired_bootstrap.py` **7 项通过**
（向量化 Sharpe 与 `metrics.sharpe` 逐值一致、块内连续性、同序列 → 差恒 0 且 p=1、
尺度不变性、同种子可复现、强差异样本能拒绝 H0）。

## 6. 未预登记的实现自由度及取值

预登记只钉死 **block=20 日、n≥1000、报 CI 与 p**。以下自由度由本次实现选定，
**均为一次选定、一次运行，未做任何"多试几个再挑"**：

| # | 自由度 | 取值 | 选取理由 |
|---|---|---|---|
| 1 | 块的重叠方式 | **重叠（moving block）**，起点在 `[0, T−20]` 均匀 | 教科书默认；非重叠会把有效抽样单元从 3,046 降到 153 |
| 2 | 环绕（circular wrap） | **不环绕**，末块截断到 T | 避免人为把 2026 年末尾与 2014 年初拼接。**代价**：首尾各 19 个观测的期望入选次数只有中段的约一半（实测 0.51 / 0.50 次每抽样 vs 中段 1.01）；该 38 个观测在 T=3,065 的 full 窗占 **1.2%**（可忽略），在 631 日的 2024-2026 窗占 **6.0%**（该窗本就最不精确，CI 宽度 ±0.8） |
| 3 | 块数 | `k = ceil(T/20)`，拼接后截断到 T | 保证重抽样序列长度 = 原样本长度 |
| 4 | 重抽样次数 n | **10,000**（预登记下限 1,000） | 只降蒙特卡洛噪声、不影响估计量；p 的 MC 标准误 ≈ 0.005 |
| 5 | 随机种子 | **0** | 仓内既有约定（`significance.py` / `baseline.py` 默认 seed=0） |
| 6 | 重抽样对象 | **引擎产出的净日收益序列**（成本+carry 已内嵌），非"重抽仓位再跑引擎" | 保持严格配对；块内成本结构原样保留 |
| 7 | p 的构造 | **平移到 0 的双侧 bootstrap p**，`(#{\|d*−d̂\|≥\|d̂\|}+1)/(n+1)` | +1 修正与 `significance.py` 一致 |
| 8 | CI 的构造 | **percentile 95%**（2.5/97.5 分位） | 与 p 同一分布读出，无需额外假设 |
| 9 | 覆盖面 | `equal_weight` × 3 口径 × 4 窗 = **12 格全报**，判据格开跑前钉死为 blend/full | 无事后挑选；全部结果见 §3 |
| 10 | 成本 | `cost_bps=3.0` | harness 默认，两口径同值 |

## 8. 局限与附注

1. **样本外程度**：三窗均已被历次决策消耗（勘误 §3：2024-2026 一律称"第二验证窗"）。
   本检验是对**已有样本**的统计推断，不是新的样本外验证。
2. **carry 样本边界（§4 C6）**：`futures_daily` 止于 2026-04-29，
   2024-2026 窗末 **70/631 个交易日**两口径均按 carry=0 计。
   按 `engine.run_strategy` 的口径 `carry_ret = pos_eff × carry / 245`（正 carry = 贴水），
   缺 carry 段**多头少计贴水收益、空头少付贴水成本** → 机械上**不利于 long-flat**、
   有利于对称口径的空头腿。**此结论以"2026-05 后 IC/IM 延续贴水"为前提**——
   该段恰无观测，若期间转升水则方向反转。若前提成立，2024-2026 那格 +0.269 的差
   补齐 carry 只会更大，而它本来就不显著。
   （此方向系直接读 `engine.py`/`data.py` 得出；与议程 §4 C6 原行文方向相反，
   经独立 QA 以三条依据仲裁确认，议程侧已同批勘误。）
3. **不显著 ≠ 两口径等价**。**MaxDD 与换手**两项在 blend 三窗（乃至全 12 格）方向
   **全部一致**地偏向 long-flat；**Calmar 则是 9/12**，例外集中在 **2021-2023**——
   该窗 long-flat 年化收益跌到 **11.7%**，压过了 MaxDD 更浅的优势
   （blend 2021-2023 Calmar 0.893 lf vs 1.517 sym；500 为 0.781/1.167、1000 为 1.005/1.887）。
   换手是 **≈2:1** 的结构性关系（对称口径每次翻向要做双倍交易；实测比值
   **2.000~2.013×**，非严格 2:1 是因为 1.31% 的零信号日）。
   这些都不依赖 Sharpe 的统计检验。本文只检验了 **Sharpe 差**，因为预登记条款只覆盖它。
4. **本检验不覆盖 ①b**（θ_L / 滞回带 h / 部分空头权重 w_S 的 32 点网格）。
   ①b 排在候选 ⓪（置换选优机器改造）之后，未在本批次执行。
5. **对 `to_position(discrete, θ=0)` 的一个口径事实**：`signal == 0` 恰好落 0 仓
   （3,065 日中 1.31%），故对称口径并非严格的全时段满仓多空。
6. **既有 harness 的一个已知问题（本次仅登记，不改码）**：`engine.py:24`
   `trade.iloc[0] = abs(pos_eff.iloc[0])` 的**意图**是收首日建仓成本，但
   `pos_eff = position.shift(1).fillna(0.0)` 令 `pos_eff.iloc[0]` **恒为 0**，
   该行实际只起"把 `diff()` 的首个 NaN 填成 0"的作用（这一点是必需的，否则首日收益为 NaN），
   真正的建仓成本落在**第 2 天**。两口径对称承受，**配对差完全不受影响**。
   由独立 QA 越界发现，登记于此供后续动 harness 时处理。
