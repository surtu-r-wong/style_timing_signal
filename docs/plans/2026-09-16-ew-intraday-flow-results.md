# equal_weight开尾盘资金流：多空独立首轮结果

**本批四个多头过滤规则均弱于原多头；空头B_neg有描述性改善，保留为复核项，不替换现役。** 大部分组合Sharpe提升通过降低空头仓位已能取得，开尾盘过滤相对固定半空的额外Sharpe约0.03；历史收益和回撤仍有进一步改善，但存在分窗不均衡和已用历史选优。

用户关于买入额的说明仅为解释大小单名词，已撤销此前助手误加的字段代码追问。按用户已确认的10点前/14:30后主力净流入、当天发布、历史不修订继续研究。金额单位按元记录，不改库值。

## 范围与证据

[固定规格](2026-09-16-ew-intraday-flow-pilot.md)在本批收益运行前保存。主run为`20260916-ew-intraday-flow-pilot-r1`，[完整报告](../../backtest/output/runs/20260916-ew-intraday-flow-pilot-r1/outputs/REPORT.md)和[全指标表](../../backtest/output/runs/20260916-ew-intraday-flow-pilot-r1/outputs/metrics.csv)包含8个单腿候选、25组合及控制/同暴露参照，3个执行情景共153本账。未做收益后调参。

所有比较采用共同窗口 **2016-02-15～2026-09-03，2,568个交易日**。实际IC/IM合约、次日收盘、单边3bp；IM上市前100%IC，之后IC/IM各半。采用分数合约与每日目标敞口恢复，不是账户实盘收益。与旧现货代理或起点不同的历史基线不能直接拼表。

A=剔除全天主力净流入比例和当日板块涨跌后的尾盘残差；B=同样剔除后的“尾盘−早盘”残差。回归仅用过去250日，两板块等权、20日平滑。残差并不保证未来独立或预测力。

B_neg的精确含义：**EW指空时，只有B的20日均值为正（或abs<=1e-12中性）才保留做空，否则空仓。** 这不是“尾盘原始净流入为正”，也不是“尾盘弱才做空”。正反两种方向在跑前均已登记，不能事后将本结果讲成唯一先验。

四个多头规则在两个等长半窗的CAGR和Sharpe也均低于原多头，未形成改动多头的依据。空头B_neg收益/Sharpe改善的同时，胜率从60.71%降到55.42%，闭合段数由56增至83；不能把它称作胜率优化。

“仅控制变量拟合部分”的B分数在共同窗口2,568日全正，因此其反向空头规则退化为原空头，正向为空仓。这一控制对照本身缺少状态变化，不应夸大为通过了强动态替代模型检验。A拟合分数只有300日为正，完整对照数据保留。

表中前三者和过滤方案均为同一账户独立复算，不相加两个单腿复利收益。固定半仓和同暴露组合是在看到首轮结果后，**事先记录补验口径再运行的归因对照**；不冒称原首轮未选优的确认。原组合与过滤组合直接复用首轮账本。补验run为`20260916-ew-intraday-flow-attribution-r1`，[对照明细](../../backtest/output/runs/20260916-ew-intraday-flow-attribution-r1/outputs/control_comparison.csv)。同暴露比例来自已看过的全历史，仅是事后归因参照。

相对固定半空，过滤组合CAGR多约5.39个百分点、回撤浅约7.82个百分点，但Sharpe只多0.030；主要Sharpe改善不能全部归功于新资金流信息。

## 执行和历史稳定性

| 次次日收盘3bp | 29.32% / 1.199 / −35.45% | 30.95% / 1.390 / −19.58% | 1.375 |

改善并未在上述两项敏感性中消失，但相对半空的Sharpe优势缩到约0.015，幅度不大。

前/后半窗各1,284日：原组合CAGR32.03%/34.89%，过滤组合31.23%/39.11%；Sharpe从1.295/1.369变为1.393/1.667。前半窗收益略退步，后半窗改善较明显。2021-23 CAGR也从16.22%降到13.93%；2024后则从54.96%升到70.01%。这些都是复用历史，不能当新样本外。

空头过滤在2018/2022年减少了显著盈利，在2021年完全空仓，2024后改善较突出。完整年度表保留，不以全窗均值遮盖年份取舍；2016和2026是部分年度。

## 沿用七事件的描述性归因

在看到首轮结果后，复用09-15固定的七个事件起点，各10个交易日，共70日；未为本候选新选事件或调窗口。计算的是净收益对数差，不是因果效应。

- 相对原组合，过滤组合全窗相对对数收益+0.12957，其中七窗−0.06253，窗外+0.19210；这七窗不是相对原组合改善的来源。
- 相对固定半空，全窗+0.42639，其中七窗+0.04392、窗外+0.38247；仍有其他时期的增量。
