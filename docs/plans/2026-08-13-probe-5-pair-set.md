## 0. 结论先行

1. **B（500+1000+2000）/ C（单 1000 对）/ D（四对+红利腿）三个候选集合全部 STOP。**
   闸门 ⓪（非偏 rank IC 头对头）三条全不过；收益层三条判据也没有任何一个候选全中。
   → **设计稿 §2.2 悬了一个月的「300 对该不该在等权里」正式关帐：留在等权里。**

   > **⚠️ 证据方向限定（防误引用）**：本次证明的是**挑战者没达到预登记的举证门槛**，
   > **不是**"300 对被证明有正贡献"。恰恰相反，**唯一指向"去掉 300 对"的那把秤，
   > 正是 ⑤(f) 的首闸 rank IC**——B 在五个窗上都**弱高于** A（见结论 2 的秩序轴）。
   > 举证责任在挑战者一侧、而挑战者未过闸 → 维持现状；这是**程序性关帐**，
   > 不构成"300 对有价值"的正面证据。未来若有人引用本报告主张"300 对已被证明该留"，
   > 那是误引用。
2. **"四对等权 = 配对维度的稳健选择"这次有了 OOS 依据——但必须按轴分别陈述**：
   - **收益轴：全面占优。** 在**选择窗**（2014-2023）与**全样本**两把秤上，现役 A 的
     净 Sharpe（1.539 / 1.610）**高于全部候选**；MaxDD（选择窗 −13.5%、全样本 −16.7%）
     **优于全部候选**；剔最强年后的 Sharpe（1.237）**大幅优于全部候选**（次优 C 只有 0.953）。
     **不是"差不多"，是收益轴上的全面占优。**
   - **秩序轴（⑤(f) 的首闸，非偏 rank IC）：A 并不占优，B 五窗全部 ≥ A。**
     diff(B − A) = train **+0.0271** / val **+0.0059** / 选择窗 **+0.0187** /
     full **+0.0210** / holdout **0.0000**。**但五个窗的配对差 98.33% CI 全部不排除 0**
     （最强的 full 窗 +0.0210，CI **[−0.0177, +0.0603]**）→ 按预登记读法 ⓪ 不过。
     即：**秩序轴上现役没有优势，只是挑战者也没有可判定的优势。**
   - *（holdout 2024-2026 上 A 的 MaxDD −16.7% 差于 B −14.2% 与 D −12.2%、优于 C −18.2%；
     该窗**不进任何闸门**，仅报告。）*
3. **唯一一处候选占优的地方，恰是预登记选来当统计量的那一个**：`worst(train,val)`
   —— B 1.098 / C 1.091 vs A 1.001。但差距是 **+0.098 / +0.090**，**低于预登记的 +0.15 门槛**，
   也低于其他候选用过的 +0.10 门槛；且它来自 **A 的 train/val 跨度更大**（1.705→1.001），
   不是 B/C 在任何一窗真的更强（见 §7 边缘读法 1）。
4. **红利腿（D）的最大发现不是它的读数，而是它的身份**：预登记写的 `000922 / H00922`
   实测是**同一条中证红利指数的"价格版 / 全收益版"**（两码日收益 corr **0.9983**、
   净值比 12.6 年从 1.260 漂到 2.175 = **年化 4.43% 的股息**）。
   → 按预登记口径把它们当作一对"成长/价值式对照"构造出来的所谓"红利腿因子"，
   **相对收益的经济含义是分红计提，不是风格对照**。这条腿**该测什么**（红利 vs 宽基）
   **预登记里没有**，我**不自行补**——见 §8 未测项登记，等控制器/用户拍板。
5. **红利腿的前置诊断闸（corr>0.9 → 同源不测）没有触发**（max|corr| = **0.098**），
   但**这道闸这次量错了东西**：它设计来抓"红利≈价值腿"的同源，而在"价格版 vs 全收益版"
   这个退化构造下，相对收益本来就与风格无关 → corr 天然接近 0。**闸没坏，是入参不对。**

> **一句话给控制器**：⑤ 的 (i) 子命题（子集不劣于四对）**证伪**，可以关帐；
> (ii) 子命题（红利腿提供未表达的风格维度）**在预登记的构造下无法被检验**，
> 需要用户决定是否补一个"红利 vs 宽基"的配对定义再测一次（成本 ≈ 半天）。

## 2. 数据诊断：红利腿的真实身份（**本探针最大的单项发现**）

### 2.1 覆盖

| 项 | 值 |
|---|---|
| `000922.CSI` / `H00922.CSI` 原始行数 | 各 **3,066** 天（2013-12-31 ~ 2026-08-11），无空值 |
| 与八条风格指数日历对齐后 | **3,065** 天（2014-01-02 ~ 2026-08-11）——红利日历是风格日历的**严格超集**，对齐只丢 2013-12-31 一天 |
| 产物字段 | `diagnostics.csv` 的 `n_days_aligned_panel = 3065` 记的是**对齐后面板**长度（即上一行），**不是红利腿自身的 3,066**。字段初版名为 `n_days_dividend_leg`，语义易误读，已按 QA M-5 改名 |
| 对 A/B/C 的影响 | **零**：那三个集合的 `pair_configs` 不引用红利两列 |

### 2.2 两码是同一条指数的价格版 / 全收益版（三条独立证据）

| 证据 | 读数 | 含义 |
|---|---|---|
| 两码**日收益** Spearman/Pearson corr | **0.99827** | 同一篮子成分 |
| 净值比 `H00922 / 000922` | 1.2602（2014-01-02）→ **2.1752**（2026-08-11） | 12.6 年累计 +72.6% |
| 该比值的**年化漂移** | **+4.43%** | 恰是中证红利的**股息率**量级 |
| 相对日收益（右−左）年化 | **+4.36%**，日均 +1.78 bp，日标准差 7.6 bp | 分红计提 |
| 相对日收益为负的天数占比 | 37.5%；\|相对收益\|>50bp 的天数占比 0.196% | 存在小幅口径/舍入噪声，不改结论 |

→ **`H00922.CSI` = `000922.CSI` 的全收益版本**（CSI 的 `H` 前缀 + 同数字码惯例）。

### 2.3 这对预登记意味着什么（**必须诚实说清**）

- 现役四对的每一对都是**同一规模档内的成长 vs 价值**，相对收益 = **风格对照**；
- 按预登记把 `000922 / H00922` 当作一对喂进同一台机器，相对收益 = **分红计提 + 少量噪声**，
  经济含义与"风格对照"**不是一回事**；其 z-score 主要由**除息季节性**（6~7 月）驱动。
- 因此：**D 的读数（§4）是"把一条分红计提序列掺进等权平均"的后果，
  不是对"红利风格维度有没有增量"的检验。** ⑤(a) 的子命题 (ii) 在本探针下**仍未被检验**。

### 2.4 前置诊断闸的读数（入档，含"闸量错了东西"的判断）

| 相关性 | 值 |
|---|---|
| 红利腿因子 vs **现役合成因子 A** | −0.0531 |
| vs 300 对分量 | −0.0274 |
| vs 500 对分量 | −0.0243 |
| vs 1000 对分量 | −0.0979 |
| vs 2000 对分量 | −0.0370 |
| **max\|corr\|（最保守读法）** | **0.0979** ≪ 0.9 → **同源判定 = False，D 继续测** |

**但这道闸这次不构成"红利腿与四对无关"的正面证据**：它的预设是"红利指数≈价值腿"，
而在 §2.2 的退化构造下，被相关的对象根本不是红利风格暴露，而是股息计提。
**闸的机制正确、判定按预登记执行、结论不可外推。**

| 候选 | 双窗 IC 均 > 现役？ | 配对差 CI 任一窗排除 0？ | **闸门 ⓪** |
|---|---|---|---|
| B | **是**（+0.027 / +0.006） | 否 | **不过** |

**读法（开跑前钉死，逐字沿用 ③ 的闸门 ⓪）**：候选须在 **train 与 val 双窗** rank IC
均高于现役，**且**配对 IC 差在 **train 或 val 窗**"明确优于而非平手"（CI 排除 0）。
产物 `verdict.csv` 里这一行的标签是
`paired_ic_diff_CI_excl_0(train或val窗, α=0.05/3)`（初版标签写作"任一选择窗"，
易被误读成"含 selection/full/holdout 的任一窗"，已按 QA M-3 改为明确表述）。
→ 三条全不过，按判据顺序**收益层本可不评**；本报告仍把收益层全部读数列出（§4/§5），
因为"关帐"需要它们，而且它们是本探针最强的正面证据（A 在**收益轴**上全面占优；
**秩序轴上 A 并不占优**，见 §0 结论 2）。

**一条负向读数值得单列**：D 在选择窗的 IC **比现役低 0.068**，p=0.020——
在未做 Bonferroni 的 95% 尺度上这已经"显著更差"，做了 Bonferroni（α=0.0167）后差一点。
即：把分红计提序列掺进等权平均，**有接近显著的证据表明它损害预测力**。

## 6. 机器接入与 `p` 的含义边界

### 6.1 接入方式（控制器三规矩逐条对表）

| 规矩 | 本探针 |
|---|---|
| (a) **多候选合成单次调用**统一校正 | 4 个集合（**含现役 A 作为池内对照点**）进**同一次** `selection_permutation_test`。两个统计量族各一次调用，两族是**串联 AND 闸**（⓪ 与收益层都要过），串联不放大假阳率。**另**：闸门 ⓪ 的配对 IC 差检验按预登记 **Bonferroni α=0.05/3 = 0.01667**（3 个候选集合），CI 相应加宽到 98.33% |
| (b) `-inf` 只给**无法评分**的行 | 统计量是纯 `worst(train,val)`；换手 / 集中度 / IC 三条判据是**独立后置闸门**，一条都没编进统计量 |
| (c) `min_shift = 2·max(k)`、`max_shift = n−2·max(k)` | k = 前瞻 20 日 → **min_shift = 40、max_shift = 2394**（n_obs = 2434），代码路径 = `shift_bounds(len(common_sel))`（判例 `test_shift_bounds_is_the_path_run_probe_actually_uses`）。**IC 族**这条下界是硬要求（防移位后前瞻窗与原窗机械重叠）。**收益层族本身无前瞻窗**，沿用同一区间的理由是**两族共用同一份索引矩阵、可逐行对表**——见下方勘误 |

> **⚠️ 勘误（QA I-3，初稿此处写反）**：初稿称收益层族沿用 `[2k, n−2k]` 是"更保守"，
> 论证是"下界更大 → 残留配对更少"。**方向反了**：小位移正是最可能残留真配对、
> 因而给出**高**统计量的那些行；把它们剔掉会**削薄空分布的上尾** → `p_selected` 偏小
> → 对收益层族是**轻微反保守**。
> **为什么不 load-bearing**：本探针的四条判据**一条都不读 p**（`p_selected` 只作诊断，§6.3），
> 裁决完全由阈值型判据决定，故该偏向不影响 STOP。
> **纪律**：若日后有人把 p 升格为闸门，收益层族必须改用**去相关长度**定下界
> （①b `choose_min_shift` 的 ACF 梯子做法），不能沿用 IC 族的 2k。
> IC 族的 2k **不动**（那里是前瞻窗的硬要求，不是保守性论证）。
| 变体 = **已算好的仓位序列** | 收益层族重排的是 `production_position` 后的 {0,1} 仓位 → 循环移位**精确保持换手**（判例 `test_rotation_preserves_turnover_of_position_series`），成本项不失真。IC 族重排的是因子本身（IC 作用在因子上） |

**Bonferroni m 的落点与量纲（QA M-4）**：**m = 3 是预登记原文**（"3 个候选集合 → α=0.05/3"），
本探针照办、**未按实际展示的行数重算**。三个数字要对得上：
产物 `probe_5_pairset_ic.csv` 的配对差表是 **4 挑战者 × 5 窗 = 20 行**
（含**非闸门**诊断集合 `D_rev` 与仅报告的 holdout / full 窗）；
**闸门实读的只有 3 候选 × 2 选择窗 = 6 条**；预登记的 **m = 3**。
→ **m=3 相对"实读 6 条"偏松**（对候选**过闸**更宽松，即本次 STOP 的判定是在更宽松的尺度上做出的）；
**相对"展示 20 行"偏紧**（对 D 的**负向**结论更保守，即 §3.2 那条"掺分红计提损害预测力"
是在更严的尺度上仍接近显著）。**两个方向都不改本次裁决。**
同一段说明也写进了 `summary.json` 的 `gate_readings.bonferroni_note`。

### 6.3 三条必须写明的边界（**否则这两个 p 会被误读**）

1. **`p_selected` 回答的不是"B 比 A 好"**。零假设是"信号与收益的时间配对被打断"，
   观测统计量是 4 个集合里的**最大值**。`p=0.001` 只说明**"这一族风格择时因子里最强的那个，
   其 worst-tv Sharpe 1.098 靠错配几乎得不到"**——现役 A 单独也能给出同量级的统计量
   （A 的 naive p = 0.0020）。**它不构成任何"该换集合"的证据，本探针的裁决也没读它。**
2. **`p_naive` 只作对照**。IC 族的 `selection_inflation = 1.375` 就是"机器修好了"的现场证据
   （旧做法会把 p 从 0.011 压到 0.008）；收益层族 inflation = 1.00 是因为观测赢家已经打穿
   1000 次置换的全部行（p 触到 `1/(B+1)` 地板），两个口径**同时**触地板，比值退化为 1，
   **不代表"这里没有选择效应"**。
3. **空分布下 4 个变体都当选过**（sharpe 族 219/200/336/245；IC 族 150/206/327/317）
   → 没有某一个变体霸占 max、min-P 与 max-statistic 结论一致，机器工作正常。

## 7. 边缘读法（**诚实列出，供 QA 攻击**）

1. **`worst(train,val)` 这把秤唯一地偏向 B/C，而它是预登记的统计量。**
   B 1.098 / C 1.091 > A 1.001。但把秤换成**选择窗整段**或**全样本**，A 立刻回到第一
   （1.539 / 1.610 vs B 1.200 / 1.370、C 1.329 / 1.406）。原因是 **A 的 train/val 跨度更大**
   （1.705 → 1.001），而 `worst` 只看短板。**B/C 没有在任何一窗打败 A 的绝对水平**——
   B 的 train 只有 1.238（A 1.705）、C 的 train 1.404。
   → 若有人主张"该换 B"，他实际主张的是"用 worst-tv 这一个数字覆盖其余全部证据"。
2. **门槛敏感性：把 +0.15 换成其他探针用过的 +0.10，B/C 仍然不过**（+0.0975 / +0.0902）。
   换成 +0.05 则两者都过判据① —— 但**判据③（集中度）会独立杀掉两者**
   （0.884 / 0.953 vs 1.237），**判据②再杀 B 一次**。→ **裁决对门槛不敏感。**
3. **闸门 ⓪ 读法敏感性**：若把 ⓪ 弱化成"只要双窗 IC 都高于现役"（去掉"明确优于而非平手"
   的 CI 条款），**B 会过 ⓪**（+0.027 / +0.006）。但 B 随后被收益层的判据①②③**全部**挡下，
   **最终裁决不变**。C 与 D 在任何读法下都过不了 ⓪。
4. **holdout（2024-2026）上 B 是第一**（1.984 vs A 1.859），C 最差（1.688）。
   这一段**不进闸门**（§7.3 纪律），列在这里只为不藏数据；且 val 与 holdout 的排名**互相打架**
   （val：B>C>A>D；holdout：B>A>D>C），本身就说明这些差距在噪声量级。
5. **`D_rev`（红利腿方向反转的诊断变体）在 IC 上是全场最高**（选择窗 0.2406、val 0.4550）。
   **不要读成发现**：(i) 它不是预登记集合，不进机器、不进闸门；(ii) 其构造是 §2.2 那条
   退化的价格版/全收益版对照，方向反转等价于"把分红计提**加**进平均"而不是减；
   (iii) 它的配对 IC 差 CI 仍不排除 0（选择窗 [−0.024, +0.110]）；
   (iv) **收益层它照样输给现役**（worst-tv 0.951 vs 1.001，选择窗 Sharpe 1.422 vs 1.539）。
   它存在的意义只有一个：证明 D 的失败**不是我挑了对自己有利的腿方向**。
6. **D 的负向证据接近显著**：选择窗 IC 比现役低 0.068，p = 0.020（Bonferroni α=0.0167，差一点）。
   在 §2.2 的构造下这不奇怪——掺进去的是分红计提序列。**不作为"红利风格无用"的结论。**

## 12. 局限与附注

1. **前瞻收益的窗口边界**：`forward_return` 在窗口末端会跨过窗界取收益（沿用 `fusion_probe`
   口径），故 val 窗最后 1 个非重叠样本点的前瞻收益落在 2024 年初。
   影响面 = **每窗至多 1 个观测**，且**四个集合共用同一张网格** → 头对头比较不受影响。
   若要彻底切断，需改 `fusion_probe` 的实现（属跨探针口径变更，本探针不做）。
2. **val 窗只有 37 个非重叠样本点**，IC 的配对差 CI 因此很宽（±0.09~0.15 量级）。
   "CI 不排除 0"在这个样本量下**部分是功效问题**，不是"证明了相等"——
   §7 边缘读法 3 已给出弱化读法下的结论（不变）。
3. **carry 样本边界（§4 C6）**：blend carry 止于 2026-04-29，2026-05 之后的评估段没有 carry 输入
   （对多头略偏悲观）。本探针的四条判据**全部落在 2014-2023 选择窗**，不受影响；
   受影响的只有 holdout 与 full 两个**仅报告**的窗。
4. **932 系回溯段**：按 §7.1 问 0 的裁决"不核"，作为选样原则的一部分接受，结论不带星号。
5. **`D` 的读数不能外推到"红利风格无用"**（§2.3）。这是本报告最需要防误读的一条。
6. **本探针不动任何生产文件**：未改 `deploy/`、`signals/`、`production.py`、
   `config_4pairs.csv`、`index_codes.csv`、任何既有探针、任何冻结根。
