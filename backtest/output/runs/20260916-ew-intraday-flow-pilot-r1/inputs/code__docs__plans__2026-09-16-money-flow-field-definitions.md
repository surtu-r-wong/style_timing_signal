## 开尾盘候选草案（未冻结、未看收益）

优先使用沪深300和创业板全板，科创板短历史暂不新增为选优维度。与旧全天F1/F2区别在于研究日内净流入构成的增量；旧研究裁决不重开。

设O为10点前主力净流入、E为14:30后主力净流入、I/U为全天主力流入/流出，G=I+U。按已提供的字段定义和单位，定义`o=O/G`、`e=E/G`、`f=(I−U)/G`。G必须为正，异常或缺值不补零。`e−o`是两个时段总净额的归一化差，不是每分钟流速差，也不预设两个时段等长。

候选A：尾盘净流入的独立部分。对各板块e_t，用t之前250个完整交易日的OLS控制截距、全天f和板块自身日收益r，得到当日残差。系数只用过去；当日f/r属于收盘后输入。

候选B：开尾盘差的独立部分。对各板块(e−o)_t采用同样的控制与预热。A/B均要求两个板块有效，板块残差等权后取固定20日均值；不在此阶段扫描窗口。若控制矩阵不满秩或输入缺失，该点无效并显式报告，不悄悄改模型。

首批只在现役对应方向上做开/关过滤：每个候选的正向和反向解释均预先纳入，因此每条腿4个规则（A/B×2方向），共8个单腿规则。多头可用A而空头用B，也可一侧维持现役；零分数保持对应现役腿，避免人为以精确零再添加一个选择维度。数值实现时统一规定零判定规则。

组合评价应列出基准1项、仅替换多头4项、仅替换空头4项、两侧替换16项，共25个不同持仓规格；不能事后只公布两侧赢家相拼。两侧共享同一EW方向开关，初批不会同时持多与持空。按同一账户权益重算合约数量和成本，分腿独立复利的收益不能直接相加。

候选须与原腿、仅全天流/价格控制、同暴露缩仓参照区分比较，才能判断是新信息还是降低风险敞口。以上参照的精确定义、评价窗口、成本敏感性和裁决规则仍需写入正式冻结规格，本草案不作为可直接执行的完整预登记。

## 买入额与净流入的解释

“指定日内……买入金额”是用户贴出的第三段字段说明，按字面为选定日期、指定订单档位的买入总额，不是新增数据需求。买入金额应非负；净流入=该口径买入金额−卖出金额，可以为负。挂单金额是用户说明中的分档依据，与最终汇总字段是买入还是净额是两个不同问题。

例如超大单买入800万元、卖出1000万元，则超大单净流入−200万元；大单买入400万元、卖出100万元，则大单净流入300万元。两档主力买入1200万元、卖出1100万元，主力净流入100万元。这是演示数字，表述单位为万元便于阅读，不修改用户所述原始字段单位元。

此处概念解释继续保留，但用户粘贴该段的用途仅是说明分档名词；不需要为本批开尾盘研究确认买入额字段代码。
