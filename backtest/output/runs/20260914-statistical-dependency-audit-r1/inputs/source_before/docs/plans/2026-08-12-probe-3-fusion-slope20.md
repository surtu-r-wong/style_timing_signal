### 4.2 机制解剖：为什么融合低于**两个**母因子，而不是居中

**入库重算**：本节所有数字由 `build_divergence_report()` + `summarize_divergence()` 产出，
逐日明细落 `backtest/output/probe_3_fusion_divergence.csv`（3,065 行全样本 + `divergent` 标志列），
标量落 `probe_3_fusion_verdict.csv` 的 `divergence_*` META 行。TDD 见 §7。

**恒等式（代码运行期校验，`follows_equals_larger_abs = True`）**：long-flat 下两腿在分歧日
**严格互补**（一腿 1、一腿 0），且 `(a+b)/2 > 0` ⇔ **跟随 |·| 较大的那一腿**（并列 → 跟空仓腿）。
由互补性得 **`capture(现任) + capture(替补) = Σ fwd(分歧日)`**，即"可得收益"，
**随机仲裁的期望恰为其一半**。

| 分歧日（3,065 日中 **568 日 = 18.5%**） | 数字 |
|---|---|
| 可得收益 Σ fwd（T+1 毛收益，未计成本/carry） | **+72.93%** |
| ├ 现任捕获（跟现任 328 天） | **+38.32%** |
| └ 替补捕获（跟替补 240 天） | **+34.61%** |
| **融合实际捕获** | **+8.32%** |
| **捕获率 = 融合 / 可得** | **11.4%**（随机仲裁期望 **50%**，即 +36.46%） |
| 随机仲裁的 95% 区间（随机化检验，n=10,000, seed=0） | [+2.37%, +71.56%] |
| 随机化检验 p（左尾 / 双侧） | **0.0545 / 0.1090** |
| 择边正确率（选中当日实际更优的一腿） | **260 / 568 = 45.8%**（二项 p = **0.0485**） |

**如实结论（点估计强、统计支持只到边缘）**：
- **点估计层面这是反向选择，不是噪声仲裁**：融合只拿到可得收益的 **11.4%**，
  比抛硬币的 50% 差 **约 4.4 倍**；择边正确率 **45.8% < 50%**，二项检验 **p = 0.0485**。
  这一点很重要——**噪声仲裁的期望是居中**，解释不了"六格全劣"；只有系统性站错边才解释得了。
- **但收益加权的随机化检验没过 5% 门槛**（双侧 p = 0.109；随机仲裁自身的 95% 区间
  [+2.4%, +71.6%] 极宽，包含实测的 +8.3%）。即"融合在分歧日站错边"**方向明确、量级可观，
  但两项检验一个边缘显著（择边率 p=.049）、一个不显著（收益加权 p=.109）**。
- 两个统计量的落差本身有信息：择边率只低 4.2 pp，捕获率却掉到 11.4%
  → **错边集中在幅度大的日子**。这是描述，不是已检验的因果。

**⚠️ 因果假说（未检验，不作结论）**：一个候选解释是两因子都经 `tanh(z/2)` 压缩后
**幅度跨因子不可比**（slope20 用 zw120、现任用 zw40，同一个 0.2 不是同一件事），
于是"|·| 较大者胜出"这条隐式仲裁规则挑的是"z 窗更短、更容易冲高"的那一腿而非更可信的那一腿；
分歧日恰是两腿都弱的日子（分歧日 |现任| 中位 **0.176** / |slope20| 中位 **0.127**，
vs 全样本 0.370 / 0.293），仲裁尤其脆弱。

### 5.2 检验强度的已知不足（误差方向已判明）

- **F6 的 i.i.d. 配对 bootstrap 只打断了"观测点之间"的依赖，没有处理因子侧自身的自相关**。
  相对仓内先例（`rotation_probe.shift_permutation_pvalue` 用**循环移位**，
  自述"保留信号与收益**各自**的自相关结构、只打断二者配对"）**本处偏激进**。
- **误差方向对本报告的结论是保守的**：忽略残余自相关会让 CI **偏窄**、p **偏小**，
  而本处的结论恰是"**差异不显著、判平手**"——用一把偏窄的尺子仍然量不出显著差异，
  换成更保守的循环移位只会让 CI 更宽、更不显著。**⓪ 的"平手"判定因此反向稳健。**
- 同理适用于 §4.2 的随机化检验（逐日独立抛硬币，未保留分歧日序列的自相关）：
  p = 0.109 在更保守的口径下只会更大，故"收益加权证据不显著"这一表述稳健；
  反过来，**若日后要把 §4.2 的反向选择升格为可引用的实证，必须先换成保留自相关的检验。**

## 8. 建议记入的结论（供控制器裁决后落账）

1. **③ STOP：不融合。** 部署对象维持 `equal_weight`（20d/z40/sm5）+ long-flat，日更链路零改动。
2. **slope20 的第一替补身份维持**（不升格、不降级）。它在 val 窗的相对强势（long-flat 1.398 vs 1.001）
   是**regime 应试变体**的价值，与"换主信号"是两件事——后者在同秤非偏 IC 上仍是平手。
3. **新增可写进"勿重开"的实证（只写可证伪的观测，不写未检验的因果）**：

   > `corr ≈ 0.82` 的两个同族风格择时因子做**预登记单点因子层等权融合 `(a+b)/2`**，
   > 在 `baseline.py` 同秤下**不产生分散收益，反而低于两个母因子**：
   > 500 / 1000 / blend 三口径 × train / val 两窗**六格全劣**（−0.13 ~ −0.19 Sharpe），
   > 对称映射同向；worst(train,val) 由现任 1.001 降到 0.828（闸门要求 +0.10）。
   > 伴随观测：两腿仓位分歧日占 18.5%，融合在这些日子只捕获可得收益的 **11.4%**
   > （随机仲裁期望 50%），择边正确率 45.8%（二项 p = 0.049）。

   **适用边界（必须随条目登记）**：本次证伪限定于"**符号/阈值映射（long-flat / 对称）
   × 未做跨因子幅度归一的 z-tanh 因子 × 50/50 单点**"。
   比例映射（`proportional`）、幅度归一后的融合、非等权配比**均不在证伪范围内**，
   本探针**不为其背书也不预测其结论**；若日后要做须换命题、重预登记（不建议现在做）。

   **不得写进条目的**：§4.2 的"tanh 幅度跨因子不可比导致仲裁劣化"是**未检验的因果假说**；
   §4.2 收益加权随机化检验 p = 0.109 **未过 5% 门槛**，故"反向选择"只能作为
   **点估计 + 边缘显著的择边率**陈述，不能作为已确立的机制写进勿重开清单。
4. **①a 的基线表述纪律继续生效**：long-flat 是风险偏好选择（MaxDD/换手占优），
   无收益优势的统计证据（p=0.373）。
