# 被否决信号的事件依赖审计（描述性）

用户授权：审查既往被否决候选是否因为错过少数事件行情而落后现役。此计划在事件收益分解前保存；不改生产映射，不重新优化候选，不把事后剔除事件当可交易策略。

## 范围与分母

逐项盘点research_registry的63条记录，优先审计40项STOP/ALL_FAIL；将统计方法、数据/结构、增量不显著、收益/风险门槛分开。网格未选中参数与整项研究被否决不是同一计数单位，独立列示。登记外已有未采用的固定生成器补充纳入，不冒称历史搜索全集。每项明确已重建、部分覆盖、不适用或缺证据。

## 预先固定的事件定义

以A股首个可反应交易日为锚：2018-03-23（301行动）、2018-06-19（6月关税清单）、2019-05-06（5月升级威胁）、2019-08-02（8月升级威胁）、2024-09-24（金融政策组合）、2025-04-03（4月2日美国关税）、2025-05-12（日内瓦会谈周末进展）。最后一项基于05-12开盘前进展消息，15:00正式声明另以05-13锚作敏感性，不能说正式声明在开盘前已知。

主窗口为事件锚起10个交易日，固定参考1/5/20日；所有事件窗口取并集避免重复累计。同时报告仅9·24、仅关税事件和逐事件归因。方向包括利好/利空，不按候选输赢选事件。日期来源另存events.json。仅此清单不代表全部历史重大事件。

补充：按同窗blend绝对日涨跌取最大的5/10/20日，统一对所有候选删除作无标签尾部敏感性；不得把候选自身最差日用于挑事件。

## 算法

1. 复用冻结价格和修复后carry，重建原候选仓位或读取逐日账本；仓位日期、预热、k日换仓起点保留原定义。缺原数据不猜造。
2. 保留原完整市场/信号路径，先算完整逐日收益。事件中性结果将同一事件日期的收益设为0、保留日历，绝不先删价格再重算信号。该结果是观察收益归因，非事件未发生的因果反事实。
3. 全期及2014—2020/2021—2023/2024—2026分开，含worst(train,val)；分别报告候选和基准的Sharpe、对数收益、最大回撤、事件/非事件相对对数收益。对数相对收益差可以逐日精确相加；Sharpe差不能当收益贡献相加。
4. 同秤基准：对称候选对EW对称；历史long-flat候选对EW long-flat，并另对当前slope现货long-flat。持仓映射跨方向候选注明风险口径。主旧引擎shift(1)相当于T收盘，shift(2)代表买卖均次日收盘，作为执行敏感性。成本每边3bps；期指方向代理沿用修复后carry，现货不含carry。
5. 计数：全期原本落后而主事件窗口中性后领先的候选是“排序反转”；窗口5/10/20及执行时点/分段一致性单列。仅事件中性后收益仍低于基准者不计入反转。没有相应历史否决门槛的候选，不能把反转说成否决被推翻。
6. 尽量分辨事件发生前已有仓位与后续响应：逐事件记录锚日前已知仓位、首次换向时点和事件路径；不声称识别了政策文本或证明纯运气。

## 验证与产物

新建不可变run：inputs/保存计划、登记、使用数据和代码；outputs/保存登记覆盖表、候选清单、事件日历、收益归因、排序反转和报告；manifest记录哈希、完成状态及未覆盖项。验证逐日引擎与已归档账本/独立标量公式一致、归因恒等式、事件并集、时点无前看。每个本地Python命令2GB虚拟内存上限和单线程数值库。

结论限于实际覆盖的候选及这些事件窗口；无法从一个反转推出该候选更好，也不接受“未反转所以无效”的过度表述。
