对四个历史提交的扫描CSV分别执行“族内最大三窗最差Sharpe”和“族内最大train/val最差Sharpe”，结果完全一致：

| 改后两窗最差 | L20 / skip0 / zw120 / sm0 | 1.397922 |

评分只是当时表中数值，不是新的绩效估计。174行是最后保存的合并扫描表行数；不能把84+120+174相加当独立试验次数，也不能当作全部研究尝试的上限。

**另有一处证据缺口**：`98f22f2`与`f7ad5b1`里的 `scan_momentum.csv` Git blob完全相同，当前HEAD也未改写该表。代码 `run_head2head` 读取扫描表选代表，再按新引擎评估代表。因此可确认“规则改变、代表改变、head2head重跑”，但不能确认“carry修复后全网格重新计算并选优”。本机未保存的临时运行仍无法排除；本轮不为填补这个缺口重新优化参数。
