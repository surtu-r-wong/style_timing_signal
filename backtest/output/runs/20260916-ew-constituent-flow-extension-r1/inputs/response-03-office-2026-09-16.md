## 1. 字段字典

| 消费含义 | 字段 | 参数 |
|---|---|---|
| 分档**买入**金额 | `mfd_buyamt_d` | `traderType=N` |
| 分档**卖出**金额 | `mfd_sellamt_d` | `traderType=N` |

`traderType` 取值 **1=超大单 · 2=大单 · 3=中单 · 4=小单**。

**主力 = 超大单 + 大单**，所以：

```
I（全天主力流入总额）= mfd_buyamt_d(traderType=1) + mfd_buyamt_d(traderType=2)
U（全天主力流出总额）= mfd_sellamt_d(traderType=1) + mfd_sellamt_d(traderType=2)
```

**一个档位一次调用**（`traderType` 是标量参数），所以 I 与 U 合起来需要**两次调用**、
每次同时取 buy 与 sell 两个字段。
