# equal_weight资金流：段龄匹配诊断结果

2026-09-17，按[固定规格](../../../../../docs/plans/2026-09-17-ew-holding-age-audit.md)完成，run=`20260917-ew-holding-age-audit-r1`。

## 结论

**在本次事后对照下，两个退出版本的历史改善不能仅用平均段龄仓位结构解释，但收益优势仍不稳健。** 新P1源只控制退出/进场加退出，相对逐龄同暴露对照的组合Sharpe增量为+0.075/+0.055；旧源为+0.080/+0.060。把各自最有利5日的双方收益置零后，四个增量全部转负。后半期只控制退出仅约+0.016，进场加退出略负；候选尾部日损失也大于分数仓位对照。

这不推翻[上轮审计](../../../../../docs/plans/2026-09-16-ew-exit-mechanism-results.md)：更严格的同暴露缩放daily比较下，新源退出增量小且后半期负、旧源全期负。年龄对照和daily对照回答不同问题，不能用前者较容易超过来绕过后者。本轮未确认资金流预测力，也未提出新的可部署持有天数规则。

最长原段56天；不足5个原段支持的高段龄共涉及23个决策日，未丢弃或平滑。以新源只控制退出为例，p(1)=1，p(2)=0.4667，p(10)=0.3243，p(20)=0.2333，p(30)=0.2667；后者上升来自仍存活的长段样本组成变化，不能将这个曲线当作单调退出概率。

独立空头CAGR：新源daily/只退出/进退为8.29%/8.60%/8.31%，各自对照4.02%/3.01%/2.99%；旧源为10.66%/8.75%/8.46%，对照4.26%/3.07%/3.05%。这些是含空仓日的全日历口径，不是持仓日年化。

新源只退出的组合最大回撤−15.07%，对照−16.80%；进退为−16.33%，对照−16.45%。但候选最差5%日均收益分别−2.732%/−2.731%，对照−2.333%/−2.307%。较好的最大回撤不能概括为所有尾部指标改善。

新源只退出年化换手34.970，对照35.401，年化成本1.049%对1.062%；进退换手30.769对31.198。候选成本略低，但高成本下相对优势上升含有对照换手更高的贡献，不能当成资金流信息变强。

旧daily最好5日置零仍正，并不解决旧WSET与P1的聚合口径疑点，也不能据此选旧源。六条规则及三情景全部保留，没有把表现最好的一个升格为赢家。

- 新增6项针对性测试通过，F/E9检查通过。源run六份输入的SHA-256和复制结果核对通过。
- 36本新账全部通过账户、分腿、交易损益恒等式；6本代表账与原contract_ledger逐日收益最大差为0。45本复用账逐日核对目标及成交延迟。

- 12个年度独立空头Sharpe差为空，均为2021年daily或entry_exit全年度空仓、零波动导致。原通用`describe`在`metrics.csv`按既有约定输出Sharpe=0，`comparisons.csv`保留无定义的NaN；不据此比较该年Sharpe。运行日志的除零警告对应这些行，不是行情缺失或回测失败，明细在`postcheck.json`。

办公室最新可读回复仍为09，源端关键聚合异常原因未知。当前研究使用冻结文件，不受工作树日更输出变化影响。没有取新数、发函、修改数据库、生产、调度或前瞻协议；未提交/推送。

本轮完成“平均段龄是否足以解释改善”的有限诊断。它不支持把改善全部归为机械缩短持仓，也不足以启动候选确认。退出机制仍归档为稳定性发现、预测增量未确认；后续若继续扩展，应先定义不同的经济机制或取得新证据，不在本样本继续选择持有天数、窗口和阈值。
