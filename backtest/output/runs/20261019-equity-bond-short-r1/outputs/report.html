股债比值能否构造纯空头信号？

研究日2026-10-19；数据截至2026-10-16。所有规则只允许做空/空仓；组合诊断可用半仓空头。未部署生产。

本轮证据支持把股债比值用于限制现役空头，尚不支持以两条指数独立产生一个稳定的新空头信号。

IC/IM上，独立趋势主规则年化复合收益−1.07%、最大回撤50.66%；27组趋势参数全期复合收益均为负。持续持空到收敛的补充主规则也亏损。现役EW空头附加R>1限制，则从年化8.90%提高至12.23%，但改善约75%来自2015—2016，执行延迟和阈值会影响结果。保留研究候选，不宣布已验证有效。

1. 固定规则和对照

R = H00300.CSI收盘 / 885007.WI收盘，沿用原始点位。独立主规则：R>1.05、R低于自身60日均线、R的20日变化为负，三项同时成立才持空−1，否则0。三项均只用截至信号日的数据。其含义是同时要求距离债基有回落空间、相对趋势已经转弱，不能仅凭点位较高就做空。

首轮冻结规格：protocol.json。27组邻域参数为底线1.00/1.05/1.10 × 均线40/60/120日 × 变化10/20/40日；全部报告，不挑最好者作结论。普通股指趋势、无底线的比值趋势、高位转弱、现役EW及交集/并集/各半都为预设对照。

保留的纯空头研究候选：short_position = -1 if equal_weight_position < 0 and R > 1.00 else 0。当比值重新回到1以下或EW不再看空时平空；恢复条件后可再次开空。它沿用EW判断开空方向，债基负责限制低位空头。1.05作为敏感性阈值保留，未宣布为最优。

2. 数据与成交

共2795个交易日，2015-04-16—2026-10-16。两指数复用前轮Wind冻结数据，现役信号冻结CSV；IF/IC/IM来自本轮只读PostgreSQL快照。未调用新的Wind采集或写共享库。

主口径为IC；IM有首个报价的下一交易日起改IC/IM各半。IF在同窗单独诊断原始沪深300适配性。使用实际合约价格，前一交易日持仓量选主力，旧仓按旧合约计盈亏，换月计平旧和开新双边成本，不能把两合约点位跳差算成收益，也不再额外叠加估计贴水。到期按第三个周五、遇休市顺延到下一已观察交易日，并在到期日排除该合约；采用既有执行研究的规则，未重建所有特殊到期公告。参见中金所交易细则。

信号T日出、T+1收盘执行；再检验T+2收盘。初始现金1，最多约1倍名义敞口，空仓收益0，按池内净值日调仓，单边3bp/10bp。这里年化是净值CAGR，按245交易日；不是保证金收益率，也不是账户实绩。首日初始化空仓，收益/成本包含所有空仓日。整数手数、资金利息、保证金追缴、涨跌停无法成交、冲击及历史交易限制未建模；两指数的实际完整公布时点也待核实。

7. 交付与结论边界

可以形成一个只空/空仓的研究候选，最值得保留的是EW负责方向、股债比值负责低位止空。两个指数独立开空的版本，在本轮代表性规则和参数下尚无足够稳健性；IF波段版本有少量正面结果，值得知道，但还不能用事后最好参数替换现役。

研究候选CSV：ew_short_bond_guard.csv；规则：candidate_spec.json；完整首轮signals.csv与metrics.csv；补测cycle_metrics.csv；逐笔episodes.csv；统计bootstrap.csv。

本次未修改生产信号、调度或数据库。入库日更请求仍独立交由data_manager办理。原始点位基准日任意性、基金指数历史回溯和实时发布时点的限制继续成立；新增数据日更本身不能补成真正历史点时数据。

复核

新批量账本与仓库既有独立实际合约账本，在IC/IM和IF的主规则及EW基准上共4组、全部2795日收益逐日完全一致（最大差0）：ledger_crosscheck.json。6项数值测试覆盖因果性、预热、波段退出、信号滞后、前日持仓量选合约、换月成本。完整文件校验见manifest.json。

离线复现：bash -c 'ulimit -v 2000000; OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 tools/research_equity_bond_short.py'；波段补测加--cycle-extension。首轮执行无需重新取数；--prepare只用于首次冻结，已存在目录会拒绝覆盖。报告可单独调用write_report重建，无需重复回测。
