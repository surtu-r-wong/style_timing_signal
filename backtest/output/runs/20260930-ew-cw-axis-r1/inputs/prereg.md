## 3. 网格、窗口、秤与闸门（冻结）

### 3.1 网格

2 族 × (lb, zw) ∈ {(5,60), (5,250), (20,60), (20,250)} × k ∈ {5, 10, 20, 40} = **32 变体**（与新高参与度面同规模）。

### 3.2 窗口

- **主样本 D**：决策日 2014-01-02 ~ 2026-09-29（3,099 日），前瞻窗须整段落在 D 内。
- **两半窗（按 D 交易日数中点切，不按日历习惯）**：H1 = 2014-01-02 ~ 2020-05-13，H2 = 2020-05-14 ~ 2026-09-29；前瞻窗须整段落在该半窗内（同 `rotation_probe._win` 口径）。
- **确认段 C（未触碰）**：决策日 = 代表规格首个可用日 ~ 2013-12-31，前瞻窗须在 2013-12-31 及以前结束（不取 2014 年任何收益）。按形态 1,914~2,119 日（首个可用日 (5,60) 为 2005-04-12，(20,250) 为 2006-02-20）。

### 3.3 统计量（相对 `run_families_probe` 的改动，按 09-14 更正）

- **OA-IC（全起点平均 IC）**：对 o = 0..k−1，取块点 i = o, o+k, o+2k, …（要求 i+k 不越窗），IC_o = Spearman(sig(tᵢ), Σ_{m=1..k} r(t_{i+m}))；OA-IC = 各 o 的算术平均。另报 IC_o 的最小 / 中位 / 最大，以及旧口径 `rotation_probe.nonoverlap_ic`（即 o = k−1；本机与旧机器两个值并列记录，只报数、不作断言）。
- **偏 OA-IC**：各 o 上按 `rotation_probe.partial_rank_ic` 控 equal_weight，再对 o 平均。
- **分批持仓（与 OA-IC 同一决策网格）**：pos(t) = 方向 × (1/k) Σ_{j=0..k−1} sign(sig(t−j))，等价于 k 个错开起点、各持有 k 日的子账户等权合并；另报旧口径 `rotation_probe.hold_position`（单起点）的 Sharpe。
- **置换（完整循环群）**：在 D 决策日序列（长 n）上把信号整体循环移 s 位，s 在 {0, …, n−1} 均匀抽 999 次（种子 20260930），每次重算同一个 OA-IC / 偏 OA-IC（偏 IC 只移信号，控制与收益不动）；双侧 p = (1 + #{|perm| ≥ |obs|}) / 1000。
- **秤**：blend，3 bp，信号日收盘成交；关 3 用对称多空 + blend carry。

### 3.4 代表规则（逐族，blend，D）

候选 = 全窗、H1、H2 三个 OA-IC 同号且非 0 的变体；取 min(|OA-IC_H1|, |OA-IC_H2|) 最大者；平局依次比 |OA-IC_全窗| 大、k 小、lb 小、zw 小。无候选 → 关 2 不过（存档行取 |OA-IC_全窗| 最大者）。方向 = 代表 OA-IC_全窗 的符号。

### 3.5 主样本三关（逐族；三关全过才进确认段）

- **关 1**：OA-IC 置换 p < 0.05；且偏 OA-IC（控 equal_weight）与方向同号、置换 p < 0.05。
- **关 2**：代表存在（同号规则）。
- **关 3**：分批持仓、对称多空、3 bp、含 carry，D 段净 Sharpe > 0。
- **关 0（只诊断，不设闸）**：32 变体共用同一组循环移位，统计量 |OA-IC|，报 Westfall–Young **min-P**（及 max-T）下各族代表的校正 p。口径依据：默认 min-P（`method-gate0-criterion-min-p`）；但 09-14 独立模拟中完整循环群 min-P 在共同波动 / 状态切换场景误报率约 9%（名义 5%），未经本输入校准前不能作 GO 依据。本面的 GO 依据由确认段承担。

### 3.6 确认段检验（只对三关全过的族；代码自动执行，无人工介入）

- 代表规格（族、lb、zw、k、方向）冻结不改；F2 在 C 内为 300 / 500 两对平均。
- **α\* 先定（只用模拟数据；定完才读取 C 的收益）**：按代表的 (lb, zw, k) 与 C 的实际决策日数 n_C，用 `backtest.research_statistics.generated_null` 的三种无预测力场景（stationary / shared_volatility / regime）各生成 400 份，种子基 20260930 + 1,000,000，长度 = 预热 (lb+zw−1) + n_C。x 作相对收益驱动（EW 净值 = ∏(1 + 0.005·x)，CW ≡ 1，经同一变换与可用性掩码），y 作标的收益；同一 OA-IC、同一完整循环群 999 次，单侧 p。α\* = {0.05, 0.04, 0.03, 0.025, 0.02, 0.015, 0.01, 0.005} 中「三场景拒绝率都 ≤ 5%」的最大值；一个都不满足 → 确认段判不过（不可校准）。报告全部场景、全部 α 档的拒绝率及 95% 二项区间。每份数据集种子 = 种子基 + 10,000 × 场景序号 + rep（场景序号 stationary=0、shared_volatility=1、regime=2，rep 从 0 起），旋转种子 = 数据集种子 + 100,000（与 `research_statistics.calibration` 同约定）；各形态的「预热 + n_C」恒等于 D 前交易日数 2,183，故两族校准用的是逐位相同的模拟数据；校准的单侧方向固定取 +1（零假设下 y 关于 0 对称，±1 两个方向的 p 分布相同）。
- 两族都进 C 而其中一族不可校准：该族记 p = 1（判不过），α\* 取可校准那一族的值，仍按两族做 Holm（另一族须 p ≤ α\*/2）。
- **过线（三条全满足）**：
  1. C 段 OA-IC 与方向同号；
  2. 单侧置换 p ≤ α\*（C 实测置换种子 20260930 + 2,000,000；两族都进 C 时用 Holm：较小 p ≤ α\*/2，较大 p ≤ α\*；两族的 α\* 不同则取较小者，两族校准共用同一组模拟数据）；
  3. 分批持仓、对称多空、3 bp、不含 carry（当时无 IC/IM），C 段净 Sharpe > 0。
- 主样本未过的族**不碰 C**；C 原封留给以后的冻结规格作确认。
