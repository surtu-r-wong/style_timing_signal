# 自建腿灾备（failover）—— 切换手册

**适用事故**：`index_daily` 的官方风格腿**停发**或长期不可用（中证停止发布、
数据源合同变更、上游长期断更）。**不适用**于短期采集故障——那类由 topup 自愈 +
`family_sentinel` 拦截，见 `deploy/daily_signals/`。

## 1. 为什么这条路成立（先看证据再动手）

复刻误差阶梯实测（`docs/plans/2026-08-20-classifier-swap-argument.md` §7.10）：

| 层级 | 读数 |
|---|---|
| 单带价差 ρ | 1000 带 0.8957 / 2000 带 0.8710 / 300·500 带 0.957·0.964 |
| 单带信号仓位分歧 | 13.1% ~ 15.9% 天 |
| **装进四对系统后** | 最终信号 corr 0.984~0.985、仓位分歧 ~5% 天 |
| **系统级绩效差** | **0 ± 0.05**（p 0.69~0.93） |

机制 = 生产信号是四对价差的平滑等权平均，**多重平均把复刻误差也钝化掉了**。

⚠️ **红线**：灾备必须走**官方级复刻管线**（`backtest.pure_style_builder`，Gate 0 已验）。
不得临时改用自有因子层——7 月 B1 那条路（换方法论而非换测量）实测绩效
**−0.27~−0.36**（p 0.046~0.066）。**「换测量」代价≈0、「换定义」代价显著**。

## 2. 演练验收（平时做，不要等出事才第一次跑）

```bash
python3 -m deploy.failover.failover_legs --bands 1000 --start 2023-01-01 --end 2026-08-18
```

判定容差取自 §7.10 单带实测区间：信号 corr ≥ 0.85 且仓位分歧 ≤ 20% → `READY`。

**最近一次演练（2026-08-24，1000 带，2023-01-01 → 2026-08-18，8 个调样期）**：

| | 读数 | 判据 | |
|---|---:|---|---|
| 信号 corr | **0.9088** | ≥ 0.85 | ✅ |
| 仓位分歧 | **11.66%** | ≤ 20% | ✅ |
| 结论 | **READY** | | |

比 §7.10 登记的单带区间（corr 0.886~0.892 / 分歧 13.1~15.9%）**略好**，
方向一致 → 复刻管线状态健康。产物在 `output/`（gitignored 的大件除外）。

## 3. 真出事故时的动作顺序

1. **确认是停发不是故障**：`family_sentinel --mode scan --since <近月>` 看是否只是
   冻结/跳飞；查 `index_daily.updated_at` 最近写入时刻（上游漏采后批量补录是常态）。
   短期故障**不要**切灾备。
2. **补断料期**：对每个受影响的带跑 `failover_legs.py --start <断料前一个调样日> --end <今天>`。
   构建是重活（单带全窗 ~1 小时级，与 Gate 0 同量级）；只补断料期，**不要全量重建**。
3. **验收**：同一命令输出的 `verdict.status` 必须 `READY`。若 `DEGRADED`，
   **先查复刻管线**（Gate 0R 是否仍过闸、样本空间是否异常），不要直接上线。
4. **接线**：把 `failover_legs_<band>.csv` 的腿日收益接到信号构造的价差 NAV 输入。
   ⚠️ 本仓目前**未**做自动接线（见 §4 遗留）——需人工改信号链的取数源。
5. **续期**：官方腿停发后每半年（中证调样日）跑一次增量构建，保持腿名单当代。

## 4. 已知遗留（诚实交代，切换前必读）

1. **未做自动接线**：`failover_legs.py` 产出腿日收益 CSV，但信号链仍从 `index_daily`
   取数。真切换需人工改取数源。**这是本套件最大的未完成部分**。
2. **300/500 带依赖官方成分真值**（`truth_codes_by_date`）：若停发同时成分也不再公布，
   这两带须退回排名带代理，保真度会下降（未实测）。
3. **2000 带自建长窗未建**（§7.10 限制，用 649 天真值窗代表）。
4. 演练只做过 1000 带；其余三带的演练读数尚无（构建成本所限）。
