## 2. 缺陷本体

交易日的值），母指数（000300/000918/000919 等）不受影响。表征 = 08-03 当天
932406/932407/932408/932409/H30351 收盘价与 07-31 **逐位相同**，而沪深300 动 −0.98%。

- 同型事故 2026-08-06 曾被 TOPUP_SUSPECT 拦下并于 08-20 人工修复，但**没人回看更早**，
  08-03 这批就此留存 21 天。
- 全表取证另见两处非本项目输入码的冻结：2026-08-03 的 `885000.WI`/`H00922.CSI`/
  `H11021.CSI`（合计 8 个码冻结）与 **2026-08-14** 的同三码。**未修复**（不在
  `tools/topup_index_daily.sh` 的码表内，且不进本项目信号），登记待跨线处置。

## 3. 修复

```bash
tools/topup_index_daily.sh 2026-08-01     # Job 10000001749, rows=240
```

幂等 upsert 重取 2026-08-01 → 今天。修复后 08-03 各腿值 = 修复前 08-04 的值，
逐日后移一格——**整段滞后被纠正**，母指数值分毫未变（佐证「只有腿滞后」的判断）。
修复前后逐行状态存于本目录（`before_0803.txt` 为修复前全量行快照）。

## 5. 哨兵生产化（防复发）

新增 `deploy/daily_signals/family_sentinel.py`，原语 = **同族序列应当共动**，两条规则：

- **规则 5 对内价差**：`|r_成长腿 − r_价值腿| ≥ 8pp` → CRITICAL。全库标定
  3,073 交易日 × 4 对，超 8pp 的历史事件**只有 2026-06-16 的两条**（27.07pp / 9.82pp），
  第三名骤降到 7.45pp → 12.6 年零误报。6pp = WARN（约 1.8 年/次，人工复核）。
- **规则 6 序列冻结**：收益恰为 0 而**非冻结**同族中位 `|r| > 0.5%` → CRITICAL。
  13.5 年历史仅命中 1 次（正是 08-03）。参照必须剔除冻结码，否则大批冻结时中位被
  拖到 0 而漏报。

已并入 `topup_guard.audit_changes` 作规则 5/6：**CRITICAL 阻断链路、WARN 不阻断**
（未证实的可疑不拖停生产）。另提供 `--mode scan [--all-codes]` 全历史回扫供定期体检
与事后取证。测试 21 个（含两起真实事故的读数回归 + mutation 验证过）。

**为什么不用「偏离全市场中位」**：实测会误伤天生高波动序列——万得微盘在 2024-02
踩踏与 04 国九条期间偏离中位 8~12pp，那是真实行情；按序列自身尺度归一（z 分数）
也分不开（真实行情 z 达 32 vs 事故 45，同量级）。对内价差直接利用「两腿必然共动」
的构造性约束，才是干净判别式。
